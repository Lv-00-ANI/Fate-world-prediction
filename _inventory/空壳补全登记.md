## 1 · ThreeKinds ✅

| 项 | 内容 |
|---|---|
| 文件 | `FateWorld/FateV2/Meta/ThreeKinds.lean` |
| 补全前 | 609 B，0 声明（自陈「未实现」） |
| 补全后 | 191 行，13 个声明，编译通过 |
| 内容 | 三类陈述（可证/条件/经验）的判据 + 互斥性 + `support` 与 `status` 的独立性 |

### 关键定理

| 定理 | 内容 |
|---|---|
| `kinds_exclusive` | 三类**两两互斥** |
| `not_support_empty_implies_proven` | **`support = ∅` 推不出 `status = proven`** |
| `proven_allows_support` | `status = proven` 也推不出 `support = ∅` |
| `provable_compose_provable` | 可证 ∘ 可证 = 可证 |
| `compose_of_conditional_not_provable` | 可证 ∘ 条件 ⟹ **不可能回到可证** |
| `compose_of_not_provable_support` | 任一侧不空 ⟹ 组合后来源不空 |
| `kind_toStatus_injective` | 三类标签到状态是单射 |

### 为什么这两条独立性定理重要

`not_support_empty_implies_proven` 钉住的是**冲突 C-005**：
项目里「不需要公理」和「已证」长期被混为一谈。
这条定理明确证明：**没有未证前件 ≠ 已证**（一条经验陈述也可以没有前件）。

### 公理实测

```
kinds_exclusive                         不依赖任何公理   ✅
not_support_empty_implies_proven        不依赖任何公理   ✅
proven_allows_support                   不依赖任何公理   ✅
compose_of_conditional_not_provable     [propext]
provable_compose_provable               [propext, Quot.sound]
kind_toStatus_injective                 [propext]
```

`propext` 来自 `simp`。核心判据三条零公理。

### 一处陈述的修正（诚实记录）

初稿写的是「可证 ∘ 条件 = **条件**」，构造证明时发现**这是假的**：
若 `j₂` 状态是 `refuted`，`weaker` 会取 `refuted`，结果既不可证也不是条件。

**已改为「可证 ∘ 条件 ⟹ 不可证」**（`compose_of_conditional_not_provable`）。
这个修正本身揭示了「脏会传播」的准确含义：**它污染的是来源，不是状态**。
