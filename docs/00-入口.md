# 00 · 入门：五分钟看懂这个项目

## 一句话

> **把一个真实世界建模成结构因果模型，从数据中抽取规则，用它预测状态、干预与反事实，
> 并把结果导出成与原世界同类型的多模态视图；误差以噪声尺度 σ 为准绳闭合。**

这是作者对项目的原始表述（2026-09-24）：

> 「一个大规模化的预测理论」
> 「不应该把前面所有的理论用 lean4 加 mathlib 在数学完整的证完
> 并且把误差界压到可以接受再按照证明实现工程吗」

## 主链路

```
真实世界
   │  ① 数学建模（世界→数学的唯一接口）
   ▼
Model = ⟨V, U, F, P_U⟩        ← 模型 = 结构因果模型（SCM）
   │  ② 规则层：IR（条件定理 = 规则，带 support）
   ▼
规则集 R
   │  ③ 预测：predict / intervene / counterfactual
   ▼
预测出的 Model
   │  ④ 导出：模态 = 投影（开放注册表）
   ▼
多模态结果
   │  ⑤ 误差：σ = inf E_W（裁决 K）
   ▼
残差 ──⑥ 闭环──→ 回到模型层
```

## 三个最反直觉的设计

### ① 误差不是「越小越好」

**裁决 K**：合格 = **误差 ≈ σ**，其中 σ 是噪声尺度。

```
E_W(γ) := b(γ) + v(γ)                                  误差剖面（偏差 + 方差）
IsFitBoundary(W,σ,γ) := (E_W(γ)=σ) ∧ (∀γ'. σ ≤ E_W(γ'))  定义 2.3
```

**定理 3.2 已机检**：满足拟合边界的 σ **必然等于** `inf E_W`。
也就是说 σ 不是可以随便定的目标值，它被数学锁死。

**为什么**：把误差压到低于噪声尺度，是在拟合噪声本身，不是拟合规律。

### ② 底座是「纯 CIC」，经典数学是「假设」

**裁决 D-016**：

```
┌ 经典外壳（可选）──────────────────────────┐
│ propext / Classical.choice / Quot.sound    │  ← 这三条是**假设**，不是底座
│ → 得到 ℝ、Measure、拓扑                    │
├ 构造性核（纯 CIC，无任何假设）─────────────┤
│ Term / Formula / Data / Judgment           │
│ 在此层证出的定理：support = ∅，status = proven │
└────────────────────────────────────────────┘
```

**⟹ 「底座纯 CIC」的真实含义**：底座只有 CIC；需要经典数学时，是在纯 CIC 之上**加了三条假设**。

配套铁律 **账实相符**：`#print axioms` 必须**等于** `support.assumptions`。
用了什么就必须登记什么，没登记的公理不允许出现。

### ③ 模型必须按因果组织（不能按模态拆）

**裁决 D-014**：`Model = ⟨V, U, F, P_U⟩`（内生变量 / 外生变量 / 结构方程 / 外生律）。

**裁决 D-013**：模型是**一体化完整系统**，不按模态拆分；模态只是**导出投影**。

**代价**：「图 ⟹ 概率」的桥成为**必经之路**——这是全设计最脆的地方。
