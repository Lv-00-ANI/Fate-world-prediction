## 每条裁决必须包含的字段

见 [`_模板.md`](_模板.md)。核心是六项：

1. **裁决原话**（你的原话，逐字）
2. **裁决内容**（整理成表）
3. **依据**（为什么这么定，带出处）
4. **必须一起承接的代价**（不定这些就等于没定）
5. **对既有产物的影响**（哪些环节/文件要改）
6. **未决尾巴**（这一裁决拉出的新问题）

> **第 4 项和第 6 项最关键**。项目过去最大的问题就是「裁决下了，但代价没承接、尾巴没人跟」。
