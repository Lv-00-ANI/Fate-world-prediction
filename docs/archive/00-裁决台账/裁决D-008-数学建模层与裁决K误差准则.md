## 一、裁决内容（三条）

| # | 裁决 |
|---|---|
| **1** | **新增「数学建模层」，作为全链第一层**。它位于「真实世界」与「规则层（IR）」之间 |
| **2** | 该层的职责：把真实世界**建模**成数学对象，并**显式登记**建模所引入的经验假设 |
| **3** | **误差准则沿用裁决 K**：合格标准不是「越小越好」，而是**误差恰好落在拟合/过拟合边界 = 噪声尺度 σ** |

## 二、数学建模层在链条中的位置

```
真实世界
   │
   ▼  ★ 数学建模层（本裁决新增，全链第一层）
   │     · 数据构造（D-007）
   │     · 选动力学形式（f 或 μ,σ）
   │     · 定观测模型（h, η）与 A14 分支
   │     · 定噪声尺度 σ
   │     · 登记「构造忠实性」等经验假设
   ▼
数学对象 + 经验假设账本
   │
   ▼  规则层（IR：Term / Formula / Judgment）
   │
   ▼  预测 / 干预 / 反事实
   │
   ▼  误差层（用 σ 判合格 —— 裁决 K）
```

## 三、建模层的产出契约

| # | 产出 | 类型 / 形式 | 去向 | 状态 |
|---|---|---|---|---|
| 1 | **数据对象** | `Data` / `def`（ℚ 序列、有限测度、函数、复杂逻辑结构） | IR 的 `lit` | 必产 |
| 2 | **动力学形式** | `f : X×U×E×Θ×A → X` 或 `(μ, σ)` | `F2-01` / `F2-12` | 必产其一 |
| 3 | **观测模型** | `h : X → Y`、`η` 的分布 | `F1-07` | 必产 |
| 4 | **A14 分支选择** | 无损 / 估计（二选一，须显式声明） | `F1-09` / `F1-10` | 必选 |
| 5 | **噪声尺度 σ** | `σ > 0`（或不可识别的说明） | `F7-02` / `F7-11` / 误差判据 | 必产 |
| 6 | **建模假设** | 经验假设（含「构造忠实性」） | 假设账本 | 必登记 |
| 7 | **脏的建模** | 缺失掩码、噪声分布、采样偏差说明 | 与 6 合并 | 必登记 |

**关键**：**σ 由建模层产出**。没有 σ，裁决 K 的判据（误差 ≈ σ）**无法执行**。

## 四、裁决 K 的精确内容（逐字）

> **作者原话**：
> 「**误差太大了　之前是聊过的误差必须小到不影响　就是刚好拟合和过拟合的边界**」
> —— `作者裁决K-误差准则.md:10`

**准则**：

| 情形 | 判定 |
|---|---|
| 误差**大到影响结论** | ❌ 不合格 |
| 误差**小到开始拟合噪声** | ❌ 不合格（过拟合） |
| 误差**恰好等于信号与噪声的分界尺度** | ✅ **合格** |

**性质**：这是**分辨率选择原则**（偏差—方差权衡），不是「越小越好」。

**适用范围**：**全部误差相关项**（E8 编码误差、误差界、编码分辨率），**强制**。

## 五、为什么必须新增这一层

### 5.1 没有建模层，σ 无处产生

裁决 K 要求「误差 ≈ σ」，但 **σ 不从规则层来，也不从预测层来**——它只能由**对世界的建模**给出。

`F7` 族实测：σ 在框架内**既不可证也不可否证**（AIC／信息增益／领域参数三条路径全部失败），只能登记为经验假设。
⟹ **σ 的产生地必须在链条最前端显式存在**，否则误差判据永久悬空。

### 5.2 没有建模层，D-007「数据必须数学构造」没有归属

D-007 要求所有数据用数学语言构造，但**构造动作发生在哪一环**原来没定。
建模层就是那个环节。

### 5.3 它把「定义」「假设」「脏」三件事集中到一处

| 原来是散的 | 现在集中 |
|---|---|
| 数据形态（`F1-13`） | 建模层产出 1 |
| 动力学形式（`F2-01`/`F2-12`） | 建模层产出 2 |
| 观测模型 + A14（`F1-07/09/10`） | 建模层产出 3、4 |
| σ（`F7-02`） | 建模层产出 5 |
| 经验假设（`F8-05`） | 建模层产出 6 |
| 「脏」（散落在数据里） | 建模层产出 7 |

**⟹ 建模层是「世界 → 理论」的唯一接口。跨过它的一切都必须已经是数学对象。**

## 六、必须一起承接的代价

### 代价 1 · 建模层不可证，只能登记

「这个建模忠实于世界」**无法在框架内证明**。它是**新的、集中的经验假设**。
⟹ 必须有逐条登记 + 可追溯（档案 hash + 建模记录）。

### 代价 2 · σ 可能给不出

若 σ 无法从数据或领域确定，建模层必须**显式写「σ 不可识别」**，而不是随便填一个数。
否则裁决 K 的判据会被一个假 σ 污染——**比没有判据更危险**。

### 代价 3 · 建模层成为新的瓶颈

全链第一步就依赖它，且工作量大（每个系统都要建模）。
⟹ 可能需要「建模模板」（同类系统的建模复用）。

### 代价 4 · 与 FCA 入口的连锁

裁决 K 已判定：当前编码方案「胞腔直径 = 全域 52%」，**远离噪声尺度**，故 FCA 不能作主线入口。
建模层给出的 σ 会**重新激活**这条判定——σ 变了，合格性结论也变。
