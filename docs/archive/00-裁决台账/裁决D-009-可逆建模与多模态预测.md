## 一、裁决内容（四条）

| # | 裁决 |
|---|---|
| **1** | **数学建模层必须可逆**：`Model ↔ RawData` 双向，`reconstruct ∘ construct = id` |
| **2** | **整个预测可还原成一个大型数据建模问题**：预测不是在数值上外推，而是在**模型空间**里演化，再还原成数据 |
| **3** | **产出多模态**：预测结果包含**原数据拥有的全部数据类型**，不只是标量 |
| **4** | 因此**状态空间 `X` 的元素是 `Model`**，不是单个实数向量 |

---

## 二、可逆性怎么实现（关键设计）

**不靠定理，靠构造**：

> **让 `Model` 把 `RawData` 整个包含进去。**

```lean
structure Model where
  raw        : RawData                    -- ★ 原始数据原样保留
  modalities : List ModalityView          -- 每个模态的规范化视图
  coupling   : Coupling                   -- 跨模态耦合
  noise      : ∀ m, NoiseScale            -- 每个模态的 σ（裁决 K）
```

于是：

```lean
def construct (d : RawData) : Model := { raw := d, modalities := view d, … }

def reconstruct (M : Model) : RawData := M.raw

theorem reconstruct_construct : reconstruct (construct d) = d := rfl   -- ★ 定义性成立，不是假设
```

**⟹ 可逆性是 `rfl`，不需要任何假设、不丢信息。**

这是本裁决最重要的技术选择：**把可逆性做成定义性的，而不是要求建模者「证明无损」**。

---

## 三、损失源分离（这条裁决的真正价值）

有了可逆建模层，**误差来源被干净地分开**：

| 阶段 | 是否有损 | 损失叫什么 |
|---|---|---|
| **建模层** | ❌ **无损**（可逆） | ——（没有损失） |
| **规则层（α 抽象）** | ✅ 有损 | **抽象损失** |
| **预测层** | ✅ 可能有损 | **预测损失** |
| **还原层（reconstruct）** | ❌ 无损 | ——（没有损失） |

**⟹ 所有误差都可以归因到「抽象」与「预测」两处，不会混进「数据表示损失」。**

对比原来的问题：数据表示、抽象、预测三层损失混在一起，谁也说不清误差从哪来。
现在：**建模无损做基准，误差纯度高。**

---

## 四、预测的形式

```
原始多模态数据
   │ construct（无损）
   ▼
Model_t          ← 状态空间的元素（不是标量）
   │ 规则层抽象（有损）
   ▼
规则集 R
   │ 预测：Model_t → Measure Model_{t+1}
   ▼
Model_{t+1} 的分布
   │ reconstruct（无损）
   ▼
预测出的多模态数据 + 每个模态的 σ
   │ 与真实数据逐模态比较
   ▼
误差（按裁决 K 判合格：误差 ≈ 该模态的 σ）
```

**关键变化**：
- `Pred : X → Measure X` 仍然成立，但 **`X = Model`**
- 误差在**数据层面**算，且**逐模态 + 联合**
- σ 是**每模态一个**（多维），不是一个标量

---

## 五、必须一起承接的代价

### 代价 1 · `Model` 巨大

`Model` 含 `raw`（全部原始数据）+ 视图 + 耦合。一百万行的数据集 → 一个巨大的结构。
**作者已接受**（「虽然可能会很大」），但工程上必须分层（分段 + 摘要 + 引用），否则内核检查不可用。

### 代价 2 · 状态空间爆炸

`X = Model` 意味着状态空间的每个元素都携带全量数据。
所有基于 `X` 的定理（轨迹、转移核、`Pred`）都变成「在巨大对象上」的命题。
⟹ 可能需要「状态的分层表示」：`X` 只携带**摘要 + 引用**，全量数据留在档案。

### 代价 3 · 多模态耦合难以形式化

「所有模态的联合分布」比「每个模态各自的分布」难得多。
跨模态耦合 `coupling` 的具体形式未定——这可能是整个设计里最难的一块。

### 代价 4 · 与 D-005/D-006「消融」的张力

D-005/D-006 说数据可消融（有损）。
本裁决说建模层可逆（无损）。
**两者不矛盾，但必须分层说清**：

| 层 | 性质 |
|---|---|
| **表示层**（建模） | **无损**（可逆） |
| **推理层**（抽象/消融） | **有损**，损失必须可度量（用 σ 判合格） |

⟹ **消融是「从 Model 抽规则」时的有损操作，不破坏 Model 本身。**

## 六、对既有产物的影响

| 对象 | 变化 |
|---|---|
| `StateSpace` / `X` | 元素从「标量向量」变为 **`Model`**（破坏性） |
| `Pred`（`Frame.lean:782`） | 仍是 `X → Measure X`，但 `X` 语义变了 |
| `F2-01` 转移方程 | `f : Model × U × E × Θ × A → Model` |
| `F6-04 xNextDist` | 输入输出都变成 `Model` |
| `F7` 误差判据 | σ 变为**每模态一个**；误差按模态分别判 + 联合判 |
| 建模层产出契约（D-008） | 新增「可逆性」与「多模态完整性」两条 |
| 主链装配 | 起点与终点都变成 `Model` |

**破坏性极大**：这是本裁决最重的代价——`X` 换语义会波及全部轨迹层与预测层定理。

## 七、未决尾巴

| # | 问题 | 不定的后果 |
|---|---|---|
| **1** | **「所有数据类型」的枚举与类型**：模态有哪些？（数值/类别/时序/图/文本/图像…） | 多模态无法定义 |
| **2** | **`Model` 是否含全量数据**，还是「摘要 + 引用」 | 巨大 vs 可算，二者冲突 |
| 3 | **跨模态耦合 `Coupling` 的形式** | 联合分布无法表达 |
| 4 | **σ 是每模态一个还是联合一个** | 裁决 K 的判据无法落到多模态 |
| 5 | 可逆是否要「精确」还是允许 up-to-ε | 若允许 ε，则「无损」变成近似 |
| 6 | `X = Model` 的破坏性迁移路径 | 全部轨迹/预测定理要重写 |

**⚠ 尾#1 最要紧**：不定「模态有哪些」，多模态就是空话。
