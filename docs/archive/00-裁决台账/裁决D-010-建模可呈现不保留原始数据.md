# D-010 · 建模不保留原始数据，只要求「可呈现」

> **裁决日期**：2026-10-28
> **裁决人**：作者
> **裁决原话**：「没必要保留原始数据啊　整个预测结果能转换出来就行　不如预测结果咋看　建模回可看数据的意思」
> **修订**：[`裁决D-009`](裁决D-009-可逆建模与多模态预测.md) 的「可逆」要求
> **设计稿**：[`07-IR设计/README.md`](../07-IR设计/README.md)

---

## 一、修订了什么

D-009 要求 `Model ⊇ RawData`、`reconstruct ∘ construct = rfl`（严格可逆）。

**本裁决修正为：**

| 原要求（D-009） | 新要求（D-010） |
|---|---|
| `Model` 保留 `raw : RawData` | ❌ **不保留** |
| `reconstruct : Model → RawData`，且 `∘ construct = rfl` | ✅ **`view : Model → 各模态数据`**，只要求**能呈现成原数据同类型的值** |
| 无损（信息不丢） | 不必无损；但**建模误差必须可测** |

**「可逆」的真实含义 = 可呈现（presentable）**：
> 预测结果要能**转换出来给人看、给下游比**，而不是「字节级还原」。

---

## 二、新结构

```lean
structure Model where
  modalities : List ModalityView      -- 每个模态的规范化视图
  coupling   : Coupling               -- 跨模态耦合
  noise      : ∀ m, NoiseScale        -- 每模态一个 σ
  -- ✗ 没有 raw : RawData

/-- **呈现算子**：把 Model 渲染成「与原数据同类型」的值。
    这是「建模回可看数据」的落点。 -/
def view : (M : Model) → ∀ m ∈ M.modalities, m.carrier
```

**要求**：
- 每个模态 `m` 有确定的 carrier 类型，且**与原数据该模态的类型一致**
- `view M m` 产出**可看、可比、可算误差**的值

**不要求**：`view (construct d) = d`（那才是严格可逆）。

---

## 三、代价：多了一项必须管的误差

既然建模不再无损，**建模误差**就成了一个独立且必须度量的量：

```
建模误差  ε_model(m) := dist( view (construct d) m , d m )      -- 第 m 个模态
```

**但这不是坏消息**——它可以用**裁决 K** 判定：

| 情形 | 判定 |
|---|---|
| `ε_model` **远大于 σ** | ❌ 建模太粗，丢掉了信号 |
| `ε_model` **远小于 σ** | ❌ 建模在拟合噪声（过拟合） |
| **`ε_model ≈ σ`** | ✅ **合格** |

**⟹ 裁决 K 不仅管预测误差，也管建模误差。建模层自己也要过这一关。**

这其实比 D-009 更严：D-009 靠「无损」把建模误差设为 0（免检）；现在建模误差**必须显式报出来并接受合格性判定**。

---

## 四、损失源分离表（更新）

| 阶段 | 有损？ | 损失名 | 用裁决 K 判？ |
|---|---|---|---|
| 建模层 `construct` | ✅ **有损**（但可测） | **建模误差 `ε_model`** | ✅ **必须判**（≈ σ） |
| 规则层 `α` 抽象 | ✅ 有损 | 抽象损失 | ✅ 应判 |
| 预测层 | ✅ 可能有损 | 预测损失 | ✅ 必须判（≈ σ） |
| 呈现层 `view` | ❌ 无额外损失 | —— | —— |

**⟹ 三层损失全部显式，全部用同一个判据（≈ σ）。**
比 D-009 的「两层」更完整——D-009 把建模损失藏进了「无损」假设里。

---

## 五、这样改的好处

| 好处 | 说明 |
|---|---|
| **`Model` 变小** | 不再携带全量数据，可计算 |
| **可逆性不再需要证明** | 只要求 `view` 能产出同类型值，是工程要求不是数学定理 |
| **误差更诚实** | 建模损失从「假装为 0」变成「显式报数并受检」 |
| **与裁决 K 统一** | 三层损失用同一判据 |

## 六、代价

| 代价 | 说明 |
|---|---|
| **必须实现 `view`** | 每个模态都要有「渲染回原类型」的映射，且要保证语义可比 |
| **建模误差必须被测量** | 需要「原始数据」在建模时可访问（用完即弃，不必长期保留） |
| **多模态的 `view` 签名复杂** | 依赖类型（`∀ m ∈ modalities, m.carrier`）在 Lean 里较繁 |
| **可呈现 ≠ 可还原** | 若 `view` 写得不好，预测结果可能「看起来对但细节失真」——需要验收判据 |

---

## 七、对 D-009 的影响

| D-009 条款 | 状态 |
|---|---|
| 建模层必须可逆 | ⚠️ **改为「必须可呈现」** |
| 整个预测 = 大型数据建模 | ✅ 保留 |
| 多模态产出含原数据所有类型 | ✅ **保留，且是「可呈现」的核心内容** |
| `X = Model` | ✅ 保留 |
