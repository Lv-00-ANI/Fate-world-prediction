## 一、裁决内容

**模型 = 结构因果模型（SCM）**。D-013 的三个类型由此定形：

```lean
/-- **模型 = SCM**：一个完整的系统，按因果结构组织（不按模态）。 -/
structure Model where
  V   : Type                       -- 内生变量集
  U   : Type                       -- 外生变量集（噪声来源）
  F   : V → (V → Val) → (U → Val) → Val   -- 结构方程族
  P_U : Measure U                  -- 外生律（= 噪声结构）
```

| D-013 的占位 | 现在定形为 |
|---|---|
| `WholeState` | **内生变量赋值** `V → Val`（一个点） |
| `WholeMechanism` | **结构方程族** `F` |
| `NoiseStructure` | **外生律** `P_U : Measure U` |

**⟹ 这与净版定义 3.1 的 `𝓜 = ⟨V, U, ℱ, P(U)⟩` 是同一个东西。**

## 二、为什么这个选择好

| 理由 | 说明 |
|---|---|
| **理论本来就长这样** | 净版第 3 章的 SCM 就是四元组；不需要新造对象 |
| **干预 / 反事实原生支持** | `do(X=x)` = 换一条结构方程；反事实三步直接用 SCM 语义 |
| **一体化但不是无结构** | SCM 有明确结构（变量 + 方程），但**结构不是按模态切的**——正合 D-013 |
| **对外生律直接给出噪声** | `P_U` 就是噪声结构；不需要另造「噪声模型」 |
| **已有编译通过的实现** | `SCMGraph` / `SCMSemantics` 在 `ProperFit` 树里**已编译**（见 `08-拟合边界` §六） |

## 三、顺带解决：σ 的传播规则

这是我之前标记为「完全空白」的 `induce`。在 SCM 里它有了自然形式：

```
外生律 P_U  ──结构方程 F──▶  V 上的诱导分布 P_V
                                    │
                                    │ 投影 project_m
                                    ▼
                            模态 m 上的分布 P_m
                                    │
                                    │ 取离散度
                                    ▼
                         σ_model(m) := spread(P_m)
```

**用一句话说**：

> **模态的噪声尺度 = 外生律经结构方程与投影推前之后的离散度。**

```lean
def induce (M : Model) (project : (V → Val) → carrier) : NoiseScale :=
  spread (Measure.map (project ∘ (fun u => M.F … u)) M.P_U)
```

**⟹ `dT/dt` 的 σ 由 `T` 的外生噪声 + 求导投影共同决定——可以算，不是拍脑袋。**

### 这给出两个 σ，且它们是**可比较**的

| σ | 定义 | 怎么得到 |
|---|---|---|
| **σ_model(m)** | 模型诱导的离散度（上式） | **从模型算**（无需数据） |
| **σ_emp(m)** | 误差剖面的下确界 `inf E_W`（定理 3.2） | **从数据测** |

**裁决 K 用的是 `σ_emp`；而「`σ_model ≈ σ_emp`」本身是一条可检验的经验命题。**

这正好接上 `08-拟合边界` §8.6 的「经验腿」——**我们的建模层提供 `σ_model`，于是那条桥接有了一个具体可算的一端。**

## 四、必须一起承接的代价

### 代价 1 · 「图 ⟹ 概率」的桥重新进入关键路径

选 SCM 作模型，意味着**要从结构推概率**——这正是本项目最破的一处：
- 无条件版在**未归一化口径**下已被机检证伪（`FactorizesNotImpliesLMG`，`2=4`）；⚠ **概率口径下未被证伪**（反例 `colliderP` 总质量 = 4，见 `04-状态核对` 冲突 #9）
- 条件版（因子分解 ∧ d-分离 ∧ 覆盖）是**真证**，但前件 `hcover` 极重
- 全库仅 0.84% 定理同时含图与概率

**⟹ 选丙的代价是：桥成为必需，而桥基本不存在。** 这是本裁决最重的代价。

### 代价 2 · 需要「图已知」假设（A19）

SCM 的图若未知，要因果发现——而因果发现**全库零实现**（`F5-18` 缺失）。
⟹ 建模层必须**给图**，或者接受 A19 作为显式假设。

### 代价 3 · `V → Val` 的类型设计

内生变量的值可能是实数、类别、甚至结构。`Val` 若统一为 ℝ，会丢掉类型区分；
若做成依赖类型，则 `Val` 依赖 `V`（`v : V → Type`），复杂度上升。

### 代价 4 · 时变变量怎么表示

动力学 `x_{t+1} = f(x_t, …)` 在 SCM 里需要「时间索引的内生变量」：
`V = (Entity × Time)`，结构方程跨时间引用。这会**显著放大 `V`**。
