## 一、事实核查（关键，先把「有没有 HIT」钉死）

### 1.1 Lean 4 内核**不支持** HIT

`Quot` **不是**高阶归纳类型，而是 `init_quot` 注入的 **opaque 原语**：

| 事实 | 证据（工具链源码，本机实测） |
|---|---|
| `Quot` 系列是 **`opaque` 原语**，不是 `inductive` | `Init/Prelude.lean:446-459`：「Initialize the Quotient Module, which effectively adds: `opaque Quot …` / `opaque Quot.mk …` / `opaque Quot.lift …` / `opaque Quot.ind …`」→ `init_quot` |
| `Quot.sound` 是**公理**（不是证明出来的） | `Init/Prelude.lean:473`；它出现在任何用到商的定理的 `#print axioms` 里 |
| `propext` 是**公理** | `Init/Core.lean:1591`：`axiom propext {a b : Prop} : (a ↔ b) → a = b` |
| 内核没有 path constructor / 区间类型 | 工具链不含 HIT 相关声明 |

**⟹ Lean 4 无法表达 HIT。** 需要 Cubical Agda / Arend 一类内核。

### 1.2 Mathlib **没有** HIT

| 检查 | 结果 |
|---|---|
| `higher inductive`（8268 个 `.lean` 全文） | **0 命中** |
| `HIT` 字样 | 5 处，**全部误报**（`performance hit`、变量名 `hit`） |
| `Quot.sound` 使用处 | **207 处** |
| 引用 `Quotient` / `Quot.mk` / `Quot.lift` 的文件 | **958 个** |

**⟹ Mathlib 的商全部建立在 `Quot` 原语（含 `Quot.sound` 公理）之上。没有 HIT 这条路。**

## 三、商怎么改（构造性标准做法）

| 通常做法（用 `Quot`） | 构造性替代（不用 `Quot`） |
|---|---|
| 商类型 `A/~`，元素是等价类 `[a]` | **`~`-不变的谓词** `P : A → Prop`，且 `r a b → (P a ↔ P b)` |
| 从商出发定义函数：`Quot.lift f h` | 定义 `f : A → B`，并**证明 `f` 在 `~` 下不变** |
| 在商上证性质：`Quot.ind` | 直接在代表元上证，再证性质的不变性 |
| 商上相等：`Quot.sound` | **不出现商上相等**——只在代表元层讨论 |

**核心洞察**：商的「类型」被替换为「不变量」。这是 Bishop 式构造数学的标准手法。

### 对规则层的直接后果

> **「规则 = 商」在核内实现为「规则 = `~` 下的不变量」。**

这与 `T112Exactly` 发现的「FCA 特有命题不存在」也相容：既然规则的本质是「不变量」，那它不依赖 FCA 的特殊结构，正合该结论。

## 四、必须一起承接的代价

### 代价 1 · `ℝ` / `Measure` 用不了

- Mathlib 的 `ℝ` 是 Cauchy 序列的商 → 用 `Quot`
- `Measure` 的 Carathéodory 扩张依赖 `Classical.choice`

⟹ **两者都只能在经典外壳里**。核内不能有实数、不能有测度。

**影响**：`σ` 是实数、`P_U : Measure U`、误差剖面 `err : ℝ → ℝ` —— 全部落在经典侧。

### 代价 2 · 「从规则类型出发的函数」全部要重写

没有 `Quot.lift`，所有 `Rule → 某物` 的函数都要改成「不变的函数 + 不变性证明」。
这是 `F4` 族（四算子）的**实际工作量**。

### 代价 3 · `F3-13` 的四个 `∼_𝓔` 变体要重评

| 变体 | 依赖 | 在核内是否可用 |
|---|---|---|
| V1 外置 `Setoid` 参数 | `Setoid` 是 class（依赖 `Quot`？**不依赖**，`Setoid` 只是关系+等价性） | ✅ 可用 |
| V2 `α∘enc` 的核 | 同上 | ✅ 可用 |
| V3 `⊤`（全同） | 同上 | ✅ 可用 |
| V4 规则空间上的构造等价 | 若形成商类型则**不可用** | ⚠️ 需改写为不变量 |

> **注**：`Flat/Setoid` 本身不含 `Quot`；`Quotient` 才需要。所以「有 Setoid」不等于「用了商类型」——这是本裁决的一个有利事实。

### 代价 4 · 商上做推理会变啰嗦

「两个元素相等」在商里是 `Quot.sound`；在不变量表示里，要显式带上「它们 `~` 相关」这个前提。
所有用到商相等的地方都要改。
