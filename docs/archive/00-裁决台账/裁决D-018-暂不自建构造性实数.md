# D-018 · 暂不自建构造性实数，但**必须后补**

> **裁决日期**：2026-10-29
> **裁决人**：作者
> **裁决原话**：「暂时不自建后面要补」
> **关闭**：[`D-017`](裁决D-017-内核纯构造不用Quot.md) 尾#4
> **定级**：**承诺后补**（不是放弃，也不是待研究）

---

## 一、裁决内容

| # | 裁决 |
|---|---|
| **1** | **现阶段不自建构造性实数**（Bishop reals / Cauchy 序列 + modulus） |
| **2** | 但**必须后补**。这是一条**承诺**，不是放弃 |
| **3** | 补的触发条件：**当核需要自己谈误差/收敛时** |
| **4** | 在补之前，核的定位是**纯语法层**；一切带 `ℝ` 的分析落在经典外壳 |

---

## 二、为什么现在不建

| 理由 | 说明 |
|---|---|
| **工作量与收益不匹配** | Cauchy 序列 + modulus + 构造性完备性，是独立的大型工程；而当前最缺的是**一个能跑起来的实例** |
| **不影响 P0** | 核的第一步是 `Term`/`Formula`/`Data`/`Judgment` 的**语法**，不需要实数 |
| **现行设计已把分析隔离** | σ、误差剖面、`P_U` 全在经典外壳；核内不碰它们就不需要实数 |
| **避免过早绑定** | 构造性实数的具体表述（Cauchy / Dedekind / Bishop 式）本身有取舍，仓促定会锁死后续选择 |

---

## 三、为什么必须后补（不是放弃）

**补的理由是结构性的**：

| 若不补 | 后果 |
|---|---|
| 核里没有实数 | 核**永远无法自己谈误差**——`ε_model ≈ σ` 这类命题只能在经典外壳里说 |
| 依赖经典外壳 | 一旦挂上三条假设，就**不再是构造性的**，「底座纯 CIC」的意义被削弱 |
| 误差层与核脱节 | 而误差层是裁决 K 的落点，也是整个系统的判据核心 |

**⟹ 后补构造性实数，是「让核真正成为核」的最后一块。**

---

## 四、后补的判据（什么时候算补完了）

| 判据 | 内容 |
|---|---|
| C1 | 存在 `ℝc`（构造性实数），**不依赖** `propext`/`choice`/`Quot.sound` |
| C2 | `ℝc` 有加法、乘法、序、完备性（Cauchy 完备或 Dedekind 完备的构造性版本） |
| C3 | 误差剖面的核心结论（`E_W = b + v` 非负、`inf E_W` 存在）能在 `ℝc` 上重述 |
| C4 | `#print axioms` 对这些定理 = `[]` |

**判据 C4 是硬门禁**：补完之后，这些定理的公理依赖必须为空。
