## 二、否定性结果的射程（裁决内容）

### 2.1 被推翻的（**用法**）

| 命题 | 状态 |
|---|---|
| 「几何—组合双界**主导**实际可满足性」 | ❌ **被论文自己的实验推翻** |
| 「`n ≥ s/σ` 可作**分辨率预算**」 | ❌ **不成立**（α ≠ 1 且因数据而异） |
| 「几何量 → 误差量」的 **Lipschitz 传递（α=1）** | ❌ **2/3 公开数据集上被证伪**（α = 0.280 / 1.007 / 0.601） |

### 2.2 未被推翻的（**定理**）

| 结论 | 状态 |
|---|---|
| **定理 3.2：σ = inf E_W** | ✅ 不受影响 |
| 定理 3.3 / 3.4（去参数化等价、σ 取错则边界集空） | ✅ 不受影响 |
| 定理 6.1 / 6.4 / 6.5（唯一性来自严格凸） | ✅ 不受影响 |
| 定理 8.5（σ 有限数据下不可辨识） | ✅ 不受影响 |
| 定理 10.2（胞腔宽度 ≥ s/n） | ✅ 不受影响 |
| 定理 10.7（胞腔数 ≤ (n+1)^d） | ✅ 不受影响 |

**⟹ 「失效来自假设，不是定理」——这是论文自己的定性，本裁决采纳。**

## 三、由此产生的三条使用规则

| # | 规则 |
|---|---|
| **1** | **裁决 K 仍以 `σ = inf E_W` 为准**。它只依赖定理 3.2，不依赖双界。 |
| **2** | **双界只作数学界，不作工程预算。** 凡引用 `n ≥ s/σ` 做工程判断，必须标注 $\alpha$ 的来源与实测值。 |
| **3** | **`ε_model ≈ σ`（D-010）仍可用**；但**不能由它反推「建模该多细」**——那需要 $\alpha$。 |

## 四、为什么**不**退回旧版论文

旧快照（2026-10-28）没有 §11.5/§11.6。**但这不是因为结论不成立，而是因为实验还没做。**

若以旧版为准，等于**假装实验没发生**。这与本项目最忌的两件事同类：

| 已忌 | 本次对应 |
|---|---|
| 把「编译通过」当成「数学有进展」 | 把「界成立」当成「预算可用」 |
| 静默删除不利证据 | 用旧版回避否定性结果 |

**⟹ 处置：新版为准，旧快照存档；否定性结果进设计约束，不进档案室。**
