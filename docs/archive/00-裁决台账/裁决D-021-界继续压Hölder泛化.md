## 一、作者的怀疑是什么

D-020 采纳的否定性结果是：

> 「几何量 → 误差量」的传递假设（**α=1**，即 Lipschitz）在 3 个公开数据集上有 2 个被证伪
> （实测 α = 0.280 / 1.007 / 0.601）。

**作者怀疑：这不是终点——界还能继续压，压到阳性结论。**

本裁决采纳这个怀疑，并给出**它成立的确切条件**。

## 二、否定性结果的真实结构

它的 Lean 形式化在 `Legacy/ProperFit-6e03674/LipschitzTransfer.lean`：

| 定理 | 内容 | 性质 |
|---|---|---|
| `lipschitz_cell_error` | `|f x − f y| ≤ L·w` | **条件**定理（前件 = Lipschitz） |
| `cell_error_le_of_lipschitz` | `L·(s/n) ≤ σ ⟹ 误差 ≤ σ` | 条件 |
| `needed_bins` | `L·(s/n) ≤ σ ⟹ L·s/σ ≤ n` | 条件 |
| `step_not_lipschitz` | 阶跃函数不 Lipschitz | **无条件**（构造性反例） |
| `step_no_decay` | 阶跃下任意 `n` 误差 ≥ 1/2 | **无条件** |
| `no_uniform_decay` | 不存在统一的 `1/n` 衰减 | **无条件** |

**关键区分**：

- **无条件的部分**（阶跃反例族）= 「**没有 α 假设时**，误差不随 n 衰减」——**这条永远成立**
- **条件的部分**（传递引理）= 「**给定 α**，误差界是 `L·w^α`」——**这里 α 是可换的**

**⟹ 被证伪的不是「界」，而是「α=1 这个具体取值」。**

## 三、怎么压（四条，按优先级）

| # | 压法 | 换来什么 | 可证性 |
|---|---|---|---|
| **1** | **Lipschitz(α=1) → Hölder-α** | 判据对任意**实测** α 成立 | ✅ **本裁决立刻可做**（策略④ 泛化） |
| 2 | 均匀网格 → **自适应划分** | 把 `s/n` 换成实际最大胞腔直径 | 需新几何模块 |
| 3 | 环境维数 `d` → **内在维数** `d_eff` | 收紧组合界 `(n+1)^d` | 需新度量模块 |
| 4 | 最坏情形（L∞） → **L² 平均** | 同样 α 下所需 n 更小 | 需 L² 投影论证 |

**本裁决只落第 1 条**（其余列后续）。

## 四、第 1 条的具体形式（本裁决要求实现）

### 4.1 定义

`f` 是 **α-Hölder（常数 L）**：

```
∀ x y, |f x − f y| ≤ L · |x − y|^α
```

`α = 1` 即 Lipschitz（特例，见 4.3）。

### 4.2 新的传递与判据

| 定理 | 内容 |
|---|---|
| **`holder_cell_error`** | `|f x − f y| ≤ L · w^α` |
| **`cell_error_le_of_budget`** | `L·(s/n)^α ≤ σ ⟹ 误差 ≤ σ` |
| **`lipschitz_is_holder`** | α=1 时退化为 `LipschitzTransfer.lipschitz_cell_error` |

**⟹ 判据从 `n ≥ s/σ`（只对 α=1）变成 `L·(s/n)^α ≤ σ`（对任意实测 α）。**

### 4.3 「阳性」是哪种阳性（必须说清）

| 读法 | 含义 | 压界后 |
|---|---|---|
| **P1 · 有效性** | 界重新支配可满足性（判据成立） | ✅ **能救回**——Hölder-α 就是 |
| **P2 · 可行性** | 实际参数下可满足 | ⚠️ **不确定**——α 越小，所需 n 越大 |

**α = 0.28 时**，达到同样 σ 所需 n 是 α=1 时的 `(L/σ)^{1/0.28 - 1}` 倍——**天文数字**。
所以：

> **压界能救回「判据有效」（P1）；要救回「实际可行」（P2），必须同时用第 2/3/4 条。**

**这不是坏消息**：P1 恢复后，「什么条件下可行」变成**可计算**的问题，而不是被一句「不成立」封死。

## 六、代价与风险

| # | 代价 |
|---|---|
| 1 | **必须实测 α**——不能再用 α=1 免测。α 的估计本身有误差（论文里 `k` 敏感），误差会传到预算 |
| 2 | α-Hölder 是**全局**假设；真实函数常是**局部** Hölder（不同区域不同 α），全局版会低估所需 n 或高估可行性 |
| 3 | `α → 0` 时判据退化（所需 n → ∞），与「无假设即不衰减」一致——**这是正确行为，不是缺陷** |
| 4 | `ℝ^α`（`Real.rpow`）是 `noncomputable`，落经典外壳，需登记 |
