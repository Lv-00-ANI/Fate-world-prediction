## 二、为什么空泛（两条，任一即足以否决）

### 2.1 它是定义展开，不是定理

```lean
def Holder (f : ℝ → ℝ) (L α : ℝ) : Prop :=
  ∀ x y : ℝ, |f x - f y| ≤ L * |x - y| ^ α

theorem holder_cell_error (hf : Holder f L α) (P : WidthCell w) (hy : y ∈ P.cell x) :
    |f x - f y| ≤ L * w ^ α
```

`Holder` 的定义里**已经**写了 `≤ L·|x−y|^α`；`WidthCell` 的定义里**已经**写了 `|x−y| ≤ w`。
「证明」只是把两句拼起来，**换了个符号**。

**与项目审计已命名的 `P3` 模式（前提即结论 / 定义展开）完全同类。**

> ⚠ **这是本项目第二次出现同一模式**（第一次在旧代码里被审计抓到，这次由我自己重犯）。
> 它不是笔误，是**「用形式化掩盖缺乏内容」**的稳定倾向，必须靠门禁而非自觉来防。

### 2.2 方法上是循环论证

α 的实测值（0.280 / 1.007 / 0.601）**来自同一批数据**。
再用这个 α 去给同一批数据算「需要多少分辨率」——**用估计结果证明估计可行**。

换掉的只是那个「1」，**循环还在**。

## 三、这条失败暴露的真问题

| 原设想 | 实际 |
|---|---|
| α=1 不对 → 换成实测 α 就修好 | ❌ 换 α 只是把假设**参数化**，假设没被消除 |
| Hölder 是 Lipschitz 的泛化 → 更强 | ❌ 泛化的是**假设**（更弱）与**结论**（更弱），净信息量为零 |
| 压界能救回 P1（有效性） | ❌ 救不回——**有效性不是被 α 的取值破坏的，是被「α 只能从数据估」破坏的** |

**⟹ D-020 的否定性结论因此被**加强**，而不是被绕过。**

> **只要平滑度参数只能从「待预算的那批数据」里估计，几何界就不能被读懂为分辨率预算。**
> 这一条不是换指数能解决的。

---

## 四、若将来再试，必须满足其中之一

| # | 条件 | 为什么才有内容 |
|---|---|---|
| 1 | α 来自**独立于待预算数据**的机制（物理先验 / 另一批独立样本） | 打断循环 |
| 2 | 不用平滑度假设，改用**不依赖 α** 的界（minimax 下界、分布假设下的期望误差） | 假设换成可检验的 |
| 3 | 把「预算」改成**事后校验**（先定 n，再用留出数据检验误差 ≈ σ） | 不做预测性循环 |

**这三条都不是「压界」，是换问题。** 已写进存档 README，防止再走一遍。
