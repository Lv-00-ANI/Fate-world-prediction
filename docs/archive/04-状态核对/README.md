## ⭐ 状态冲突 #9 · 「图→概率被证伪」的真实射程（2026-10-29 核实）

### 记录的说法

### 核实结果：**在"未归一化"口径下成立；在"概率"口径下不成立**

| 事实 | 证据 |
|---|---|
| `LMG` 的定义**不含归一化假设**（没有 `∑ p = 1` 前件） | `FactorRecursionRouteB.lean:156`：`def LMG (p : (V → α) → ℝ) (G : DAG V) : Prop := ∀ v, ∀ x, p x * mass (nd ∪ pa') p x = mass (insert v …) …` |
| 反例 `colliderP` 的**总质量 = 4**（不是 1） | `FactorizesNotImpliesLMG.lean:56-75`：`colliderP w = if w 0 = w 2 then 1 else 0`；`Fin 3 → Bool` 共 8 个赋值，其中 `w0 = w2` 有 4 个 ⟹ `∑ = 4` |
| 于是 `p x = 1`、`mass {2} = 2`、`mass {0,2} = 2`，LMG 断言 `1·2 = 2·2` 即 `2 = 4` | 同上 `:78-98` |

### 结论修正

| 命题 | 状态 |
