# 06-项目链 · 预测系统的全部候选形态与可拼装环节

> **本文件夹回答一个问题**：《命运》项目里被设计成「一个预测系统」的东西，**到底有几种形态？每一种由哪些环节组成？**
>
> 不产出结论，只产出**可选择的材料**。最后由作者挑一条，或改一条。

---

## 一、做到哪一步了

| 阶段 | 做了什么 | 产出 |
|---|---|---|
| **① 侦察** | 8 路并行，各自从一类素材里枚举「系统形态」 | `_侦察/F*.md`（8 份，共 **~174 条候选**） |
| **② 拆环节** | 把候选按语义归成 8 个环节族，逐族拆出**最小可组合环节** | `环节池/F1…F8.md`（8 份，共 **247 个环节**） |
| **③ 去重** | 跨族合并同义环节（各族自己上报的重叠） | `环节池-最终.csv` / `.md`（**240 个环节**） |

**为什么最终给「环节」而不是「链」**：
同一条链在不同素材里的差异，**90% 是环节的取舍不同**，不是环节本身不同。
把环节拆到最小再去重，剩下的差异才是真正的设计分歧——这时你看到的每条链，都是「同样的积木、不同的搭法」。

## 三、怎么用（拼链流程）

```
1. 打开 环节池-最终.md，找到「T1 原始数据」作为输入的环节
2. 看它的输出类型（T2/T3/T4/…）
3. 找「输入类型 = 上一步输出」的环节
4. 重复，直到抵达 T9 预测分布 或 T12 干预方案
5. 找不到匹配 → 那里就是断点
```

**类型词汇见 [`环节接口约定.md`](环节接口约定.md)**（T1–T17）。

> **⚠ 类型标注不全（如实登记）**：240 个环节里，**82 个**有子代理明确写出的 T 码（显式），
> **66 个**由关键词推断（`输入T`/`输出T` 可能不准），**93 个**没有类型标注。
> CSV 的 `类型来源` 列区分「显式 / 推断 / 空」——**拼链时请优先信「显式」，推断的要回看 `输入`/`输出` 原文**。

**排序建议**：先按状态过滤。
- 只想要「能跑」的链 → 只用 `已实现`
- 想要「理论完整」的链 → 允许 `部分` + `仅文档`，但把 `缺失` 标出来
- 想要「曾经有过」的链 → 把 `被推翻` 也拉进来（但要知道为什么被推翻）

## 四、拼接时必然撞上的 7 个断点

这些不是猜测，是被子代理实测确认的**类型对不上**处：

| 断点 | 上游输出 | 下游输入 | 缺什么 |
|---|---|---|---|
| **观测 → 状态** | T1 原始数据 | T3 轨迹 | `h` 的估计器零实现；A14 取无损分支则「命运」不可观测 |
| **实例 → 规则** | T4 实例集 | T7 规则集 | `α` 的**完整实例从未有过**（净版自评「至少一个完整实例——无」） |
| **规则 → 预测** | T7 规则集 | T9 预测分布 | `Comp`/`pow` → `Pred` **零行**（`Pred` 全库仅 3 处：定义 + 2 处文档） |
| **图 → 概率** | T14 因果图 | T9 预测分布 | 桥基本不存在（全库仅 0.84% 定理同时含图与概率） |
| **σ → 误差** | — | T10 误差剖面 | σ 不可识别；`err` 是抽象参数，无字段接到 `Frame`/`Step` |
| **残差 → 参数** | T10 误差剖面 | T13 参数 | 回写**算子**已实现（`writeBack`），但**主循环未消费** |
| **场景树 → 干预** | T11 场景树 | T12 干预方案 | 类型链完整，但承重前件 `FaithfulSim` 全库**无一处证明**；且选出方案无回流边 |

## 七、几条会被反复用到的结构性事实

1. **「一次预测」在两条互不相通的轨道上**：点预测走 `predFrom`（`EndToEnd.lean:144`），分布预测走 `xNextDist`（`TrajGenStochastic.lean:113`）；`Pred`（`Frame.lean:782`）零调用。两者无一条定理相连。
2. **唯一从头到尾跑得通的链是点预测链**：`observe → predFrom → e2eResidual → writeBack`，但它输出的是 **θ′（参数），不是预测值**。
3. **`∘` 与 `pow` 是全项目最硬的一块真内容**：`comp_assoc` / `comp_idRule` / `idRule_comp` / `pow_add` 无条件真；但 `pow` 零外部消费者。
4. **「规则→预测」不是没做，是已被证明为假**：`EndToEndWithRulesNegative.lean` 给出 7 条否定结果（`Rules` 类型里没有 θ 位）。
5. **因果层有三个互斥开关同时有效**（旁路 / 并行来源 / 主链一环），无任何文档宣布另两档作废。
6. **误差层「一条界也没有」但「边界结构很硬」**：`FitBoundary` 41 定理全真证（存在性、唯一性、两条不存在判据、分离定理），而 E1–E8 一条界都没有。
