#### 候选 1 —「实例 → 规则 → 预测」单主线，因果置旁路（裁决 A 款）

- **一句话**：整条系统只有一个方向——实例抽象出规则，规则演化，规则出预测；因果层不在这条链上。
- **输入 → 输出**：输入 = 实例/数据集合 ℰ；输出 = 演化后的规则集，以及由规则给出的点预测/轨迹 `{x_t}`。
- **部件链路**：
  1. 实例集 ℰ（原始数据，唯一的规则来源）
  2. `α` 抽象算子：ℰ → ℛ
  3. 规则空间 ℛ
  4. `γ, π, υ` 三个演化算子（规则集的生长/精化/完善）
  5. 演化后的规则集
  6. 预测（点预测）
- **结构差异**：唯一一条主线；「`SCM → 规则`」这条边被**明令废止**；因果不进必需链路，只作机制解释/反事实的旁挂件。与候选 2（两源）、候选 5（闭环）、候选 15（按目标切换）**结构性互斥**。

#### 候选 5 —因果 × 分类的「抽象—解构」闭环（裁决 O 款）

- **一句话**：因果结构**直接进入**分类系统的循环去提取关系与规则；循环向上抽象、向下解构，永不终止，只在「信息不足、继续会过拟合」时临时停。
- **输入 → 输出**：输入 = 持续注入的新信息/实例流；输出 = **每一轮**的关系与规则（+ 更新的分类），以及一个「临时停止点」。
- **部件链路**：
  1. 持续注入的信息
  2. 分类系统（要素/概念、属性、对象划分）
  3. 提取关系与规则
  4. 因果结构修正
  5. **回灌**步骤 2（闭环）
  6. 每轮产出规则集；停止判据 = 裁决 K（信息不足 → 继续会过拟合 → 临时停）

#### 候选 6 —α 双输出（θ + R_θ）与观测核预测（裁决 J 款）

- **一句话**：同一抽象过程分出两路——**全局参数 θ** 与**以 θ 为参数的局部规则族 R_θ**；预测走 R_θ 的观测核，不走状态机制 f。
- **输入 → 输出**：输入 = 实例集 ℰ；输出 = **输出空间 Y 上的预测分布**（`y_t` 的分布，不是 `x_t`）。
- **部件链路**：
  1. 实例集 ℰ
  2. `α_θ` → θ（全局、无上下文；「慢」= 在样本上取常值，`ThetaStableOn`）
  3. `α_R` → R_θ（局部、带上下文 `c`；核 `C × X → Measure Y`）
  4. R_θ 吃 `(θ, c, x)` → `Measure Y`
  5. 观测 `y = h(x)`（Y 是输出/观测空间，不是状态空间）
- **结构差异**：**R 与 f 不同型**——f 产状态、R 产观测；θ 必须进 R，否则「命影响命运」只在解释层成立。这是唯一显式处理「预测对象是观测量而非状态量」的款。

#### 候选 16 —可干预式世界模型三层：`υ` × 反事实 × 优化

- **一句话**：系统 = 信息持续注入（`υ` 更新规则集）× 同外生 `u` 下换干预的分支模拟 × 在分支上择优的干预选择。

- **部件链路**：
  1. 历史 / 数据
  2. ① 信息注入：`υ`（完善算子）用新数据更新规则集

#### 候选 17 —规则全参与 + 动态激活 → 场景树 → `Policy`

- **一句话**：规则不是被「选一条」，而是**全部参与**（`∘ = 取交`），按数据失活/激活并经依赖闭包连锁复活；再由「规则 + 数据」展开场景树，最后由 `Policy` 在树上选动作。
- **输入 → 输出**：输入 = 规则集（初始全激活）+ 实际数据 `(x_t, u_t, θ)`；输出 = 场景树 + 选中的行为 `a`。
- **部件链路**：
  1. 规则集（**全参与**，`compose R₁ R₂ := fun c x => R₁ c x ∩ R₂ c x`）
  2. 动态激活（数据进来 → 部分规则不适用 → 失活；某激活规则依赖某失活规则 → **立刻重新激活** → 连锁）
  3. 场景树（`a` 多场景展开 → `b` 择优 → `c` 细化）
  4. `Policy.choose : ScenarioTree → Act.Carrier`
  5. 干预 `a`
- **结构差异**：与「从规则集挑一条」的 `Selector` **直接矛盾**（作者原话否定了这个理解）；并把因果层的 `Trunc`（沿 edge 向上闭包）与规则层的激活闭包视为**同一结构**。这是全案唯一给出「模拟」具体算法的款。
- **证据**：
  - `命运-实现/O7-世界模型完整规格.md:4-7`（作者原话四句：「干预是根据规则然后待人实际情况的数据模拟出整个情况进行一些行为作为干预」「不可能只有一条规则啊，规则是全参与的」「开始的时候全部规则都激活……用到的其他未激活规则可以立刻激活」「规则间依赖：两者都要」）
  - `命运-实现/O7-世界模型完整规格.md:24-31`（「全参与」vs「选一条」对照表）
  - `命运-实现/O7-世界模型完整规格.md:49-57`（规则→数据→模拟→干预 四步链）
