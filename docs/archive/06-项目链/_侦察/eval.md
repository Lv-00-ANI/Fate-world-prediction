## 〇、先给结论：20 个候选，分属 6 个结构家族

材料里的「预测系统」不是一个方案，而是**六种互不相同的结构家族**，彼此不是措辞差异，而是**部件表和拓扑不同**：

| 家族 | 核心结构差异 | 候选编号 |
|---|---|---|
| **A · 规则核链**（FCA/规则作主线入口，核复合出预测） | 预测 = 条件分布核的 n 次幂；误差在最后接 | 1, 2, 3, 4, 6, 9, 10, 11, 12, 15 |
| **B · 误差链优先**（先把 ε→预测误差接通，规则可后置） | 预测链退居第二，交付物是「界 + 可接受判定」 | 7, 8, 14 |
| **C · 标准自回归 + 区间**（放弃符号内核，只留「理论给的映射」） | `x_{t+1}=f(x_t,u_t,ε_t;θ,a_t)` 直接接 LightGBM/ARIMA + 共形区间；FCA 或被砍或降为特征 | 13, 14 |
| **D · 世界模型骨架（代码里真的存在的那一套）** | 状态/规则集/模拟器/选择器四组件 + 残差回写；输出是「参数收敛」而非「预测值」 | 17, 18, 19, 20 |
| **E · 要件/门槛型标尺**（不是实现，而是「必须具备哪些部件」） | 五要件 / 五层 / 三通道门槛 | 4, 5, 16 |
| **F · 因果位置之争**（同一链条里 SCM 在上游、在旁路、还是在循环里） | 结构差异只在「因果是否在必经链路」 | 1, 2, 3, 19 |

**一句话总判**：二十个候选里，**只有 17/18/19/20 有代码，其余全是文档级设计**；而四个有代码的候选，**没有一个是「输入一段序列 → 输出一个预测值 + 一个可核对的误差」**——17 的链条有 4 处断点，18 只在一维线性 `h=id` 下成立，19 输出的是「干预律=推进步」这条等式而非预测，20 的选择算子 `Classical.choose` 不可执行。

## 二、逐条详解

### 候选 1 · 主线八段链（因果上游 + 预测终点 + 闭环回修因果）

- **一句话**：把「命运」写成一条八段流水线——SCM/do 算子 → d-分离 → 后门/前门/do-calculus → 实例抽规则 α → 规则集运算 γ/∘/υ → **规则集→预测** → 误差界 → 分类反过来修因果；这是 `路线图-权威版 §2.1` 的「权威拓扑」，被 D4 用作度量主线贯通度的骨架。
- **输入 → 输出**：输入 = 实例/数据 + 一个 SCM（因果图）；输出 = 一个预测值 +（本应附带的）误差界。
- **部件链路（数据流序）**：
  1. S1 因果：SCM 定义与 do 算子
  2. S2 d-分离 → 条件独立（Pearl 1.2.4）
  3. S3 后门/前门/do-calculus 三规则
  4. S4 实例 →(α) 规则
  5. S5 规则 →(γ,∘,υ) 规则集
  6. S6 规则集 → 预测
  7. S7 误差界（ε_t → 可测误差）
  8. S8 分类 → 反过来修因果（裁决 O 闭环）
- **每一步算什么**：S1–S3 算「因果量」；S4 算「从实例集合到条件分布核的抽象」；S5 算「核复合/泛化/完善」；S6 算「把规则集变成下一步的分布」；S7 算「误差从哪来、放大多少」；S8 算「把分类结果回写成因果结构的修正」。
- **与其它候选的关键区别**：**唯一一个把因果放在「预测上游的必经链路」的完整八段链**，且**唯一一个把「分类反修因果」画成闭合回边**。与候选 2 正好相反（因果旁路），与候选 19 的差别在于 19 只做「SCM→WorldModel」这一桥，不接规则与预测。
- **实测状态**：S6 = 0（全库无「规则集 ⇒ 预测值」定理）、S8 = 0、S7 = 0.5（形式齐、Lean 零证）；因果侧 2.5/4 = 62.5%，预测侧 1/4 = 25%。
- **证据**：`02-分项报告/D4-完成度框架.md:167-173`（拓扑图）；`:175-181`（0/0.5/1 判据）；`:192-208`（八段打分表，S6/S8 为 0）；`:207`（因果侧/预测侧拆分）。

### 候选 2 · 因果旁路化的四段链（作者的裁决版）

- **一句话**：把候选 1 的前三段整体拿掉，只留「规则入口 → 预测闭环 → 误差界」，因果降为**不参与点预测必需链路的旁路/可选层**；D1 进一步把执行顺序改写为「预测系统最小闭环 → 误差界 → 规则入口（FCA/混合）→ 因果旁路化」。
- **输入 → 输出**：输入 = 一段序列数据（不需要 SCM）；输出 = 预测值 + 误差界；因果只作为「机制解释与反事实」的旁挂查询通道。
- **部件链路**：
  1. 规则入口（FCA / FCA×SCM 混合）——从实例抽规则
  2. 预测闭环（规则集 → 预测 → 残差 → 回写）
  3. 误差界（13 条界中的可用者）
  4. 因果旁路（机制解释 / 反事实，不在主链）
- **与其它候选的关键区别**：**结构上把「因果」从必经链路里删除**——这是全部 20 个候选里唯一由作者本人裁决过的拓扑（裁决 A：「`SCM → 规则` 这条边**废止**」）。与候选 1 是同一个系统的两种拓扑，**不是措辞差异**：一个要求先有 SCM，一个明确不需要。

### 候选 3 · 裁决 O 的「因果 ↔ 分类」循环

- **一句话**：因果不是上游也不是旁路，而是**直接进入分类系统的循环**——用因果去驱动规则/关系的循环提取，再把分类结果回写修因果；循环的动作是「抽象与解构」，不是「细分」。
- **输入 → 输出**：输入 = SCM + 实例集合；输出 = 规则集 + 被修正的因果结构（而不是单个预测值）。
- **部件链路**：
  1. SCM / 因果图（入）
  2. 分类系统（FCA 概念格）
  3. 循环提取「关系 + 规则」
  4. 规则集
  5. 回写：分类结果反过来修因果（闭环）
- **每一步算什么**：2 算概念格；3 算「关系/规则的循环抽象」；5 算「用分类结论修订因果边」。
- **与其它候选的关键区别**：**它是候选 1 的第 8 段被单独提出来当一个系统**；与候选 19（SCM→WorldModel 桥）的差别是：19 是一次性构造 + 一条等式定理，3 是**迭代循环**（提取 → 回写 → 再提取）。

### 候选 4 · E1 五层预测栈（状态 → 机制 → 规则核 → 误差 → 闭环）

- **一句话**：按「预测系统」而不是按「理论章节」切五层——①状态与轨迹（含观测模型）②机制/动力学 `x_{t+1}=f(x_t,u_t,ε_t;θ,a_t)` ③规则层（条件分布核 + α/γ/∘/υ）④误差层（八类误差 + 13 条界）⑤闭环（υ 更新规则）。
- **输入 → 输出**：输入 = 状态轨迹 `{x_t}`（A14 假设可直接获取）；输出 = 条件分布 `P(x_{t+1}|x_t)`（定义 7.1 的 φ），外加一层误差界（形式上有、证明为空）。
- **部件链路**：
  1. 状态与轨迹（`StateSpace` + `trajectory` 递推 + 观测模型 `y_t=h(x_t)+η_t`）
  2. 机制/动力学（`f`、SDE、Euler–Maruyama 离散化、θ=命）
  3. 规则层（`MeasurableRule` 核、`comp` 马尔可夫核复合、`pow`、α/γ/υ）
  4. 误差层（`ErrProfileWeak`/`IsFitBoundary`、八类误差、13 条界）
  5. 闭环（`UpsilonOperator` 闭包算子 + `MainLoop`）
- **每一步算什么**：1 定状态空间与轨迹存在唯一；2 定一步推进；3 把「规则」变成可复合的核并组合；4 给误差剖面与拟合边界；5 按 `R_{t+1}=υ(R_t,Data_t)` 更新规则。
- **与其它候选的关键区别**：**唯一以「层」为单位的系统分解，且误差层与规则层并列**（不是「误差是预测的附属」，而是独立一层）。与候选 5 的差别：5 按「能力」切（表征/动力学/预测/决策/闭环），4 按「数据类型」切（状态/机制/规则/误差/闭环）——**同一个系统的两种粒度，不是同一个东西的倍乘**。
- **实测状态**：五层加权 ≈27%，「能做出一次预测」<5%；其中层 3 的 `comp` 是真的（`ComposeOperator.lean:383`、`comp_kernel_apply`），但 `Pred` 是从未被调用的 `abbrev`（`Frame.lean:782`）。
- **证据**：`02-分项报告/E1-预测系统五层评估.md:24-30`（五层表）；`:96-105`（输出形式是分布、无区间、无 n 步定理）；`:32-33`（加权 27% / <5%）。
- **成熟度**：只有骨架（层 1、3 有 Lean 类型；层 2 的 `f` 无估计；层 4、5 无证明）。

### 候选 5 · Dreamer/JEPA 五要件世界模型（作为标尺的设计）

- **一句话**：用真实世界模型的标准分解「表征 → 动力学 → 预测 → 决策 → 闭环」来定义系统应有哪些部件，及格线是 ①+②+③（表征学会、动力学可滚、预测能测误差）。

- **部件链路**：

### 候选 6 · E1 的 S1–S4 最小接线（<350 行换「第一次能预测」）

- **一句话**：不动因果、不证 115 条定理，只做四件事把「规则 → 单步/多步预测」接上并喂一个真数字：`R.predStep x := R.kernel c x` + 证 `n 步 = R^{∘n}`；给 α 一个 3×3 形式背景的真实实例；把 `h, η_t` 落进 Lean；把真实 `err` 喂进 `FitBoundary`。

- **部件链路**：

### 候选 17 · WorldModel 四组件 + ObsEstimation + writeBack 闭环（代码里真实存在的那一套）

- **一句话**：`WorldModel` 是一个四组件复合类型（状态 `W.state` / 规则集 `W.rules` / 模拟器 `W.simulator` = `sim` / 选择器 `W.selector`），数据流是「观测 y_t →（ObsEstimation）→ 状态估计 x̂_t →（WorldModel.sim）→ 预测 x̂_{t+1} →（predicted）→ 与真实比较 → 残差 r_t →（writeBack）→ 更新 θ → 回到第一步」。
- **输入 → 输出**：输入 = 观测序列 `y_t` + 外生 `u` + 噪声 `ε` + 动作 `a`；输出 = 预测 `x̂_{t+1}` + 更新后的 θ（系统的交付物实际是「收敛的参数」而不是「一次预测」）。
- **部件链路**：
  1. `ObsEstimationStrong`：`h x' = h x + η`、`‖η‖ ≤ ηmax ⟹ dist x' x ≤ L·ηmax`
  2. `WorldModel.sim`：`trajGen` 正向迭代（读 `W.state.initial`，**不读 x̂**）
  3. `predicted W … n := W.sim … (n+1)`
  4. 残差 `residual x (predicted …)`
  5. `writeBack Θ η φ r θ := θ + η * φ r`（`ResidualLoop`）/ `writeBackL` + `errL`（`ResidualReduces`）
  6. 回到 2
- **每一步算什么**：1 算状态估计误差界；2 算轨迹；3 取下一步；4 算残差；5 算参数修正；6 迭代。
- **与其它候选的关键区别**：**唯一有真实 Lean 代码、且有「闭环会变好」定理的候选**（`writeBack_reduces_error`：严格下降；`reduces_iff_window`：下降 ⟺ `|1−η|<1`；紧性与下界齐全）。与候选 18 的差别：17 走 `WorldModel.sim`（不吃 x̂），18 走 `pipelineStep`（吃观测、含估计环）。
- **实测断点（4 处）**：①→② 断（`ObsEstimation*` 不在构建图、0 模块引用）；② 类型可通但 `sim` 无字段接受 x̂；⑥ 不存在（无定理说「θ 更新后预测更准」——K2 时点；M1 时点已被 `ResidualReduces` 补上）。
- **证据**：`_归档/04-最新核实/K2-世界模型线深度评估.md:329-344`（完整数据流 + 逐环节断点表）；`:22-28`（五要件判定：类型层全有、数值层全无）；`:36-86`（`ResidualLoop` 探针判定：内容在前提）；`:382-386`（离「带误差带的一次预测」还差 5 步）；`:90-126`（`ObsEstimationStrong` 是真数学但走失）。
- **成熟度**：完整定义+代码。

### 候选 18 · M1 六环 `pipelineStep`（观测→估计→预测→残差→更新→收敛）

- **一句话**：把上面那条链压成**一步六环复合** `pipelineStep`，主定理 `pipeline_tendsto` 证明 θ 收敛到 θ*，并有闭式 `θ_n − θ* = (1−η)^n (θ_0 − θ*)`；成立条件被压到最简：一维线性 `linWorld`（机制 `θ*x`）、`h=id`、`x≠0`、`|1−η|<1`。
- **输入 → 输出**：输入 = 观测（`h=id` 时即状态）+ 初始 θ₀ + 收缩因子 η；输出 = 收敛的 θ* + 闭式误差 `(1−η)^n(θ₀−θ*)`。
- **部件链路**：
  1. ①观测
  2. ②估计（`h=id` 时退化为恒等）
  3. ③预测（`linWorld`：`θ*x`）
  4. ④残差
  5. ⑤更新（`writeBack`，η 为步长）
  6. ⑥收敛（`pipeline_tendsto` / `pipelineN_closed` / `pipeline_tendsto_unique`）
- **每一步算什么**：1–2 拿状态；3 算一步；4 算差；5 按 `|1−η|` 收缩；6 证极限与唯一性。
- **与其它候选的关键区别**：**唯一有「端到端收敛定理」的候选**——但只在「一维线性 + 无噪观测」上成立；`WorldModelCapstone` 自己声明学习链与闭环链**不是同一条链的同构**，只共享收缩因子 `c(η)=|1−η|`。
- **证据**：`_归档/05-全景清点P1-P10/M1-世界模型全面评估.md:68-91`（六环定义 + 三个限定）；`:143-157`（逐环节状态 + 端到端成立的四条件）；`:163-172`（Capstone 自述两条链不同构）；`:114`（端到端收敛 60%，一维线性特例）。
- **成熟度**：完整定义+代码。

## 四、共性：二十个候选里没有任何一个能同时满足的四件事
