## 0 · 一页纸：19 条候选的族谱

材料里其实同时活着**五种互不兼容的「系统主句」**：

| 族 | 主句 | 候选编号 |
|---|---|---|
| **A 闭环族** | 系统 = 一个**带残差回写的闭环预测器**（观测→估计→模拟→预测→残差→回写） | 1、9、11、19 |
| **B 规则族** | 系统 = 一条**规则驱动链**（数据→α→规则→Step→动力学→预测），因果不进主线 | 2、3、5、13、16 |
| **C 因果族** | 系统 = **SCM 的三层级**（关联/干预/反事实），世界模型是它的实现 | 4、6 |
| **D 记账族** | 系统 = 一张**边界表 / 判定矩阵**，产出不是预测值而是「每条结论依赖哪条假设」 | 7、8 |
| **E 审计族（元层，非预测链）** | 系统 = 一套**闸门 + 台账**，先修「判定工具」再谈预测 | 17、18 |
| （跨族） | 系统的**评价口径**：界+紧+下界 × 载体一般 | 14、15 |

一句话观察：**A 族的「图」和 B 族的「文字声明」在流程图里被强行接成一条链，而 R2 内核图把因果画成旁路、R3 规划把「装端到端」列为最高价值——三份规划对「主干是什么」给出的答案互不相同。**

## 候选 1 · 残差回写六环闭环预测器

- **一句话**：整台机器就是一个「预测 → 与真实比 → 用残差改参数 → 再预测」的**闭环控制回路**，外加一个在候选干预里择优的决策出口；它的卖点不是预测更准，而是**每个环节都有可证明的界**。
- **输入**：真实世界观测序列 `y = h(x) + η`（加上初始参数 θ、外生输入 u、噪声 ε）。
- **输出**：下一步预测 `x̂_{t+1}` + 一个干预方案；**设计上还应有误差带，但实际输出端是空的**。
- **部件链路**：
  1. `观测模型`：`y = h(x) + η`（`ObsEstimationStrong` / `ObsErrorRandom` / `ObsEstSharp`）
  2. `观测估计`：由 y 反推状态 `x̂`（`estimator_error_bound`，误差 ≤ L·ηmax）
  3. `动力学模拟`：`WorldModel.simulate` = 规则驱动的 Step 迭代（`sim_zero` / `sim_succ`）
  4. `一步预测`：`ResidualLoop.predicted`（实为 `sim_succ` 的转录）
  5. `残差`：`r = x − x̂`
  6. `参数回写`：`writeBack`，`writeBack_reduces_error`（严格下降）、`reduces_iff_window`（充要 η∈(0,2)）
  7. `闭环收敛`：`pipeline_tendsto_gen`（任意完备赋范空间 V）
  8. `决策出口`：多分支场景树 `ScenarioTree` → 干预选择 `bestScoreSup = tree.sup'`
- **与其它候选的关键区别**：唯一一条把**残差回写**（学习）放进系统的候选；其余候选要么只到「预测」，要么只到「择优」，都不含参数更新回路。也是唯一一条把「输出端」画成独立节点（且标注为空）的候选。
- **证据**：
  - `流程图:27-38`：「落到代码上，这个系统是一个**带残差回写的闭环预测器**」+ 8 行箭头伪码（真实世界→观测估计→simulate→预测→残差→writeBack→循环→择优）
  - `流程图:40-48`：「它的独特定位不是「预测更准」，而是「每个环节都有可证明的界」」+ 界/紧/下界三判据表
  - `流程图:90-108`：图 1 的边集（DATA→ALPHA→…→RDE→SIM；OBSM→OBSEST→SIM；SIM→PRED→RES→WB→CONV→SIM；PRED→SCEN→SEL→OUT）
  - `流程图:121-145`：逐环节的模块/定理/行数表（`ObsEstimationStrong` 664 行 26 定理…`InterventionTight` 384 行 24 定理）
  - `流程图:147-152`：三个缺口（真实数据 0 / 输出端不存在 / 场景树不是反事实树）
  - `全景:1533-1549`：世界模型线待做总表（W7 `pipeline_error_band` 端到端误差带）
- **成熟度**：**完整定义+代码**。每个环节都有具名模块与定理；缺的是「装到一起」（R3 判端到端串联 0%）。用 `流程图:52` 的话：九要件 7 项到极限、1 项部分、1 项不可证。
- **备注（冲突）**：`流程图:8` 自我修正过一版——v1 把世界模型画成**独立于规则**的链路是错的，v2 把规则层放回主链。所以「六环」与「规则族」在图上已经并成一条；但两组文档对「规则层是前置还是并列」仍不一致。

## 候选 2 · 规则即动力学的三段桥（LawDetToStepGen → RuleEntersWorldModel → RuleDrivesEndToEnd）

- **一句话**：世界模型的 `simulate` 不能自己定义动力学，必须由**规则**翻译成 Step 再迭代轨迹；系统的主干因此是「规则 → Step → 轨迹 → 主链」三段桥。
- **输入**：规则集 `RichLaw / LawRule`（点质量/Dirichlet 型规则）+ 上下文 `CtxSpace`。
- **输出**：规则驱动的轨迹生成器 `trajGen`，等于 `trajOfRichLaw`；下游即世界模型 `simulate`。
- **部件链路**：

- **与其它候选的关键区别**：候选 1 里 `simulate` 是一个**自由字段**；这条候选把它约束成「规则导出」。它回答的是「动力学从哪来」，不是「误差怎么控」。与候选 3 的区别：候选 3 覆盖到数据入口 α 与末段轨迹输出，本候选只覆盖「规则如何进入世界模型」这一段内部接口。

## 候选 4 · SCM 构造世界模型（干预律 = 推进步）

## 候选 5 · 因果降旁路：规则→预测主线 + 可选 SCM 附件

- **一句话**：系统主干是「对象层 → 机制层 → 规则层 → 预测」，因果层是**挂在旁边的可选层**，只在解释/政策/干预设计/反事实时才接上；层与层之间有三条明确登记的空缝。
- **输入**：唯一原始对象 `O`（任意有状态系统）+ 参数 `θ`（命）+ 外生 `(u_t, ε_t)`（运）+ 初值 `x_0`。
- **输出**：`P(x_{t+1}|x_t)` 点预测；干预/反事实要另接因果层。
- **部件链路**（`R2内核:51-124` 的五个 subgraph 就是它的一级分解）：
  1. **对象层**：`𝒳 / x_t / 𝒯 / {x_t}=命运`、`y_t=h(x_t)+η_t`（唯一可观测）

  4. **规则层**：`ℰ →α→ ℛ →(γ,∘,υ)→`、FCA（Galois 不动点 + DG 基）、`enc: x_t ↦ (A_t,B_t)`（未定义）

- **与其它候选的关键区别**：**唯一一条显式声明「缝」的候选**——它不假装系统是连通的，而是把三处接缝（动力系统↔因果、观测分布↔轨迹、实例↔规则↔状态）当作系统的一等公民画出来。与候选 4 相反：因果在这里无专属主语，不挂在 O 上。

  - `R2内核:126-134`：三条缝的定义与判断（「凡真需要具体构造的地方，文档都退回到『登记为开放问题』……它画的是一张**接口图**，不是一张**实现图**」）
  - `R2内核:193-197`：V1（规则抽象自实例）/ V2（因果降为旁路／可选层）
  - `R2内核:253-254`：S5——该架构的代价「主线（规则→预测）与最有意思的目标（干预/反事实）在架构上被拆开了，而且没有说明怎么重新接上」

## 候选 6 · 关联 ⊂ 干预 ⊂ 反事实 的三层级（外生地位判定 + 反事实三步）

- **一句话**：系统按**三类任务**分层，判据只有一条——**预测与干预对外生分布取期望，只有反事实必须落到单个 ω 的外生实现上**；于是「反事实模块里有没有 `P(U|e)` 更新」成为可执行的判别式。
- **输入**：观测 `e`、图 `G`、外生实现 `ω`（反事实才需要）。
- **输出**：三个不可互推的层级——`P(Y|X)`（关联）/ `P(Y|do(x))`（干预）/ `Y_{X=x}(u)`（反事实）。
- **部件链路**：
  1. `关联层`：`P(V)`，图已知下的条件化
  2. `干预层`：`do(X=x)` = 删入边 + 替换为常数方程 + 其余不变（`C3`）
  3. `反事实层`：三步算法，第一步 **abduction `P(U|e)`**（不可省）
  4. 退化判据：去掉第一步 ⟹ 反事实在计算上**退化为干预**（`C4` 判据 2）
  5. 可实现性核对：`Rule13Genuine` / `Rule2Genuine`（do-calculus 三规则）、`T43Abduction`（溯因负面结论）、`T44Counterfactual.counterfactual_not_identified`

## 候选 19 · 裁决 K：误差剖面 err(γ) → 拟合边界唯一性 → σ

- **一句话**：模型选择是独立的一块：给定误差剖面 `err(γ)`，"刚好拟合/过拟合"的边界由**严格凸 + 唯一极小**保证存在且唯一，`σ` 就是那个边界值；这块的产出是**正则化强度**而不是预测。
- **输入**：误差剖面 `W : ErrProfileWeak`（`err : ℝ → ℝ`）、容差 `σ`。
- **输出**：拟合边界 `γ*`（唯一）+ `σ`（= `err γ*`，同时是全剖面下界）。
- **部件链路**：
  1. `ErrProfileWeak`（误差剖面类型）

  5. `StrictConvexOn` → `existsUnique_isFitBoundary_of_strictConvexOn`（唯一性）
  6. 反例 `strictConvex_unique_attaining_not_suffice`（严格凸+取到 ⟹ 下界，**假**）
  7. `σ` 的三条来源路径：AIC/BIC、信息增益、领域参数（**全部失败**）
- **与其它候选的关键区别**：唯一一条以**模型复杂度/正则化**为输出的候选；也是唯一一条材料自己判定「下界 = 定义投射、仍未修」的候选（⑤的 `A∧A` 同病）。
- **证据**：
