### C1 · HH2 五要件扇入装配（观测估计 → 决策稳定性 → 多分支模拟 → 干预选择最优 → 残差闭环）

- **输入**：观测 `y`（观测映射 `h`）+ 状态 `x_t`（A14 取无损分支）+ 参数 `θ`。
- **输出**：更新后的 `θ'`（残差写回）+ 每条要件的误差/稳定性界；**不输出**一次具体的预测值（无 n 步预测定理）。

### C2 · 六要件口径（HH2 五要件 + 链式误差预算 `ChainErrorBudget`）

### C4 · E1 五层（状态与轨迹 → 机制/动力学 → 规则层 → 误差层 → 闭环）

### C7 · WorldModelPipeline 六环管线（观测 → 估计 → 预测 → 残差 → 更新 → 学习）

**一句话**：Lean 里唯一一条被显式命名、且一步就是六环复合的管线：`pipelineStep = endToEnd`，主定理是「从观测出发迭代，`θ_n → θ*`」。

- **输入**：观测 `y`（`y = h x + η`，主定理取 `h = id`）+ 参数 `θ` + 外生 `u, ε` + 干预 `a` + 设计点 `x`。
- **输出**：`θ_n → θ*`（`pipeline_tendsto`）；带噪时另给估计误差界 `L·η_max`（不参与主定理）。
- **部件链路（layers，原表在 `WorldModelPipeline.lean:10-17`）**：
  1. **① 观测** `y = h x + η` — `Fate.ObsEstimationStrong`（`LipschitzInvertibleOn`、`chooseEstimator`）
  2. **② 估计** `x̂ = x̂(y)` — 同上（`chooseEstimator_apply_of`、`inverse_estimate_error`）
  3. **③ 预测** `ŷ = f(x,u,ε;θ,a)` — `Fate.WorldModelReadsTheta`（`wmStep`、`predFrom_wmWorldModel`）
  4. **④ 残差** `r = x̂_obs − x̂_pred` — `Fate.EndToEnd`（`e2eResidual`、`endToEnd_apply`）
  5. **⑤ 更新** `θ' = θ + η·φ(r)` — `Fate.EndToEnd`（`endToEnd`、`endToEnd_step_eq`）
  6. **⑥ 学习** `θ_n → θ*` — `Fate.ThetaConvergence`（`thetaN`、`linWorld_tendsto_thetaStar`、`thetaN_closed`）
- **与其它候选的关键区别**：
  - **观测环 + 估计环是分开的两环**（①→②），但主定理取 `h = id`，估计环**精确退化为恒等**（`WorldModelPipeline.lean:41-49`，自陈「这不是偷懒，裁决 Q-2 读法 (a)」）；
  - **⑥ 学习环只在 `linWorld`（`f x = θ*x`）上成立**，不声称非线性机制（`:51-54`）；
  - 与 C8 的差别：多 ① 观测与 ⑥ 学习两环；与 C1 的差别：**没有多分支模拟、没有干预选择、没有决策稳定性、没有 σ**。
  - 泛化版 `pipeline_tendsto_gen` 只泛化「更新/学习律」，明确**不**声称六环本身在一般 `V` 上成立（`PipelineTendstoGen.lean:72-78`）。

### C8 · EndToEnd 四环节链（观测 → 预测 → 残差 → 更新）

**一句话**：六环管线的前五环压成一条四环节链，三条判据（不动点 / 会动 / 分解式）证明四环真的首尾相接。

- **输入**：观测 `y`（经 `chooseEstimator` 得 `x̂_obs`）+ 世界模型 `W`（经 `W.f` 得 `x̂_pred`）+ `θ` + `u, ε, a`。
- **输出**：`θ' = θ + η·φ(x̂_obs − x̂_pred)`（一步）；`endToEndIter` 给多步。
- **部件链路（layers）**：

  2. **② 预测** — `WorldModel.WorldModel.sim` / `W.f` 的一步（`predFrom`，`predFrom_eq_sim_succ`）
  3. **③ 残差** `r = x − x̂` — `ResidualLoop.residual`（`Residual X = X.Carrier`）
  4. **④ 更新** `r ↦ θ'` — `ResidualLoop.writeBack`（`Residual X → Θ → Θ`）
- **与其它候选的关键区别**：
  - **没有学习/收敛环**（`E1.3` 自陈「不声称闭环收敛」，`:46-48`）——收敛交给 `ThetaConvergence`（C7 的⑥）；

### C9 · ChainErrorBudget 三环误差预算（估计 → 学习 → 稳态 → 预算 → 最优差距）

**一句话**：不串「部件」，只串「误差」——三环误差沿链相加成预算 `σ_total`，再由预算推出端到端最优差距上界。

- **输入**：三环各自的误差上界（`‖Ω₁‖ ≤ σ_est`、`‖Ω₂‖ ≤ σ_learn`、`‖Ω₃‖ ≤ σ_steady`），由操作者逐环验证提供。
- **输出**：`IsOptimalGap (σ_est+σ_learn+σ_steady) (εbest + ‖Ω₁+Ω₂+Ω₃‖) εbest`，即 `εbest ≤ ε ∧ ε − εbest ≤ σ_total`。
- **部件链路（layers）**：
  1. **链环 1 · 估计**：`σ_est = varOf P / n`，Gauss–Markov 下界（`est_err_ge:191`）+ 可达（`est_err_attained:199`）⟹ **紧**（`est_err_tight:210`）
  2. **链环 2 · 学习**：`σ_learn = c(η)^n · e0`（`learn_err_eq` / `learn_err_le_pow:255` / `learn_err_tendsto_zero`）
  3. **链环 3 · 稳态**：`σ_steady = d / (1 − |1−η|)`（`steady_eq` / `steady_eq_abs` / `steady_err_nonneg`）
  4. **链环 4 · 预算 → 端到端**：`chain_end_to_end_from_links:357`（主定理）、`chain_budget_tendsto_of_shrink:385`
- **与其它候选的关键区别**：
  - **显式拒绝合取**：第 200 轮已证 `assembly_no_gain`（不相交变量集的约束取合取不产生新信息），故本链用**三角不等式传播**（`ChainErrorBudget.lean:12-24`）；
  - 三环的名字是「估计/学习/稳态」，**不是**六环里的「观测/预测/残差/更新」——两套环的切法不同；
  - 自评「只有 `σ_est` 是紧的，`σ_total` 不是紧界，也不声称各环节最优同时可达」（`:86-87`）。
- **证据**：
  - `命运-实现/命运/Fate/ChainErrorBudget.lean:7-24`（四层标准第 1 层；为何不是合取）
  - `命运-实现/命运/Fate/ChainErrorBudget.lean:118-138`（`ChainBudget` 四字段 + `consistent`）
  - `命运-实现/命运/Fate/ChainErrorBudget.lean:56-66`（链环 4 主定理与两条推论）

## 4. 去重提示（近似重复组，供后续合并）

1. **五/六/九 三套要件**（C1、C2、C3）：同一批模块的三种切法；C2 = C1 + 一件，C3 = C1 换名 3 项 + 增补 4 项。换算表只有 C1↔C3（`FIVE-1:72-90`）。
2. **五层 vs 世界模型五要件**（C4、C5）：都来自 E1，但 C4 是「本项目分层评估」、C5 是「外部标准当尺子」；C4 有规则层、C5 有表征层与决策层。
3. **四环节 / 六环 / 七环节**（C8、C7、C11）：C8 ⊂ C7（C7 = C8 + ①观测 + ⑥学习）；C11 是另一种切法（把 γ/∘/υ 拆成三件、把因果与 σ 加进来），**不是 C7 的超集**。
4. **五要件 vs 六环**（C1、C7）：五要件没有「学习/收敛」件，六环没有「决策稳定性/多分支/干预选择/残差闭环成件」——两者交叉而不包含。
5. **误差链两处**（C2 的 ⑥ 与 C9）：C9 ⊂ C2（C2 = 五要件 + C9 这一件）。
6. **主链 vs 六环**（C13、C7）：C13 从**转移对**起、必经 **FCA 数据**；C7 从**观测 `y`** 起、完全不经 FCA。**这两条是全清单里结构差异最大的一对**。
7. **合取总装 vs 计算链大定理**（C14、C15）：同一裁决（E3）的 A/B 两种读法，输出形态根本不同（合取命题 vs 存在量+上界）。

## 5. 本视角下「三套口径」的一句话结论

- **五要件**是**唯一在源码里有落点**的要件清单（五组模块全部编译入库）。
- **九要件**是**外部标尺**，源码 0 处定义；它与五要件的差别不是「多了 4 项」，而是**多了因果（⑧）与 σ（⑨）两类完全不同性质的部件**。
- **五层**是**系统层分解**（状态/机制/规则/误差/闭环），它把「误差」提成独立层、把「表征」提成独立层，但**整个不含因果**。
- 三套口径**不能互相换算**：只有五↔九有官方换算表；五↔五层在材料中**没有**任何换算，只能按字面对齐。
