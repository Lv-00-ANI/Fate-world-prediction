### 候选 3　规则学习 ERM 实例化 (H,L,Ω) → R̂*(S)

**一句话**：把候选 2 里那个只有签名、没有构造的 α，用一个「假设空间＋损失＋正则」的经验风险最小化问题补成一条可执行路径。

- **输入**：S、假设空间 H⊆R、损失泛函 L: Y×Δ(Y)→ℝ≥0、正则泛函 Ω: H→ℝ≥0、λ≥0（`净版:1349-1354`）。
- **输出**：R̂*(S) := argmin_{R∈H} E_{P̂_S}[L(y,R(·∣x,c))] + λΩ(R)（`净版:1354`）。
- **部件链路**：`定义 2.9.1`（问题三元组）→ `假设 2.9.1` H⊆R（`净版:1369`）→ `假设 2.9.2` argmin 取到（`净版:1375`）→ `命题 2.9.1` α_(H,L,Ω) 是 α 的一个实例化（`净版:1401-1407`）。
- **与其它候选的区别**：① 它是全理论**唯一**具有「问题形态」（一个优化问题）的入口（`净版:1347` 明写「这是源材料中唯一具有问题形态的陈述」）；② 它把 H 取**包含于** R 而非**等于** R，理由是等号形式会预设一个本理论尚未证明存在的拓扑（`净版:1372`）；③ 它显式禁止 Ω 取描述长度（`命题 2.9.2`，`净版:1420`），否则会与「抽象要求解码器不存在」构成同型矛盾。
- **证据**：`净版:1349`、`净版:1369`、`净版:1401`、`净版:1420`、`净版:1372`。
- **成熟度**：完整定义仅文档。

### 候选 5　双抽象算子并行（α 出规则 / β 出因果）

**一句话**：规则与因果是**两个独立的抽象算子**，定义域相同（实例集）但靶空间不同、语义不同（观察语义 vs 干预语义），互不定义。

- **输入**：同一 ℰ_inst 的有限子集。
- **输出**：两个并行产物——规则 R（观察）与因果结构空间 ℭ 的元素（干预）。
- **部件链路**：`裁决 B`（`净版:579`）→ `定义 2.5` β: 𝒫_fin(ℰ_inst)→𝒢（`净版:726-728`）→ `定义 3.1` β: 𝒫_fin(ℰ)→ℭ（`净版:1555`，同一算子的两种记法）→ `命题 2.0` 二者互不定义故规则层合法（`净版:587`）→ `开放 3.76` β 的构造不可能单值给出（`净版:1566`）。

- **输出**：无判据（不可判真假）。
- **部件链路**：无（这正是问题）。
- **与其它候选的区别**：它是候选 23 的反面。被撤回的理由不是「太宽」而是「不是一个可操作的陈述，甚至不是本章可以判真假的命题——它缺少使『适用』一词有意义的判据」（`净版:4533`）；且原文自己的示例表已经暴露它不成立：量子态在测量中坍缩，与「命＝慢、难改」冲突；「想法」「语言」两行的对象边界与状态空间都给不出（`净版:4533`、`净版:4954`）。
- **证据**：`净版:4530-4533`、`净版:4954`（§7.11.4 第 1 条撤回）。
- **成熟度**：只有口号。

### 候选 27　宏观命运反馈约束微观因果（反馈环）

**一句话**：用轨迹的历史去约束因果边的强度，即 P(e_j∣e_i,{x_τ}_{τ≤t}) ≠ P(e_j∣e_i)；这会把 DAG 的单向性变成一个闭环。

- **输入**：轨迹历史 {x_τ}_{τ≤t}。
- **输出**：被轨迹修正后的因果连接强度。
- **部件链路**：`净版:477-481`（该式是「宏观命运反馈约束微观因果」的唯一形式化尝试）。
- **与其它候选的区别**：它是唯一让**轨迹层反过来作用于因果层**的设计；其余所有候选都是 ch3→ch4 单向。它同时被明确判为**不是良构命题**：e_i,e_j 的论域（事件空间？变量取值？）未定义，事件空间本身亦未构造（`开放问题 1.14`，`净版:481`）。相关地，「因果与命运互相包含」被列入作废表，理由是「因果是关系、命运是轨迹（函数），**类型不同，不可比较包含**」（`净版:469`）。
- **证据**：`净版:477-481`、`净版:469`。
- **成熟度**：只有口号（未良构）。

### 候选 28　构造体系七件套 / 公理替身八类（元层组件清单）

**一句话**：换一种回答「系统由哪些部件组成」的方式——不按层，而按「一个构造体系必须携带什么」列清单：定义、构造规则、组合规则、类型规则、等价关系、误差分析、算法；净版把它改写成「定义层＋八类公理替身」。

- **输入**：无（元层）。
- **输出**：组件清单与每一类的现状判定。
- **部件链路**：原主张七项（`净版:5053`）→ 净版拆出四类「公理替身」：类型规则、等价关系、组合规则、误差界（`净版:5079-5087`）→ 另补四类隐蔽替身：抽象算子的存在性与唯一性、规则空间的代数结构、时间尺度分离参数、过程的存在性条件（`净版:5089-5105`）→ 元规则 8.1（定义/约定的准入条件，`净版:5119-5123`）。

- **成熟度**：只有裁决片段。

## 3. 三个横向观察（供后续去重/排序用）

1. **「同一根链条被切成两半、中间不接」是这一版的系统形态特征**，不是个别缺陷。三个关键断点都被逐字登记：规则→轨迹（`净版:1240`）、等价类→具体图（`净版:1982`）、SCM→(μ,σ)（`净版:2825`）。任何试图把 v1.0 当成一条连续管线的读法都会在这三处断。
2. **候选 2 / 3 / 4 / 17 / 29 全部落在 L1**，候选 7 / 8 / 12 落在 L2，候选 21 / 22 改变的是「观测」与「定义」而非能力级；**没有一条候选落在 L3**（`命题 6.103` 的 L3 需要 P_U 的完整指定，而 `说明 7.27` 直接声明「本理论目前不具备反事实计算能力」）。这意味着：如果目标是「预测系统」，v1.0 能支撑的最强输出是 L2 的一个点估计。
3. **「挑出满足要求的一种干预」这一步在 v1.0 完全缺失**，且缺失的位置是精确的：`开放问题 6.12` 要求目标函数与约束（`净版:4433`）、`问题 4.O.5` 要求混沌控制的可行性与代价下界（`净版:2904-2906`）、`开放问题 6.1` 要求多步效应的形式化（`净版:4074`）。三处合起来正好是「模拟分支→评价→选择」的第三段。评审若要判断某个候选能否成长为目标系统，看它是否补上了这一段。
