## 0 · 一页纸：24 条候选的族谱

净版 v2.0 是一个**分层文档**，不是一条数据流。因此「这套系统长什么样」在材料里至少有六种互不相同的答案：

| 族 | 系统主句 | 候选编号 |
|---|---|---|
| **A 主线族** | 系统 = 一条**规则驱动链**：实例 →α→ 规则 →(γ,∘,υ)→ 规则集 → 预测 | 1、2、13、14 |
| **B FCA 族** | 系统 = **把状态编码成二值形式背景**，再用概念/蕴含基当规则 | 3、4、5 |
| **C 因果族** | 系统 = **SCM 三层级**（关联/干预/反事实）+ 识别 + 干预优化，或它的闭环版 | 6、7、8、9 |
| **D 模拟族** | 系统 = **一台轨迹生成器**（迭代 / SDE / 单步核），预测即推演 | 10、11、12 |
| **E 判定族（元层）** | 系统的产出不是预测值，而是**「能不能用 / 误差多大 / 该切到哪个状态」**的判定 | 15、16、17、18、19、20 |
| **F 建造族（非预测链）** | 系统 = **一台把上面那些造出来的机器**（阶段 / 库栈 / 定理层 / 实验台） | 21、22、23、24 |

**一句话观察**：**「主线」这一族在成品集里活着三个互不兼容的版本**——净版正文写「因果是主干的一部分」（第 380 轮修正），但同一份文件里 `约定 3.5` 仍整张表写「可绕过 / 不需要」，导读第 7 条也仍写「因果降为旁路」。**这不是措辞差，是「因果在不在链上」这一个结构位上有两个相反的答案**，它把 A 族劈成候选 1 与候选 6。

## 1 · 候选逐条

### 候选 1 · 「实例→α→规则→(γ,∘,υ)→规则集→预测」四段主线（因果整层不在链上）

- **一句话**：数据/实例集经抽象算子变成规则，规则经泛化/组合/完善变成规则集，预测算子直接吐出下一状态的分布；因果结构层**整层不在这条链上**。
- **输入**：实例集 `E`（含背景知识、正负例、协变量与结果）＋ 学习机制（ERM / ILP / 关联规则 / 符号回归 / 蕴含基）。
- **输出**：`P(x_{t+1} | x_t)`（单步点预测）。
- **部件链路**：
  1. `实例集 E`（定义域正名：不是因果结构、不是 SCM、不是机制）
  2. `α：E → R`（抽象算子，取实例集的等价类代表元）
  3. `规则 R：P(y|x,c)` ＋ 三个评价量 supp/conf/lift
  4. `γ 泛化`（局部规则→全局规则）／`∘ 组合`（规则×规则→规则）／`υ 完善`（规则×数据→规则）
  5. `规则集 𝓡`
  6. `预测算子 φ(x_t)=P(x_{t+1}|x_t)`
- **与其它候选的关键区别**：**因果被显式移出主链**——「`SCM → 规则` 这条边废止」「因果层不在该链上」「规则层不需要因果」。它与候选 6 的差别就是这一个结构位：同一条链，因果在不在上面。
- **证据**：
  - `10-净版.md:27`（关键裁决段：主线方向 + `SCM→规则` 废止 + 因果降旁路）
  - `10-净版.md:1231-1240`（「因果层不在该链上」+ 禁止画「因果→规则」箭头）
  - `00-导读.md:84-88`（导读第 6 条：主线方向 + `SCM→规则` 废止 + 规则是实例集合在等价关系下的商）
  - `00-总纲.md:53-56`（主线 / 因果走旁路 / 废止 / 备选路线四条）
  - `README.md:103-109`（主线框图 + 「因果走旁路」）
- **成熟度**：**只有骨架**。`α` 无构造实例（原文自评「至少一个完整实例——无」），`γ` 三条判据未给，`∘` 的语义未定，`υ` 无性质；`02-定理清单.md:12` 记「本框架内已证者：0 条」。
- **备注（冲突）**：本条在成品集里是**已被文首标注判为作废**的版本（`10-净版.md:4-19`、`00-导读.md:4-19`），但正文 `约定 3.5`（`10-净版.md:1215-1229`）与导读第 7 条（`00-导读.md:90`）**仍按旁路写、未删**。引用本条时必须连带这一条冲突。

### 候选 2 · 分层可用性架构（八章接口链，21 条依赖边闭合，明确拒绝线性流水线）

- **一句话**：不设端到端流水线；每一层自带**显式前件**，前件给了这一层就能单独用（因果层要图、轨迹层不要图），系统的「输出」按层分发。
- **输入**：任一层的前件（图 / 参数 θ / 观测数据 / 实例集）。
- **输出**：该层可用的结论集（识别判据、干预表达式、轨迹分布、规则、预测分布），**不是**一条端到端结果。
- **部件链路**（章序 = 依赖序，非时间序）：
  1. 第 1 章 对象/状态/轨迹（`O, X, T, x_t, {x_t}`，**无前件**）
  2. 第 2 章 命 θ / 运 (u_t, ε_t)（依赖第 1 章）
  3. 第 3 章 因果结构层（**前件：图已知 A19**；依赖第 1 章）
  4. 第 4 章 轨迹生成层（**不依赖 A19**；依赖第 1、2、3 章）
  5. 第 5 章 规则层（**前件：局部域 A9**；依赖第 1、2、4 章）
  6. 第 6 章 规则学习 ／ 效应估计（**前件：识别假设**；依赖第 1–5 章）
  7. 第 7 章 预测/干预/反事实三判据（依赖第 1–6 章）
  8. 第 8 章 假设/误差/开放问题总登记（依赖第 1–7 章，只出不进）
- **与其它候选的关键区别**：它是**唯一显式否定「数据→因果发现→SCM→规则→预测→干预」这条流水线**的候选——「正确的组织方式是分层而非分阶段」，且接口表做了 21 条依赖边的双向闭合自检（无环、无悬空）。候选 1 与候选 6 都是流水线读法，本条是反流水线读法。
- **证据**：

### 候选 3 · FCA 取概念作 α 的三段式（enc → 取概念 → 概念格 → 规则）

- **一句话**：连续状态先编码成二值形式背景，再用导出算子的不动点「取概念」当规则，概念格给出规则的层级；`α` 不再是待证黑箱，而是 FCA 基本定理保证存在的一个具体过程。
- **输入**：状态 `x_t`（连续）＋ 尺度化/阈值方案（`ς`）。
- **输出**：概念 `(A_t,B_t)`／概念格中的层级化规则集 → 接 `φ` 预测。
- **部件链路**：
  1. `x_t`
  2. `enc：x_t ↦ (A_t,B_t)`（**未定义**，A32 / 开放问题 5.4）
  3. `形式背景 K=(G_FCA, M_FCA, I)`
  4. `导出算子对 (·)'` 与其复合 `(·)''`（闭包算子）
  5. `取概念 α(e) := ({e}'', {e}')`（T6.12，即「α = FCA 取概念过程」）
  6. `概念格 𝔅(K)` / `DG 基`
  7. `规则集 → φ`
- **与其它候选的关键区别**：把候选 1 里那个「存在性待证」的 `α` **具体化**为取概念过程，存在性由 FCA 基本定理（T1.3/T1.4）给出，于是**缺口从「α 存不存在」整体转移到「enc 的离散化误差」（E8）**。与候选 5 的差别在入口：本条必须有 `enc` 才吃得了连续状态，候选 5 直接宣布这个入口失效。
- **证据**：
  - `10-净版.md:2123`（「必须先给出编码算子 x_t↦(A_t,B_t) 及其误差界，FCA 才能进入规则层主链」）

### 候选 4 · DG 基完备规则源（形式背景 → 蕴含基 → 规则集）

- **一句话**：把实例集二值化成形式背景后，只输出一份 Duquenne–Guigues 基——**穷尽且不冗余**的属性蕴含集——作为规则集，不做阈值筛选。
- **输入**：形式背景 `K`（由实例集二值化而来）。
- **输出**：DG 基 `{P ⇒ P'' | P 伪内涵}`（完备、不冗余，最小基数）。
- **部件链路**：
  1. 实例集 `E`
  2. 二值化（尺度化 + 离散化，**未定义**，O5.4 / O6.6）
  3. `形式背景 K`
  4. 伪内涵枚举
  5. `DG 基`
  6. 规则集（属性蕴含：全称确定命题，**无方向、无 do 语义**）
- **与其它候选的关键区别**：在这套材料的四路规则来源（ILP / 关联规则 / 符号回归 / 蕴含基）里，**它是唯一提供完备性保证的一路**；代价是输出属「全称确定命题」这一逻辑层，与主用的「条件分布核」不同构，末端必须做一次**未定义的类型转换**。
- **证据**：

### 候选 5 · FCA 改作分类系统（裁决 N：放弃「连续→二值」入口）

- **输出**：分类结果（概念即类）。
- **部件链路**：
  1. 外部给定的 `I ⊆ G_FCA × M_FCA`
  2. 形式背景 `K`
  3. 导出算子 / 概念格
  4. 分类（概念作为类）

### 候选 6 · 因果主干链（图 → do-calculus 改写 → 识别/效应 → 干预优化）

- **一句话**：先把图/SCM 立起来，用 do-calculus 把干预量改写成纯观测量并判可识别，估计效应，再在动作空间上最小化损失选干预。
- **输入**：观测数据 ＋ 已给的因果图 `G`（A19）＋ 识别三假设。
- **输出**：最优干预 `a* = argmin_{a∈A} E[L(x_{t+1}(a))]`（以及 `P(Y|do(X))`、ATE/CATE）。
- **部件链路**：
  1. 观测数据
  2. 因果发现（四类方法：约束/分数/函数/时序）→ 图或马尔可夫等价类
  3. `图 G / SCM ⟨V,U,F,P(U)⟩`（**前件：图已知 A19**）
  4. `do-calculus 三规则改写`（四删边图记号 `G_X̄ / G_X̲ / G_X̄Z̲ / G_X̄Z(W)̄`）
  5. 识别性判定（定义 3.7：存在不依赖 `F` 的泛函 `g`）／后门、前门调整公式
  6. 效应估计 `ATE / CATE`（第 6.5–6.9：回归/匹配/IPW/AIPW/DML/IV/RD/DID/合成控制）
  7. 干预优化（命题 7.3）
- **与其它候选的关键区别**：**因果在这条链上，且是最上游**（与候选 1 正好相反）。但链上**有两处硬断点**：(a) 因果发现输出的是等价类，到结构方程 `F` 的桥未建（所以第 4 步以后无法在没有 `F` 的情况下陈述）；(b) `SCM → 规则` 已废止，所以这条链**不能接规则层**，只能接干预/反事实输出口。

- **成熟度**：**只有骨架**。SCM/do/三规则/后门前门的**定义**齐备，但全是 `[已知]`（本框架内未证），`g` 与 `F` 的桥、外生可识别（A23）、图已知（A19）三处前件均不可证。

### 候选 7 · 三任务分流（四条正交判据 → 三个输出头）
