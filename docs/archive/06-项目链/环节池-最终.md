# 环节池 · 最终版（去重后）

> **240 个最小环节**，来自 8 个族，已跨族去重（并入 7 个）。
> 每个环节都是一个可独立插入流水线的处理单元：有明确输入类型、输出类型、数学核心、实现状态。
> 完整字段见 `环节池-最终.csv`；各族详细论证见 `环节池/F*.md`。

## 怎么用这些环节拼链

1. 从 **T1 原始数据** 出发（或从 T2 状态空间），找「输入类型 = T1」的环节
2. 看它输出什么类型（T2/T3/T4/…）
3. 找「输入类型 = 上一步输出」的环节
4. 重复到抵达 **T9 预测分布** 或 **T12 干预方案**
5. 找不到匹配时，那里就是**断点**

**状态含义**：

| 状态 | 含义 |
|---|---|
| 已实现 | 代码有落点，且有真定理 |
| 部分 | 载体/雏形有，关键部分缺 |
| 仅文档 | 只有文字定义，无代码 |
| 缺失 | 理论有要求但代码完全没有 |
| 被推翻 | 曾有设计，已被证伪或裁决废止 |
| 失效 | 产物在，但判据/结论不能用 |
| 冲突中 | 多个互斥版本并存，未裁决 |
