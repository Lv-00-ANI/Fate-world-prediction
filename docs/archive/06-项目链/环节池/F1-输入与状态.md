## 环节 F1-03 · 时间索引集 $\mathcal{T}$（离散／连续两分支 + $T_{\max}$）

- **输入**：「时间」这一索引维度，以及「离散还是连续」的选择。

## 环节 F1-10 · A14 估计分支（$h$ 可逆 + $\eta$ 已建模 ⟹ 估计器与误差界）

- **输入**：观测 $y=h\,x+\eta$；前件为「$h$ Lipschitz 可逆（常数 $L>0$）」与「$\mathrm{dist}\,\eta\,0\le\eta_{\max}$」。
- **输出**：估计器 $\hat x:\mathcal{Y}\to\mathcal{X}$（对 $y$ 的一个确定选择函数），及其误差界
  $$\mathrm{dist}\,(\hat x\,(h\,x+\eta))\,x'\ \le\ L\cdot\eta_{\max},\qquad h\,x'=h\,x+\eta .$$
- **数学核心**（三步）：
  1. **前件的唯一实质形式**（任务书 $(\star)$ 的逐字形式化）：$\mathrm{dist}(h x_1)(h x_2)\ \ge\ \mathrm{dist}(x_1)(x_2)/L$，配 `0 < L` 即**蕴含** $h$ 单射（不必把单射当前提）；

## 环节 F1-11 · 观测反推潜变量的三档（bounded / posterior / quotient）

- **输入**：观测 $y\in\mathcal{Y}$、映射 $h:W\to Y$（$W$ 为潜变量空间）、档位标记 `tier`。
- **输出**（随档而变，量纲不同型）：
  - `bounded`：估计点 `estOf y` $\in W$ + 实数误差界 $\varepsilon\in\mathbb{R}$；
  - `posterior`：**未归一化**后验权重 $W\to\mathbb{R}_{\ge0}^{\infty}$（`prior w * lik y w`）；
  - `quotient`：等价类（商 `I.quo`）—— 只能回指 $[w]$，不能回指 $w$。
- **数学核心**：
  - 档位枚举 `InversionTier`；统一接口 `Inversion {tier, h : W → Y}`（`tier` 是**元数据**，不参与 `h` 的类型）。
  - 弱档：$\ker:=\mathrm{Setoid.ker}\,h$，$\mathrm{quo}:=\mathrm{Quotient}\,\ker$，$\mathrm{classOf}:=\mathrm{Quotient.mk}$；主定理
    $$\mathrm{classOf}\,w=\mathrm{classOf}\,w'\iff h\,w=h\,w'$$

## 环节 F1-14 · 属性提取算子 $\eta$（对象 → 实例／属性向量）

- **输入**：连续或一般对象 $o\in O$。
- **输出**：实例 $e=(o,\ \mathrm{attrs}(e))$，即属性向量 $\eta(o)\in A$。
- **数学核心**：
  - (a) **函数式属性提取**：$\eta:\mathrm{AttrExtract}\,O\,A:=O\to A$；**无损** $\mathrm{Lossless}\,\eta:=\mathrm{Injective}\,\eta$；**有损** $\mathrm{Lossy}\,\eta:=\exists o_1\ne o_2,\ \eta(o_1)=\eta(o_2)$；并有充要条件
  $$\mathrm{Lossless}\,\eta\iff\neg\,\mathrm{Lossy}\,\eta .$$
  关键语义（材料明写）：**属性提取 ≠ 离散化**——编码损失不是必然的，而是「选择哪种属性提取」的后果。

- **实现状态**：**已实现**（(a) 在 Lean：(定义 + 一条充要条件)；(b) 在 Python 原型：(算法 + 实测记录)）。
