# F2 · 轨迹与动力 · 最小环节

> **族职责**：给定机制与初始条件，生成轨迹（或轨迹上的测度），并给出该生成装置的存在性、可测性、离散化与可预测性边界。
> **接口词汇**：沿用 `06-项目链/环节接口约定.md` 的 T1–T14。本族**需要三个词汇表外的类型**，在此登记为提案，不改动原约定：
> - **T15 单步机制**：离散 `f : X×U×E×Θ×A → X`；连续 `μ : X×Θ×A → X`、`σ : X×Θ×A → ℝ^{d×m}`（＋布朗运动 `W`）。
> - **T16 路径测度**：`Measure (Traj ι X)`（或 `X^T` 上的概率测度）。
> - **T17 可预测性指标**：`λ_max ∈ ℝ ∪ {+∞}`、`t_pred ∈ ℝ`、`N(ε,δ) ∈ ℕ`。
> - **不新增第四类**：「干预动作读数」仍归 T12（`a ∈ A`），SCM 归 T14。
>
> **口径声明**：`实现状态` 五选一 = 已实现 / 部分 / 仅文档 / 被推翻 / 缺失（依 `_怎么做.md` §5.1 判据）。「已实现」= 有 Lean 产物且定理名可查；「部分」= 产物存在但只覆盖主张的一部分；「仅文档」= 只有文字、零产物；「被推翻」= 有裁决/裁决性表述否定它；「缺失」= 主张真实存在、连文档级构造也没有或不可执行。
>
> **本族贯穿的一条硬事项（背景事实 2）**：`do(a_t)` 作方程**参数**已作废，理由是类型错误（`命运理论-成品/01-理论/10-命运理论-净版.md:210`、`:1527-1551`、`03-规范与裁决/04-符号与方程规范.md:448-477`）。凡下述环节涉及干预入口，一律按「`a_t` 作机制层参数」记录；`do` 只作为模型层算子出现在 F2-15 的输入侧。**但 v1.0 对同一处有一条更弱的表述（`theory/10-命运理论-净版.md:2296`），两套净版口径不一致，见文末 X-1，本文件不裁决。**
