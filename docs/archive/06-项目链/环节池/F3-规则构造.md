### F3-02 · 配对层（轨迹 → 转移对）

| 项 | 内容 |
|---|---|
| **输入** | 一条轨迹 `γ : ι → X.Carrier`（`ι` 为**任意索引类型**，不一定是时间） |
| **输出** | 转移对集合 `Pairing.transitions P γ : Set (Transition X)`，其中 `Transition X := X.Carrier × X.Carrier` |
| **数学核心** | 配对 = 由 `ι` 上的一个二元关系 `rel` 决定的子集：`transitions P γ := {(γ n, γ m) \| P.rel n m}`。三种策略：A 相邻（`lt n m := m = n+1`，需有序）、B 按事件（`grouped`，不需序）、C 不配对（整条轨迹当对象，**绕开配对**）|
| **实现状态** | **部分**：结构、三策略构造函数、`transitions`、前后态属性、`TransRule`、单调性定理均有；**与真实数据格式的适配未做** |
| **Lean 模块** | `Fate/Pairing.lean`、`Fate/PairingToAlphaData.lean`、`Fate/PairingAlphaBridge.lean` |
