## 〇、先钉死一件事：哪些语义是理论原文，哪些是「主控解释」

这张表是本族全部环节的**语义归属底账**。凡下文写「【原文】」= 净版明写；「【主控解释】」= 实现方自行选定的语义，Lean 文件自己标了；「【本实现新证】」= 在该解释下**无条件证出**的定理（不是原文结论，但也不是空声明）。

| 语义项 | 归属 | 原文出处 / 自陈位置 | 判定要点 |
|---|---|---|---|
| 规则 = 条件分布核 `R : P(y\mid x,c)` | **【原文】** | 净版 L1794（定义 5.2）、L1802（择定核为主形式） | 理论明确「主形式是核」，不是点值 |
| `α : ℰ → ℛ` 的**类型** | **【原文】** | 净版 L1891–L1897（假设 5.2） | 只有类型 + 存在性假设 |
| `α` 的**可计算性/构造** | **【原文】自评「无」** | 净版 L1902（「未给出任何构造算法，也未给出任何一个完整实例」） | 原文自己承认没有实例 |
| `α` = FCA 取概念 `takeConcept = B''` | **【主控解释】**（来源为**作者裁决 D**，非净版原文） | `Alpha.lean:6-19`（裁决 D 逐字）、`:302` | 净版 L2137 明写「α 与 `(·)'` 的映射**未建立**」，故这一步是裁决产物 |
| `γ : ℛ_local → ℛ_global` 的**类型** | **【原文】** | 净版 L1912–L1918（假设 5.3） | 类型声明是原文，等式 `γ(R)=R'` 被原文自己改掉（L1920） |
| `γ` 的三条判据取值 | **【原文】明文拒绝给** | 净版 L1922–L1930（约定 5.2，「不虚构这三条判据的取值」） | 至今为空 |
| `γ` = 收缩/单调/幂等的 `GenOp`（α 的序对偶） | **【主控解释 E1】** | `GammaOperator.lean:39`（E1 行）、`:117`（`structure GenOp`） | 文件头逐条标了 E1/E2/E3 |
| `α ⊣ γ`（Galois 连接） | **【主控解释 E2】** | `GammaOperator.lean:40`、`:544` | 依据是「文献综述」而非净版 |
| `γ` 的载体 = 特异性预序 `RuleSpec` | **【主控解释 E3】** | `GammaOperator.lean:41`、`:644` | 目的是把 A9（局部域）做成可见前件 |
| `∘ : ℛ×ℛ → ℛ` 的**类型** | **【原文】** | 净版 L1942–L1950（假设 5.4）、L1934–L1938（改称「组合」） | 只有类型 + 封闭性 |
| `∘` 的**语义** | **【原文】明写「无」** | 净版 **L1962–L1964**（开放问题 5.1：「只作为一个形式记号使用，**不承载任何计算含义**」） | ★ 这是本族最关键的原文事实 |
| `∘` = 马尔可夫核复合（`Measure.bind`） | **【主控解释】** | `ComposeOperator.lean:59-69`（「第二步 · 实现层（**依主控解释**）」）、`:383` | 原文列的三候选之一（「前后相接」），但选谁是解释 |
| 三条组合律（结合/左幺/右幺） | **【原文】明写「不预设」** | 净版 L1986（§5.3.4 末段：「不以三者间存在任何交换律、结合律或优先序为前提」） | 律不是框架定理，是**实现的义务** |
| 核复合满足三条组合律 | **【本实现新证】** | `ComposeOperator.lean:436` / `:472` / `:491` / `:514` | ★ 无条件、零 `sorry`，**Lean 比理论多做** |
| `pow`（n 次幂 / Chapman–Kolmogorov 代数形状） | **【本实现新增】**（理论无对应条目） | `ComposeOperator.lean:548` / `:573` | 净版无 `pow`；这是实现方的加法 |
| `υ : ℛ×𝒟 → ℛ`，`R_{t+1}=υ(R_t,Data_t)` | **【原文】** | 净版 L1968–L1972（定义 5.8） | 只有类型与递推式 |
| `υ` 的任何性质 | **【原文】一字未给** | `UpsilonOperator.lean:18-22`（引 `02-定理清单` T6.10：「原文未给 υ 的任何性质」） | 原文空白 |
| `υ` = 闭包算子（扩张/单调/幂等） | **【主控解释】** | `UpsilonOperator.lean:9-41`（整节标「依主控解释」）、`:195` | 「把规则完善=补全未覆盖情形」是主控给的语义指示 |
| `φ(x_t)=P(x_{t+1}\mid x_t)`，单步 | **【原文】** | 净版 L2894–L2896（定义 7.1） | 明确是**分布**、**单步**，与流映射 `φ_t` 严格区分 |
| 预测算子作用在定义 5.2 的核上 | **【原文】** | 净版 L2225（§5.7 接口第 3 条） | ★ 原文**要求**接线，但没给接法 |
| `Pred` 与 `Comp`/`pow` 的接线 | **【缺失】** | E1 问题 3 第 2 条、`:86`；本文件 §F4-20 复核 | 零定理、零使用 |

> **一句话**：`∘` 与 `pow` 是本族唯一「已实现的真内容」——它的**语义**是主控解释，但**在该语义下的三条律与加法律是无条件真定理**；而 `γ`/`υ` 的语义同样是主控解释，却**没有**对应的真定理能像 `comp_assoc` 那样无条件成立（它们是**契约式**的：把性质写成 `Prop`/`structure` 字段，由使用者提供见证）。


  点质量特例另设 `DetRule := C.Carrier → X.Carrier → Y.Carrier`，由 `DetRule.toRule` 嵌入为 Dirac。
- **实现状态**：**已实现（仅载体，无语义断言）**
- **Lean 模块**：`Fate/Frame.lean`、`Fate/Basic.lean`
- **证据**：
  1. `Frame.lean:348-351` —— `structure Rule`，唯一字段 `kernel : C.Carrier → X.Carrier → Measure Y.Carrier`
  2. `Frame.lean:354-356` —— `DetRule` 为点质量特例的别名；`Frame.lean:385-386` —— `DetRule.toRule` 用 `Measure.dirac` 嵌入

- **变体**：
