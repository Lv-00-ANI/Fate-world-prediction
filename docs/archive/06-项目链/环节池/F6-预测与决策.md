#### F6-01 单步点预测（机制一步）

- **输入**：`T2`（状态空间的**一个点** `x`）+ `T13`（θ）+ 外生输入 `u`、噪声 `ε` + 动作 `a`
- **输出**：`T3`（单步：下一状态点 `x_{t+1}`，**不是轨迹**）
- **数学核心**：
  ```
  predFrom W θ u ε a x := W.f x u ε θ a
  W.f := W.simulator.step : Step F
  Step F := X.Carrier → U.Carrier → Ν.Carrier → Θ.Carrier → Act.Carrier → X.Carrier
  ```
  即唯一权威方程 `x_{t+1} = f(x_t, u_t, ε_t; θ, a_t)` 的**逐字一次求值**。
- **实现状态**：**已实现**（本族唯一"真正跑通的一次预测"，且已被主链调用）
- **Lean 模块**：`Fate.EndToEnd`、`Fate.ResidualLoop`、`Fate.WorldModelReadsTheta`、`Fate.WorldModelPipeline`、`Fate.WorldModel`
- **证据**：
  - `Fate/EndToEnd.lean:144` `predFrom` 定义；`:155` `predFrom_eq_sim_succ`（**证明**它就是 `W.sim` 的一步，防"另造预测器"）
  - `Fate/ResidualLoop.lean:495` `predicted`；`:502` `predicted_eq`
  - `Fate/WorldModel.lean:345` `WorldModel.f`；`:383` `sim_succ`（对**一切** n 的定义性递推）
  - `Fate/WorldModelPipeline.lean:54` `pipelinePredict`（管线环 ③）
- **变体**（同一语义四个落点，**互斥**——一条链里只能选一个）：
  1. `EndToEnd.predFrom`（任意 `W`，最通用）
  2. `ResidualLoop.predicted = W.sim (n+1)`（从轨迹里取第 n+1 点）
  3. `WorldModelReadsTheta.wmPred`（可计算镜像，`ℚ` 上可 `#eval`，与 `predFrom` 由 `wmPred_eq_predFrom` 钉死）
  4. `WorldModelPipeline.pipelinePredict`（管线专用，`linWorld` 上 = `θ * x`）
- **注意**：
  - 它输出的是**状态点**，不是分布，**不是** `Fate.Pred`。E1 审计判词「没有一次预测」在 `Pred` 线上成立，在**这条线上不成立**——这是本文件对审计的一处**加严更正**。
  - `predFrom` 需要 `[AddCommGroup X]`、`[Ring Θ]` 才能进链（减法/标量乘），但**单独一次预测不需要**任何结构（`predFrom` 本身无类型类前件）。
  - `W.sim` 的起点**固定**为 `W.x`，所以「从任意状态起一步」必须用 `W.f`（`EndToEnd.lean:135-139` 明写此理由）。

## 五、本族最小闭环候选链（三条可拼的链 + 各自断在哪）

### 链① 点预测链（**当前唯一从头到尾跑得通的**）

```
T1 ──F6-12(observe)──> T2 ──F6-01(predFrom)──> T3(单点)
                            │

                                                        │

```
- **可拼**：全部相邻类型相等（`observe : Y → X`，`predFrom : … → X`，`residual : X → X → X`，`writeBack : X → Θ → Θ`）。
- **断在**：输出**不是 `T9`（分布）**，也**不是**"一次预测的值"——链的输出是**新参数**（F6-15 注）。
- **证据**：`Fate/EndToEnd.lean:110/144/175/240`；`Fate/ResidualLoop.lean:93/159`。

### 链② 分布预测链（**跑得通，但与"世界模型"不相连**）

- **断在**：`xNextDist`/`trajLaw` **不消费 `WorldModel`**，也**不被** `Pred`/`pow`/`endToEnd` 消费（`Fate/AlphaAndStochasticWiring.lean:502`）。
