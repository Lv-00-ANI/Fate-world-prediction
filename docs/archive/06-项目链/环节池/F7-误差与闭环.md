### F7-03 · 误差幅度归一（`Magnitude`）

- **输入**：三种量纲的原始误差读数（方差 `v`、范数 `e`、limsup 界 `L`）。
- **输出**：三个非负「长度量」，可合法相加。
- **数学核心**　`errorMagnitude : ErrKind → ℝ → ℝ`，`variance ↦ √v`，`norm ↦ e`，`limsup ↦ L`。`Magnitude` 把「非负」写进类型（携带证明）。三量相加得上界：`e₂ ≤ a+b+c ∧ a ≤ s ∧ b ≤ e ∧ c ≤ L ⟹ e₂ ≤ s+e+L`。
- **实现状态**　🟢 真做。文件头自陈第 212 轮修正：上一版主定理的前件就是结论的定义展开（`rfl` 型同义反复），已换成真传递性论证。
- **Lean 模块**　`Fate.ErrorMagnitude`
- **证据**
  - `Fate/ErrorMagnitude.lean:157`（`errorMagnitude` 三分支）
  - `Fate/ErrorMagnitude.lean:173`（`structure Magnitude`：`val + nonneg`）
  - `Fate/ErrorMagnitude.lean:468`（`endToEnd_magnitude_bound`：三分量拆分 + 三条逐项界 ⟹ 端到端上界）
  - `Fate/ErrorMagnitude.lean:537`（`chain_three_part_bound`：四环节界逐项相加）
  - `Fate/ErrorMagnitude.lean:597`（`magnitude_unifies_unit_not_sharpness`）
- **变体**　`magnitudeOf`（负数截到 0，`:191`）／`MagTriple.ofRaw`（三量纲同时转换，`:396`）。
- **注意**
  1. **只统一单位，不统一精确性等级**：`√v` 是精确量，`e` 是精确量，`L` **只是上界**（`limsup` 界）。故和式是「上界定 + 精确量 + 精确量」，主定理因此**只给 `≤`，不给 `=`，不声称紧性**（`:560`、`:572`、`:597`）。
  2. **开方不是线性的**：`√(v₁+v₂) ≠ √v₁+√v₂`，故不得声称「端到端方差 = 三项方差之和」（`:89-92`）。

### F7-04 · 跨层可加性禁令（不同层误差不可相加）

- **输入**：两张异构度量空间上的误差读数。
- **输出**：一个**否定结论**——不存在保结构的公共实轴。
- **数学核心**　若「相加」要保各层误差结构，则须存在等距嵌入 `g : (ℝ×ℝ, ℓ¹) → (ℝ, |·|)`；证明其不存在：`(0,0),(1,1),(1,-1)` 在 ℓ¹ 下两两相距 2，而 `ℝ` 中**不存在**三点两两非零等距。
- **实现状态**　🟢 真做（否定性定理，含具体反例）。
- **Lean 模块**　`Fate.ErrorGraph`
- **证据**
  - `Fate/ErrorGraph.lean:153`（`no_equilateral_three_abs`：`ℝ` 中无三点等距）
  - `Fate/ErrorGraph.lean:179`（`l1dist_equilateral`：ℓ¹ 下三点等距边长 2）
  - `Fate/ErrorGraph.lean:192`（`no_l1_isometric_embed`）
  - `Fate/ErrorGraph.lean:227`（`no_cross_layer_isometric_embed`：给出具体 `ErrorGraph`，两层分别住 `ℝ` 与 `ℝ×ℝ`）
  - `Fate/ErrorGraph.lean:212`（`sum_depends_on_embedding`：`(1,2)` 在两个嵌入下得 3 与 21）
- **变体**　`ErrorDimUnified` 给出另一条同向证据：即便每类误差都在自己带内，**相加后仍可溢出**（`Fate/ErrorDimUnified.lean:36-46` 的 `crossScale_sum_not_ok` 反例 `σ₁=1, ε₁=1/2, ε₂=100`）。
- **注意**　证明的是「**保结构**的搬运不可能」，非保结构的任意搬运当然存在（基数相同），但那样搬过去的数已不代表原层误差——这一限定写在 `ErrorGraph.lean:62-66`。
