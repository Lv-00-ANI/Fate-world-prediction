## 二、裁决 K 的精确数学形式

作者原话（裁决 K）：

> 「误差必须小到不影响　就是**刚好拟合和过拟合的边界**」

**这句话在这份论文里有精确形式**（定义 2.3）：

$$\mathrm{IsFitBoundary}(W,\sigma,\gamma)\;:=\;\bigl(E_W(\gamma)=\sigma\bigr)\;\wedge\;\bigl(\forall\gamma'.\,\sigma\le E_W(\gamma')\bigr)$$

**第二项不可省**：只写第一项的话，一条穿越 σ 的误差曲线会有许多等值点，其中误差更大的那些属欠拟合，不应称为边界。

**且 σ 不是自由参数**（定理 3.2）：

$$\mathrm{IsFitBoundary}(W,\sigma,\gamma)\;\Longrightarrow\;\inf E_W=\sigma$$

**于是得到不含任何自由参数的判据**（定理 3.3）：

$$\mathrm{IsOptimalFit}(W,\gamma)\;:=\;E_W(\gamma)=\inf_{\gamma'}E_W(\gamma')$$
$$\mathrm{IsOptimalFit}(W,\gamma)\iff\mathrm{IsFitBoundary}(W,\inf E_W,\gamma)$$

**⟹ 裁决 K 的「≈」不是含糊的近似，而是「恰等于下确界」。**

## 三、三层划分 ←→ 我们的假设账本

论文的核心方法论主张（§1.2）：把三层混在一起，是停点判据长期难以严格讨论的根源。

| 论文的层 | 内容 | 在我们设计里的落点 |
|---|---|---|
| **严格核** | 边界定义、σ 被锁定、存在性分解、唯一性来自严格凸、表达力分离、下界分量独立、可算性紧界 | **IR 里可证的部分**（J₀ 的 `proven`） |
| **约定层** | 把 inf E_W 读作「噪声尺度」；「低于噪声＝过拟合」的语义约定；容差系数；量纲一致性作良定义条件 | **必须显式登记的设计选择**（D-008 产出 6「建模假设」） |
| **经验层** | inf E_W 是否等于统计噪声；双界是否主导实际可满足性 | **假设账本的 `empirical`**（F8-03 三类陈述） |

**⟹ 这个三层划分可以直接作为我们「三类陈述判据」的一次权威落地。**

## 四、σ 的产生流程（接到 D-008 上）

```
① 建模层构造误差剖面 W = (b, v)         ← 偏差 + 方差两分量，各非负
        │
② 判据（严格核，可证）：σ := inf E_W,  E_W := b + v
        │  定理 3.2 / 3.3，已机器检验
        ▼
③ 找边界点：IsOptimalFit(W, γ)  ⟺  E_W(γ) = inf E_W
        │  存在性见定理 4.x（连续性 + 穿越），唯一性见定理 6.1（严格凸）
        ▼
④ 经验腿（**必须登记，不可证**）：
        │  选一条桥接路径，声明其正则条件 —— §8.6 给了三条
        │  · 饱和路径      （γ → 细，模型容量足以拟合真值）
        │  · 差分估计路径  （sd(Δy)/√2；相邻相关时失效）
        │  · 交叉验证路径  （需标注与分割，小样本方差大）
        ▼
⑤ σ 的「噪声」语义落地；若拒绝全部路径，σ 仍是 inf E_W，但「噪声」二字无着落
```

**这就是 D-008 产出 5「定噪声尺度 σ」的精确操作流程。**

## 五、可复用的硬结果（已机器检验）

| 结果 | 内容 | 对我们的用途 |
|---|---|---|
| **定理 3.2** | σ = inf E_W | **补上 σ 的数学腿** |
| **定理 3.3** | `IsOptimalFit ⟺ IsFitBoundary(W, inf E_W)` | 判据可去参数化 |
| **定理 3.4** | σ ≠ inf E_W ⟹ 边界集必然为空 | **绝大多数 σ 取值下判据不可能满足** |
| **定理 5.2–5.4** | 只读误差序列的判据**不能**判定边界（对一切 τ 及 τ_of 的一切参数） | 与我们 F7-16「停止判据 ≠ 边界判据」完全一致，且是**已发表+机检**版本 |
| **定理 6.1** | 严格凸 ⟹ 边界**至多一个** | 唯一性条件 |
| **定理 6.4 / 6.5** | 凸但非严格凸 → 不唯一（铰链反例）；单调性不能替代凸性（平台反例） | 我们 F7-13「严格凸+唯一取到 ⟹ 下界」是**假**的，此处给了正确版本 |
| **定理 8.5** | σ 在有限数据下**不可辨识**（两个正 σ 可同时由同一份内部数据实现） | 解释了为什么必须走经验腿 |
| **定理 10.3** | 达到噪声尺度所需**最少档数的精确等价** | 可算性紧界 |
| **定理 10.7 系列** | 胞腔数 ≤ (n+1)^d，且该界可达，故 Θ((n+1)^d) | 编码可行性判定（正好用于裁决 K 对 enc 的判决） |

> **定理 10.7 系列**：给出了「要多细的分辨率才够」的**双向界** `s/σ ≤ n ≤ B^{1/d}-1`。
>
> ⚠ **但这不是可用的分辨率预算**——新版论文 §11.6 的真实数据实验（2026-10-29）表明
> 「几何量 → 误差量」的 Lipschitz 传递在 3 个公开数据集中有 **2 个被证伪**（α = 0.28 / 1.007 / 0.601）。
> 论文结论：「**双界不主导实际可满足性**」。
> 详见 [`否定性结果与影响.md`](否定性结果与影响.md)。
