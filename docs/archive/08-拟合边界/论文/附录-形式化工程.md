## D 形式化暴露了什么

### D.1 量纲缺失

**问题**：$\mathbb R$ 不携带量纲。因此「$\sigma$（标准差）与 $\varepsilon$（距离）相减」在类型层完全合法，即使二者量纲不同。一个常见的错误辩护是「Lean 里都是 $\mathbb R$」——这个理由不成立：$\mathbb R$ 不携带量纲信息，三米与三秒在 $\mathbb R$ 中同样可减。

**补救**：本文构造了一般维数的量纲系统：

| 对象 | 内容 |
|---|---|
| $\mathrm{Dim}\,n$ | 量纲 = 指数向量 $\mathrm{Fin}\,n\to\mathbb Z$；乘法 = 逐分量相加 |
| $\mathrm{Qty}\,n$ | 带量纲的实数 $\{v:\mathbb R,\ d:\mathrm{Dim}\,n\}$ |
| `Qty.add` / `sub` / `le` | **必须提供 $d_1=d_2$ 的证明**，否则类型错误 |
| $\mathrm{IsFitBoundaryDim}$ | 带量纲的判据：把「同量纲」写成**显式前件** |

由此得到三条定理：

- **定理 D.1（判据 $\Longrightarrow$ 量纲一致）**：若 $\mathrm{IsFitBoundaryDim}$ 成立，则 $\sigma$ 的量纲**必须等于**误差曲线的量纲。实现：`dim_consistent_of_boundary`。
- **定理 D.2（量纲不一致 $\Longrightarrow$ 不可满足）**：若量纲不同，则**不存在** $\gamma$ 满足判据。实现：`no_boundary_of_dim_mismatch`。**这说明量纲检查不是多余的装饰，而是判据良定义性的必要条件。**
- **定理 D.3（改造是机械的）**：新判据与旧判据**只差一条显式等式**。实现：`isFitBoundaryDim_iff`。

### D.2 类型别名不提供保护

**问题**：库中另有一处同类缺陷，但形态不同：

```lean
abbrev InfoLevel  := ℝ          -- 信息量
abbrev NoiseScale := ℝ          -- 噪声尺度
```

两个量**共用同一底层类型**，故「阈值」与「噪声尺度」的差别**只是一条命名约定，不是类型保证**。把门槛当作噪声尺度使用不会产生任何类型错误，只会得到一个语义上错误的定理。

**这一类缺陷比量纲问题更难补救**：量纲至少可以引入带单位的类型（如 12.1 所做），而语义相近的两个标量无法靠类型区分。

### D.3 依赖结构不等于语义结构

**观察**：库的结构质量不能由「编译通过」保证。本文在整理过程中实测到三类反例：

| 类型 | 实例 |
|---|---|
| **聚合器污染** | 一条与某无关领域毫无关系的 $\sigma$ 定理，因其所依赖模块文件同时导入了一个聚合器，被拖入该领域的整个依赖闭包 |
| **强制 import 链** | 一条 `import` 可以强制保留数千行与定理无关的内容，只为其中四个纯算术定义 |
| **注释与代码混淆审计** | 用「符号出现次数」判断依赖会误判：同一符号可以在两个模块中各定义一次；注释中的提及不构成依赖 |

**⟹ 结论**：**形式化本身不保证库是「干净的」——它只保证证明是对的。** 库的结构质量需要单独的审计手段：定义处精确定位、顶层声明穷举比对、代码与注释分离、逐模块内容阅读。

这与 AI4SLT「形式化暴露教材隐含假设」的主张互补：他们说的是**数学上**的隐含假设被暴露，本文补充**工程上**的隐藏耦合也被暴露。

### D.4 一处仍未闭合的「定义投射」

正文定义 2.3 的第二分量使「$\sigma$ 是下界」可以由定义直接读出，因而定理

```lean
le_err_of_isFitBoundary : IsFitBoundary W σ γ → σ ≤ W.err γ'
```

的证明体就是 `h.2 γ'`，**没有任何定理内容**。

**本文的正确陈述不是「该分量已被解释掉」，而是**：本文给出了**一条不经过第二分量的独立刻画**（正文定理 7.1–7.2（见附录 C.3），经 `IsMinOn` 中转），但**原定义未改**，那条被指控的投射定理**仍在库中服役**。这是一处**尚未闭合的技术债**。

它不影响正文第 7 节的数学（定理 7.3 已证该分量不可省），但意味着**读者若只查那条旧定理，仍会看到定义展开**。

## E 两次由验证驱动的修正

本工程的两次实质性数学改进，都不是先有想法再验证，而是**验证过程本身把问题顶出来的**。

### E.1 组合上界：$2^{dn}$ 收紧为 $(n+1)^d$，并证明紧

**起因。** 原界 $|\text{胞腔}|\le 2^{dn}$ 的证明只用了一件事：内涵是属性集的子集。
用真实数据一算，松弛达 $10^{7}$ 至 $10^{33}$ 倍——界虽然成立，却毫无信息量。

**修正。** 注意到对固定维 $j$，隶属集 $\{i:\theta_{j,i}\le x_j\}$ 只随 $x_j$ 在 $n$ 个阈值
所划分的 $n+1$ 个区间中移动而取**嵌套**的值，故每维至多 $n+1$ 种。于是

$$|\text{胞腔}|\le (n+1)^d.$$

关键引理是链的计数：沿链包含关系单调，故基数沿链严格不减；由「包含 + 基数相等 $\Rightarrow$ 相等」，
基数在链上单射，于是链的大小不超过基数的取值个数 $n+1$。

**紧性。** 仅给出更紧的上界还不够——必须有下界配对才能说「压死」。取阈值每维为 $0,\dots,n-1$，
点取 $x_j=t_j-\tfrac12$（$t:\mathrm{Fin}\,d\to\mathrm{Fin}(n+1)$），则第 $j$ 维隶属集的基数恰为 $t_j$，
不同 $t$ 给出不同内涵，$(n+1)^d$ 个点各占一胞腔。故界是 $\Theta$ 而非仅 $O$。

**后果。** 可算上限由 $C_2=\log_2 B/d$ 改为 $B^{1/d}-1$。$B=10^6$、$d=3$ 时，
旧界给 $6.6$、新界给 $99$——旧界把大量可行配置误判为不可满足。

### E.2 Lipschitz 传递的显式化与失效反例

**起因。** 定理 10.2 只断言**胞腔宽度** $\ge s/n$。但正文 §11.2 把它读成了误差界，
这一步从未被写成定理。真实数据实验（§11.6）一做，就发现衰减指数远小于 1。

**修正。** 把这一步显式化为 `lipschitz_cell_error`：若 $f$ 是 $L$-Lipschitz 且两点同处一胞腔，
则 $|f(x)-f(y)|\le L\cdot(\text{胞腔宽度})$。前件 $L$ 是**假设**，不是定理内容。

**失效的精确形态。** 仅说「没有 Lipschitz 就不行」失之笼统。`step_no_decay` 给出定量形态：
对阶跃函数，在任何档数 $n$ 下，跨跳变的胞腔内**任何**常数预测都至少错 $1/2$。
即误差**不随 $n$ 衰减**，与 $L\cdot s/n\to0$ 的情形正相反。

**为什么必须做这一步。** 如果只在正文里写「几何界到误差的传递需要光滑性」，
那是散文；写成定理之后，「失效」才成为一个可以指认的对象——
它发生在哪一条前件上，是 `lipschitz_cell_error` 的 $hf$。

## H 一处仍然存在的技术债

`le_err_of_isFitBoundary` 的证明体就是 `h.2 γ'`——它只是定义的第二分量展开，没有定理内容。
正文给出了**不经过**该分量的独立刻画（定理 7.1–7.2），但**原定义未改**，
那条被指控的投射定理**仍在库中服役**。

这不是数学问题（定理 7.3 已证该分量不可省），而是接口问题：
读者若只查那条旧定理，看到的仍是定义展开。修它需要改动 `IsFitBoundary` 的定义，
会波及大量下游证明，故留作未闭合项。
