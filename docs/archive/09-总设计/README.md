## 一、系统是什么

> **把一个真实世界建模成结构因果模型，从数据中抽取规则，用它预测状态、干预与反事实，
> 并把结果导出成与原世界同类型的多模态视图；误差以噪声尺度 σ 为准绳闭合。**

### 输入 → 输出

| | 输入 | 输出 |
|---|---|---|
| **形态** | 真实世界的多模态观测（数值 / 类别 / 时序 / 图 / 文本…） | 同一批模态的**预测视图** + 可推导的派生视图 |
| **数学形态** | 被构造为数学对象的 `Data` | `Model` 序列 + 每模态的误差与 σ |
| **附带** | —— | **每条结论依赖哪些未证前件、依赖哪些数据** |

### 与理论的关系

本系统是《命运》理论的**工程实现**。理论提供：

| 理论 | 在系统里的位置 |
|---|---|
| 核心方程 `x_{t+1} = f(x_t, u_t, ε_t; θ, a_t)` | `Model` 的机制部分（`F`） |
| SCM `𝓜 = ⟨V, U, ℱ, P(U)⟩` | **模型本体**（`D-014`） |
| 规则 `R : P(y \mid x, c)` / 商结构 | 规则层的语义靶子 |
| 三类陈述（可证 / 条件 / 经验） | 元层的判据 |
| 八类误差 | 误差层的分类骨架 |

## 三、分层与十三条铁律

| # | 铁律 | 依据 |
|---|---|---|
| 1 | **底座 = 纯 CIC**，之上全是规则：三条公理**不是底座**，是**假设账本里的条目** | D-003 / **D-016** |
| 2 | **层间只能向上引用**：`Jₙ` 引用 `J_{n-1}`，不能引用自己（predicative，避开 Girard） | D-003 |
| 3 | **来源不可丢弃**：判断必带 support，算子只能增不能减 | D-004 |
| 4 | **数据必须数学构造**：不存在「原始数据」层 | D-007 |
| 5 | **误差以 σ 为判据**：合格 = 误差 ≈ σ，不是「越小越好」 | 裁决 K / D-008 |
| 6 | **建模可呈现**：`Model` 不保留原始数据，但结果能投影成可看值 | D-010 |
| 7 | **状态即模型**：`X` 的元素是 `Model` | D-009 |
| 8 | **模型是一体化完整系统**：不按模态拆分 | D-013 |
| 9 | **模型 = SCM**：按因果结构组织 | D-014 |
| 10 | **模态是开放的、只是导出轴**：能导出就导出，边界 = 注册表 | D-011 / D-012 |
| 11 | **细节下放实现期**，用「抽象 > 泛化 > 并行 > 择优」四策略解决 | D-015 |
| 12 | **账实相符**：`#print axioms` 必须**等于** `support.assumptions`（用了什么就登记什么） | D-016 |
| 13 | **核内不用 `Quot`**：商以**不变谓词**表示；`ℝ`/`Measure` 归经典外壳（Lean 4 无 HIT） | D-017 |
### 两级底座（D-016）

```
┌ 经典外壳（可选）───────────────────────────────────────┐
│ 把 propext / Classical.choice / Quot.sound 作为**假设**引入 │
│ → 得到 ℝ、Measure、拓扑                                   │
│ → 凡用它的定理：support ⊇ {那三条}，status = conditional   │
├ 构造性核（纯 CIC，无任何假设）────────────────────────────┤
│ Term / Formula / Data / Judgment 的语法与算子              │
│ WellSorted · substitute · quote · 消融记账                 │
│ → 在此层证出的定理：support = ∅，status = proven           │
└─────────────────────────────────────────────────────────┘
```

**⟹ 「底座纯 CIC」的真实含义**：底座只有 CIC；需要经典数学时，是**在纯 CIC 之上加了三条假设**，而不是底座自带公理。

**核内的商**（D-017）：**不用 `Quot`**——它是 Lean 的 opaque 原语且 `Quot.sound` 是公理。
商改用**不变谓词**：`~`-不变的谓词与函数。于是「规则 = 商」在核内实现为「**规则 = 不变量**」。

## 四、第 0 层 · 数学建模层

### 4.1 职责

> **真实世界 → 数学对象的唯一接口。跨过它的一切都已经是数学对象。**

### 4.2 产出契约（七项，缺一不可）

| # | 产出 | 类型 | 状态 |
|---|---|---|---|
| 1 | **数据对象** | `Data`（`ℚ` / 向量 / 元组 / 实体引用 / **复杂逻辑结构** / 数据集引用） | 类型已定，无实例 |
| 2 | **SCM 的 `V`** | 内生变量集 | `[细节·策略③]` 用类型族还是索引集 |
| 3 | **SCM 的 `U`** | 外生变量集 | 同上 |
| 4 | **SCM 的 `F`** | 结构方程族 | 定形，未实现 |
| 5 | **SCM 的图** | DAG | `[未决·架构]` 建模层给（A19）还是因果发现 |
| 6 | **观测模型** | `h : X→Y`、`η` | 部分（核型仅在 v1.0 文档） |
| 7 | **σ 与建模假设** | `σ_model` / `σ_emp` + 经验假设 | 机制已定，见 4.4 |

### 4.3 A14 分支（必须显式选一）

| 分支 | 形式 | 后果 |
|---|---|---|
| **无损** | `ObservedState := id` | 「命运」在真实数据上不可观测（**定义成真，不是证明**） |
| **估计** | `h` 可逆 + `η` 已建模 ⟹ 估计器 | 需要滤波器（`F1-12`，全库零实现） |

> **必须显式声明，不得默认**。历史代码默认走无损，这是被审计点名的「silent gap」。

### 4.4 σ 的两条腿（关键）

```
┌─ 数学腿（可证）───────────────────────────────────────┐
│  σ_emp := inf E_W       定理 3.2，已机检              │
│  E_W := b + v（偏差 + 方差，各非负）                   │
└──────────────────────────────────────────────────────┘
┌─ 模型腿（可算）───────────────────────────────────────┐
│  σ_model(m) := spread( (project_m ∘ F)(P_U) )         │
│  外生律经结构方程与投影推前后的离散度                   │
└──────────────────────────────────────────────────────┘
┌─ 经验腿（须登记，不可证）──────────────────────────────┐
│  「σ_emp ≈ σ_model ≈ 统计学噪声」                      │
│  须选一条桥接路径：饱和 / 差分估计 / 交叉验证           │
│  每条都有失效条件，必须写清                            │
└──────────────────────────────────────────────────────┘
```

**裁决 K 用的是 `σ_emp`；「`σ_emp ≈ σ_model`」本身是一条可检验的经验命题。**

### 4.5 脏的建模（不可省）

| 脏 | 必须写成 |
|---|---|
| 缺失 | 缺失掩码 |
| 噪声 | `P_U` 的分布形式 |
| 采样偏差 | 抽样机制或权重 |
| 量纲不一致 | 换算关系（裁决 K 的良定义条件） |

## 五、第 1 层 · 模型层

### 5.1 模型 = SCM（D-014）

```lean
structure Model where
  V   : Type                              -- 内生变量
  U   : Type                              -- 外生变量
  F   : V → (V → Val) → (U → Val) → Val   -- 结构方程族
  P_U : Measure U                         -- 外生律
```

**模型是一体化完整系统**（D-013）：`state` = 内生赋值、`mechanism` = `F`、`noise` = `P_U`。
**不按模态拆分。**

### 5.2 状态空间

`X := Model` 的一类（更准确：`X` 的元素是内生赋值，`Model` 提供结构与噪声）。

### 5.3 时间索引与动力学

`[细节·策略③]` 三种做法：

| 做法 | 形式 | 风险 |
|---|---|---|
| 时间进入 `V` | `V = Entity × Time` | `V` 显著放大 |
| 分层（当前点 + 机制） | `X` 只存当前点，`F` 跨时间引用 | 需要"时间前进"算子 |
| 轨迹作为变量 | `V` 含整条轨迹 | 与"状态"概念冲突 |

### 5.4 `Val` 的设计

`[细节·策略③]` 先用依赖类型 `V → Type`（保留类型区分）；若复杂度失控，退到统一 `Val`（牺牲区分）。

### 5.5 未决

| 项 | 标注 |
|---|---|
| `Val` 的最终形式 | `[细节·策略③]` |
| 时间索引方案 | `[细节·策略③]` |
| **图从哪来** | `[未决·架构]` ← **本层最大空白** |

## 六、第 2 层 · 规则层（IR）

### 6.1 两级判断

```lean
-- J₀：条件定理 = 规则
structure Judgment where
  hyp     : Formula
  concl   : Formula
  support : Support      -- 只含 assumptions，不含数据
  status  : Status       -- proven / conditional / empirical / refuted

-- J₁：关于 J₀ 的定理（四算子的规格）
structure MetaJudgment where …   -- 公式里可出现 quoteJudgment
```

### 6.2 语法材料（mutual）

```lean
mutual
  inductive Term   | lit (d : Data) | var | add | mul | neg | ext
  inductive Formula| eq | le | lt | and | or | not | all | ex | ext
  inductive Data   | rat | vec | tup | ent | logic (f : Formula) | ref
end
```

**语义值域是多类**：`Value = real / prop / ent / logic`，须 `WellSorted` 排除无意义组合。

### 6.3 四算子与来源传播

| 算子 | 输入 → 输出 | support | status |
|---|---|---|---|
| **α** 抽象 | 数据 → `Judgment` | 消融后的经验假设 | 可升可降 |
| **γ** 泛化 | `Judgment` → `Judgment` | 只增 | 常降 `conditional` |
| **∘** 组合 | `Judgment × Judgment` | **并** | 取较弱 |
| **υ** 完善 | `Judgment × Data` | 加新假设 | 可升可降 |

**铁律**：没有任何算子能减少 support。这条本身是 J₁ 定理。

### 6.4 数据三级策略

| 层 | 条件 | 处理 |
|---|---|---|
| ① 消融 | 消融后命题含义不变 | 转具体定理（support=∅）或经验假设 |
| ② 嵌入 | 会改含义，规模小 | `rat`/`vec`/`tup`/`ent`/`logic` |
| ③ 引用 | 会改含义，规模大 | `ref` + 证据档案 + hash |

**判据**：**消融掉之后，这条规则还是不是原来那条？**

### 6.5 自拓展

| 层 | 机制 | 状态 |
|---|---|---|
| C1 | 规则集自长（`upsilon` 迭代） | 骨架已有 |
| C2 | 语法可扩（`ext` + 注册表） | 已设计 |
| C3 | 自动发现缺口 | `[未决·研究]` |

## 七、第 3 层 · 预测层

### 7.1 预测的定义

```
predict : Model → Measure Model          -- 分布预测
predictPoint : Model → Model             -- 点预测（分布退化时）
```

### 7.2 三任务

| 任务 | 形式 | 依赖 |
|---|---|---|
| **预测** | `P(x_{t+1} \mid x_t)` | 模型 + 无干预 |
| **干预** | `P(x_{t+1} \mid do(X=x))` | SCM 换方程 |
| **反事实** | `P(x_{t+1}^{do(a')} \mid e)` | 三步：溯因 → 干预 → 预测 |

**反事实第一步 `P(U \mid e)` 不可省** —— 去掉它反事实等同干预。

### 7.3 世界模型四组件

| 组件 | 内容 | 状态 |
|---|---|---|
| 状态 | `WorldState` | 已编译（`ProperFit` 树） |
| 规则集 | `WorldRules` / `WorldRulesθ` | 同上 |
| 模拟器 | `WorldSimulator`（`step` + `horizon`） | 同上 |
| 选择器 | `Selector`（`score` + `choose`） | 同上 |

### 7.4 场景树与择优

`ScenarioTree` → 评分 → 最优差距 → 干预方案。

⚠ **两个已知限制**（实测）：
- `Scenario` **无概率字段**，`ScenarioTree` 是 `Set (Scenario)` 而非真树
- 闭环树上**换 plan 轨迹不变**（`branch_traj_indep_of_plan`）⟹ 分支模拟退化

## 八、第 4 层 · 导出层

### 8.1 模态 = 投影

```lean
structure Modality where
  id      : ModalityId
  carrier : Type
  observed: Bool                  -- 来自原数据？还是可推导？
  project : Model → carrier

structure ExportScope where
  include / exclude : List ModalityId

def export (reg) (M) (scope) : List (ModalityId × Value)
```

### 8.2 两条义务

| 义务 | 内容 |
|---|---|
| **完备性** | 原数据出现的**每个**模态，都必须有可执行的 `project` |
| **开放性** | 可注册任意可推导模态；边界 = 注册表 |

### 8.3 默认与限定

- **限定**：可用 `scope` 裁剪；**受限导出必须带 scope 元数据**，不得声称「完整模型」

## 九、第 5 层 · 误差层

### 9.1 判据（裁决 K 的精确形式）

```
E_W(γ) := b(γ) + v(γ)                                    -- 误差剖面
IsFitBoundary(W,σ,γ) := (E_W(γ)=σ) ∧ (∀γ'. σ ≤ E_W(γ'))  -- 定义 2.3
IsOptimalFit(W,γ)    := E_W(γ) = inf E_W                 -- 定理 3.3 等价
```

### 9.2 σ 被锁定（定理 3.2）

```
IsFitBoundary(W,σ,γ) ⟹ σ = inf E_W
σ ≠ inf E_W ⟹ 边界集必空（定理 3.4）
```

### 9.3 三层损失

| 阶段 | 损失 | 判据 |
|---|---|---|
| 建模 `construct` | **`ε_model`** | ≈ σ |
| 规则 `α` 抽象 | 抽象损失 | ≈ σ |
| 预测 | 预测损失 | ≈ σ |

### 9.4 双界（可算性）

$$\frac{s}{\sigma}\ \le\ n\ \le\ B^{1/d}-1$$

左端几何（格宽下界，定理 10.3）、右端组合（胞腔数上界，定理 10.7，且可达）。
**但这不是可用的分辨率预算。** 新版论文 §11.6 实测表明 Lipschitz 传递在 2/3 公开数据集上被证伪
（α = 0.28 / 1.007 / 0.601），论文结论是「**双界不主导实际可满足性**」。
⟹ 要定所需分辨率，必须**另外实测 α**，不能用 `n ≥ s/σ` 直接预算。
详见 [`08-拟合边界/否定性结果与影响.md`](../08-拟合边界/否定性结果与影响.md)。

### 9.5 未决

| 项 | 标注 |
|---|---|

| 层间传播 `Σ(∏Λ)ε` | 已证**不存在**（`¬HasPropagationLaw`）⟹ 只能逐层报 |

## 附：本设计的自我限界

6. **核现阶段的定位是「纯语法层」**：不含实数、不含测度、不含商类型。它的分析能力是**承诺后补**的（`D-018`），不是永久缺失。
