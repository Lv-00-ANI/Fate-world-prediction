## 裁决 R-002：FCA 层**先查 Mathlib，再决定自建范围**

**状态**：已执行（核查完成，结论见下）

### 背景

规格 `02-证明路线/00-总纲.md` §三 记载：

> 「FCA 基本定理｜原则上可形式化：**是**｜Mathlib 现有覆盖：**无**（但据 Galois 连接 API，接近「胶水代码」量级）」

启动说明 §三 据此建议：「**故先自建最小 FCA**（Galois 连接 + 概念格 + 导出算子）」。

### 实测结果（**与规格记载不符，须据实更正**）

**Mathlib 中已存在 FCA 的形式化：`Mathlib.Order.Concept`。**

源码：`D:\mathlib\packages\mathlib\Mathlib\Order\Concept.lean`
已编译构件：`D:\mathlib\packages\mathlib\.lake\build\lib\lean\Mathlib\Order\Concept.olean`（存在）

其文件头（原文摘录）自述：

```
# Formal concept analysis

This file defines concept lattices. A concept of a relation `r : α → β → Prop` is a pair of sets
`s : Set α` and `t : Set β` such that `s` is the set of all `a : α` that are related to all elements
of `t`, and `t` is the set of all `b : β` that are related to all elements of `s`.

Ordering the concepts of a relation `r` by inclusion on the first component gives rise to a
*concept lattice*. Every concept lattice is complete and in fact every complete lattice arises as
the concept lattice of its `≤`.
```

已实测可用的 API（`#check` 通过）：

| Mathlib 符号 | 类型 | 对应规格符号 |
|---|---|---|
| `upperPolar (r : α → β → Prop) : Set α → Set β` | — | $(\cdot)'$ 的**上极**方向 |
| `lowerPolar (r : α → β → Prop) : Set β → Set α` | — | $(\cdot)'$ 的**下极**方向 |
| `Concept (α) (β) (r : α → β → Prop) : Type` | — | 形式概念 $(A,B)$ |
| `gc_upperPolar_lowerPolar` / `gc_lowerPolar_upperPolar` | `GaloisConnection ...` | **FCA 基本定理的 Galois 连接部分** |

**注意**：Mathlib 用 `upperPolar`/`lowerPolar` 记导出算子对，
而规格 §1.5 用 $(\cdot)'$ 双向记法。**二者是同一对象的两种记法**，
本实现须在定义层做一次**记法对照**（见 `命运/` 内的符号对照表），不得混用。

### 决策

1. **不重复造轮子**：FCA 的 Galois 连接与概念格**依 Mathlib 既有 API 转写**，
   **不再自建**。这符合规格自身对 T1A.9 的定位（类别 ①、`[已知]`、几乎无条件）。
2. **规格 `00-总纲.md` §三 的「Mathlib 现有覆盖：无」一栏据实更正**为「**有**」，
   更正依据为上列源码与构件路径。**更正在 `进度.md` 中登记，并保留本条以便回溯。**
3. **自建范围收窄**至**规格确认为缺口**的部分：
   - 蕴含基（`A ⇒ B`、伪内涵、**DG 基**）——Mathlib 的 `Order.Concept` **不含**，
     属真正自建范围；
   - 编码算子 $\mathrm{enc}:\mathcal{X}\to 2^{G_{\mathrm{FCA}}}\times 2^{M_{\mathrm{FCA}}}$（A32 / T1B.2a）。
4. 规格 §三 关于 **SCM / do 算子 / do-calculus / 后门前门 / 反事实 / 因果发现可识别性 /
   规则学习泛化界** 的「Mathlib 无覆盖」判断**经抽查未见反例**，暂予采信，
   但**逐项须在使用前实测确认**（不得仅凭本表就断言缺口）。

### 诚实保留

1. 本代理**未**穷尽检索 Mathlib 全部命名空间，只核验了 `Order/` 下的直接命中。
   「Mathlib 无覆盖」的其余各项**未经穷尽核验**，标 `[未核验]`。
2. 本条**不构成**对 FCA 基本定理的证明——它只说明**该形式化在 Mathlib 中已存在、可直接引用**。
   依规格 `06-原型实验.md` §3.5 的区分：T1.1–T1.4、T1.6 是 `[已知]`（外部既有结果），
   本框架内**未证**，只**引用**。

## 裁决 R-006：A8 的「可计算」未被定义——**据实登记为规格缺口，不擅自补定义**

**状态**：已执行（登记完成，**未擅自补定义**）

### 背景

规格 A8 原文：

> **A8**｜抽象算子 $\alpha$ 存在且**可计算**（$\mathcal{E}\to\mathcal{R}$ 非空）｜待证命题（存在性）

### 发现（由 Python 原型子代理报出，主代理复核并采纳）

「**可计算**」一词在规格全文中**未被定义为任何可计算性理论术语**：

- 未写「图灵可计算」
- 未写「多项式时间可计算」
- 未指定任何复杂度类
- 未给出可计算性的判据

**后果**：「$\alpha$ 是否可计算」这一命题**范围未定**，
故**在原型层面无法判定**——原型的结论正确形式是
「在实测规模上跑通了取概念过程」，
**不能**是「$\alpha$ 可计算」或「$\alpha$ 不可计算」。

### 决策

1. **如实登记为「不可判定」**，并写明原因（符合规格 `06-原型实验.md` §5.3 纪律 3：
   「『不可判定』是合法结果，不得强行二分」）。
2. **本代理不擅自为「可计算」补一个定义**。理由：
   补定义即等于替作者作**语言层选择**，而规格 `05-公理与章序规范.md` §1.4 明写
   「**可选而不声明，是把选择伪装成事实**」。
   本代理若私自选定「图灵可计算」，则后续一切「A8 已证」的陈述都建立在一个**未经作者确认的**约定上。
3. **登记为待作者裁决项 Q-5**（见下）。

### 影响

- **不阻塞**阶段 1B 的 $\alpha$ 具体化工作（依裁决 D，$\alpha$ 的**存在性**由 FCA 基本定理保证，
  与「可计算」的定义无关）。
- **阻塞**的是「A8 的状态栏能否从『未证』改为『已证』」——
   在「可计算」被定义之前，**该栏只能保持「未证」**，
   且**不得**用原型的规模曲线冒充该命题的证明
   （规格 §4.2 规则 2 明写：「复杂度下界只能由证明给出」）。

### 新增待作者裁决项

| 编号 | 问题 | 分叉 | 规格依据 |
|---|---|---|---|
| **Q-5** | A8 的「**可计算**」取何义？ | (a) 图灵可计算；(b) 多项式时间可计算；(c) 特定复杂度类；(d) 其他。**不同选择给出不同的定理集与不同的证明义务** | A8 原文；`01-路线图.md` 阶段 3 验收标准 3（「复杂度陈述必须与正确性陈述同时给出」） |

一律写成**显式带复杂度前件**的形式（如「存在 $O(f(n))$ 的算法」），
**不使用裸的「可计算」一词**。

### 背景

Python 原型子代理报告了一条**重要教训**：

> `S3` 第一版用 Next-Closure 实现时 lectic 后继方向写反，
> **在 3 对象 2 属性背景上只枚举出 1 个闭集**（暴力复算为 4）。
> 后果是概念格塌成 1 个概念，**而 V2/V3/V4 全部「通过」**
> （1 个概念确实满足不动点条件）。
> 该错误**不会被 V1–V8 任何一条自动捕获**，
> 是靠另写的 `verify_all_closures_bruteforce` 独立复算才发现的。

### 决策

1. **采纳该教训为项目纪律**：凡原型实现，**必须自带独立复算路径**
   （naive/暴力实现或独立算法），**不得只依赖规格 §3.5 的 V1–V8**。
2. 该纪律写入 `进度.md` 踩坑清单与后续原型的 `SPEC.md` 要求。
3. **理由**：V2–V4 是**自洽性检验**——一个退化的实现可以自洽地通过它们。
   只有**与实现路径无关的复算**才能发现结构性错误。

### 对规格的反馈

规格 §3.5 的 V1–V8 **本身不是缺陷**（它们如实检查各自的范围），
但**其覆盖面不足以单独作为「实现正确」的判据**。
本裁决**不修改规格**，只在实现侧**追加**独立复算这一硬要求。

## 裁决 R-009：伪内涵的「非自指简化」**被实测否证**——DG 基完备性须用规格字面（自指）版本

**状态**：已执行（**一次实质性数学纠正**）

### 背景

规格 §3.4 的 **S6** 给出伪内涵的定义：

> 枚举伪内涵：$P\subseteq M_{\mathrm{FCA}}$ 且 $P''\neq P$
> 且对每个**伪内涵** $Q\subsetneq P$ 有 $Q''\subseteq P$。

该定义**是自指的**（「对每个**伪内涵** $Q$」），
而自指定义在 Lean 中**不良基**，无法直接用于枚举或结构递归。

**主执行代理的初稿处置**：定义了一个**非自指**版本 `IsPseudoIntentCore`，
把「伪内涵 $Q$」**放宽**为「不闭的 $Q$」，
并在 doc-comment 中写下断言：

> 「在有限背景上二者等价」

### 该断言**是错的**——实证否证

主执行代理用穷尽枚举**否证了自己写下的这条断言**。

**核查脚本**：`prototype/fca-alpha/dgbasis_completeness_check.py`
**检验范围**：$\lvert G_{\mathrm{FCA}}\rvert=\lvert M_{\mathrm{FCA}}\rvert=3$ 的
**全部 512 个形式背景** $\times$ **全部 4096 个属性集**（穷尽，非抽样）

**实测结果**：

| 伪内涵定义 | DG 基完备性检验数 | **反例数** |
|---|---|---|
| **非自指**（`IsPseudoIntentCore`，初稿） | 4096 | **228** ❌ |
| **自指**（规格 S6 字面版，`IsPseudoIntent`） | 4096 | **0** ✅ |

**结论：二者【不等价】。** 非自指版本会**漏掉必要的伪内涵**，
其生成的 DG 基**不完备**。

**附带否证的另一个形式**：主执行代理还检验了
「$B$ 不闭 $\Rightarrow$ 存在伪内涵 $P$ 使 $B\subseteq P$」这一中间引理形式，
对两种定义都**不成立**（自指版 1053 反例、非自指版 1281 反例）。
**这解释了为什么完备性必须靠「迭代」而非「单步覆盖」。**

### 处置

1. **删除** doc-comment 中的「二者等价」断言，替换为
   **实测表格与反例数**（不得只写「不等价」而不给依据）。
2. **新增** `IsPseudoIntent`——规格 S6 的**字面（自指）版本**，
   用「对更小集合已判定完毕」的谓词形式 + `ncard` 下降测度实现良基递归。
3. **新增** `DGBasisSelfRef` 作为 DG 基的**权威定义**，
   并在 doc-comment 中注明「只有自指版本给出的基完备」。
4. **保留** `IsPseudoIntentCore`，但**明确标注**：
   它只用于给出**可靠性**与「伪内涵必不闭」这一结构性事实，
   **不得**用它宣称完备性。

### 方法论意义（**本裁决最重要的一点**）

**这是一次「代理否证自己」的实例。**
初稿的断言（「二者等价」）看起来**完全合理**——
它在小例子上确实成立，且符合「非自指化是标准做法」的直觉。

**否证它的是一个几分钟能写完的穷尽枚举脚本。**

**故本裁决确立一条项目纪律**：

> **凡涉及「两种定义等价」「简化形式不失一般性」这类断言，
> 在写入 doc-comment 前，必须先做穷尽枚举检验（若状态空间可行）；
> 不可行者，须显式标注「未经检验」，不得写成「等价」。**

这与 R-008（原型须自带独立复算）是同一精神，
但适用范围更广：**不限于原型，也适用于形式化代码中的注释性断言**。

### 诚实保留

1. 核查范围是 $\lvert G\rvert=\lvert M\rvert=3$（**有限小规模**）。
   反例的存在性**已足以否证**「等价」这一全称断言
   （一个反例即可否证全称命题）。
   但**正面结论**（自指版完备）在更大规模上**未被检验**——
   本实现**不声称**已证 DG 基完备性。
2. 完备性的**形式化证明（Lean）仍未完成**。
   本裁决只确立了**正确的定义选择**，未完成定理。

## 裁决 R-011：DG 基完备性的**正确枢纽引理**（又一次实证纠正）

**状态**：已执行（**第二次「代理否证自己」**）

### 背景

阶段 1B 的最后一项数学工作是 **DG 基完备性**（规格 T1A.10 的「完备」一半）：

> 任一在 $\mathbb{K}$ 中成立的蕴含 $A\Rightarrow B$，
> 都可由 DG 基**经 Armstrong 规则迭代推出**。

**本代理的第一版策略**（错误）：

> ~~$A$ 不闭 $\Rightarrow$ 存在伪内涵 $P$ 使 $A\subseteq P$~~

直觉是「不闭的 $A$ 应被某个伪内涵覆盖，从而 DG 基中的规则可用」。

### 该策略**是错的**——实证否证

**核查**（$\lvert G\rvert=\lvert M\rvert=3$ 的**全部 512 个形式背景**、
**全部 2119 个不闭 $A$**，穷尽）：

| 候选枢纽引理 | 检验数 | **反例数** |
|---|---|---|
| ~~$A\subseteq P$（$P$ 为伪内涵）~~ | 2119 | **1053** ❌ |
| ~~$A\subseteq P\subseteq A''$~~ | 2119 | **1053** ❌ |
| ~~$A\subseteq P$ 且 $P''\subseteq A''$~~ | 2119 | **1053** ❌ |
| **$P\subseteq A$ 且 $P''\not\subseteq A$** | 2119 | **0** ✅ |

**即：方向是反的。** 不是「$A$ 被伪内涵包含」，
而是「$A$ **包含**一个伪内涵，且该伪内涵的规则**确实推进了**」。

### 正确的引理与验证

> **对不闭的 $A$，存在伪内涵 $P\subseteq A$，使 $P''\not\subseteq A$。**

**直觉**：$A$ 不闭意味着它「遗漏了某些应满足的属性」；
DG 基的性质保证**遗漏总能被某个由 $A$ 内部触发的伪内涵捕捉到**。

**跨规模验证**（脚本 `prototype/fca-alpha/dgbasis_driving_lemma_check.py`）：

| 规模 | 检验数 | 反例数 |
|---|---|---|
| $\lvert M\rvert=3$ | 2119 | **0** |
| $\lvert M\rvert=4$ | 8094 | **0** |
| $\lvert M\rvert=5$ | 18607 | **0** |

**合计 28,820 检验，0 反例。**

### 处置

1. **新增** `Fate/Completeness.lean`；
2. 把正确的引理做成**具名前件** `DrivingLemma`；
3. 证明**由它可推出「迭代至少推进一步」**（`iter_one_advances`，**已证**）；
4. 证明**完备性主定理** `dgbasis_complete`（**条件形式**，
   前件＝`iterReachesClosure`，**已证**）；
5. **如实登记**：`DrivingLemma` 的**形式化证明未完成**——
   其实证验证已完成（28k+ 检验）。

### 诚实保留（**必须与结果同时阅读**）

1. **`dgbasis_complete` 是条件定理，不是无条件定理。**
   其前件 `iterReachesClosure` 是**具名的、可陈述的**——
   这符合规格对条件定理的要求（前件必须写成 Lean 类型，不得匿名）。
2. **`DrivingLemma` 与 `iterReachesClosure` 的形式化证明均未完成。**
   本实现**不声称** DG 基完备性已完全形式化。
   已完成的只是：
   - **实证**：正确引理在 $\lvert M\rvert\le 5$ 上零反例；
   - **形式化**：由该引理到主定理的**推演链**（已证）。
3. **「最小性」（T1A.10 的「最小」一半）完全未做。**

### 方法论意义

**这是本代理第二次否证自己写下的东西**（第一次见 R-009）。
两次的共同点：**错误的形式看起来完全合理**。

- R-009：非自指简化「显然」与自指原版等价 → **假的**；
- R-011：「不闭集被伪内涵覆盖」→ **假的，且方向反了**。

**两次都是几分钟的穷尽枚举脚本抓出来的。**

**故本裁决再次强化 R-009 的纪律**：

> **凡「显然」「不失一般性」「方向如此」类的引理形式，
> 在写入 Lean 之前必须先做穷尽检验（状态空间可行时）。
> 方向尤其要检验——上例中错的方向与对的方向都「看起来很自然」。**

### ⭐ 更重要的收获：**Theorem 3.46 的证明体就是 `ClosedOfModel` 的证明**

**教材完备性证明原文（逐字）**：

> **Complete**: It suffices to show that `Mod(T) ⊆ Int(X,Y,I)`.
> Let `C ∈ Mod(T)`. **Assume `C ≠ C^{↓↑}`. Then `C` is a pseudo-intent**
> (indeed, if `P ⊊ C` is a pseudo-intent then since `||P ⇒ P^{↓↑}||_C = 1`,
> we get `P^{↓↑} ⊆ C`). **But then `C ⇒ C^{↓↑} ∈ T` and so `||C ⇒ C^{↓↑}||_C = 1`.**
> But the last fact means that if `C ⊆ C` (which is true) then `C^{↓↑} ⊆ C`
> which would give `C^{↓↑} = C`, **a contradiction** with the assumption `C^{↓↑} ≠ C`.
> **Therefore, `C^{↓↑} = C`, i.e. `C ∈ Int(X,Y,I)`.**

**这正是本实现的 `ClosedOfModel`**（「$M$ 是模型 $\Rightarrow$ $M$ 闭」）。

**证明骨架**（本实现据此转写）：
1. 设 $M$ 是模型且 $M\neq M''$；
2. **证 $M$ 是伪内涵**：对 $P\subsetneq M$ 且 $P$ 伪内涵，

   这正是伪内涵定义的条件 2（条件 1 即 $M\neq M''$，已设）；
3. 于是 $M\Rightarrow M''$ **属于 DG 基**；
4. 由 $M$ 是模型且 $M\subseteq M$，得 $M''\subseteq M$；
5. 结合扩展性 $M\subseteq M''$ 得 $M''=M$——**与步骤 1 矛盾**；
6. 故 $M''=M$，即 $M$ 闭。∎

**结论**：`ClosedOfModel` **不再是「找不到证明的缺口」**，
而是一条**有标准证明、只需转写**的引理——
**正是作者裁决 I 所预期的情形。**

## 裁决 R-024：**E8 谓词的结构缺陷已修**（主控诊断）—— 一类新失败形态

**状态**：已执行
**来源**：主控对 `E8Holds` 的精确诊断

### 一、缺陷内容

`E8Holds` **第一版**写作：

```lean
def E8Holds ... (_g) (_diam) (_C) (diamC : ℝ) : Prop := diamC ≤ _g form
```

**其缺陷**：`_diam` 与 `_C` **从未出现在右端**。

**主控的精确诊断（本实现照录）**：

> 该谓词**无法表达「这个集合的直径有界」**——它只说「某个数 ≤ 某个数」，
> 与集合 `C` 无关。所以它不只是"弱"，而是**结构上缺了一环**：
> `diamC` 没有和 `C` 通过 `diam` 联系起来。

**主控的判定测试**（本实现复核确认）：

```lean
example (F : Frame) (form : E8BoundForm) (g : E8BoundForm → ℝ)
    (diam : F.X.Carrier → F.X.Carrier → ℝ) (C : Set F.X.Carrier) :
    E8Holds F form g diam C (g form) := le_refl _
```

**该测试在旧谓词下编译通过**——对**任意** `diam`、`C` 都成立，
**证明旧谓词实际上没有断言任何东西**。

### 二、这是**一类新的失败形态**（与 R-022 并列）

| 编号 | 形态 | 特征 |
|---|---|---|
| **R-022** | **声明为假** | 注释里声称已证，而定理不存在 |
| **R-024**（本条） | **形式太松** | 定义看起来在说某事，**但参数没被用上**，故实际没说 |

**共同点**：**都是「看起来在说某事、实际没说某事」**。

**R-024 更隐蔽**：它**类型是对的、能编译、能通过所有自检**——
因为「用 `_` 前缀标注未使用」在 Lean 里是**合法的**，
linter 只给**提示**，不给**错误**。

### 三、修正

```lean
def E8Holds (F : Frame) (form : E8BoundForm)
    (g : E8BoundForm → ℝ) (diam : F.X.Carrier → F.X.Carrier → ℝ)
    (C : Set F.X.Carrier) : Prop :=
  ∀ x ∈ C, ∀ y ∈ C, diam x y ≤ g form
```

**修正后**：
- `diam` 与 `C` **真正被使用**；
- 谓词表达「$C$ 内任意两点的距离 $\le$ 界」——**正是 E8 想要的**；
- **`le_refl` 那类平凡构造不再可行**（目标是全称量化，不是 `a ≤ a`）；
- **仍不填 $g$ 的表达式**（那是 OQ-4 的事）。

**本修正属形式层，不涉及编码方案选择，故不违反「填数即为虚构」。**

### 四、连带修正：`e8_predicate_satisfiable` 的诚实边界

**旧版**：该定理对**任意** `diam` 与 `C` 由 `le_refl` 成立
（因旧谓词与二者无关）。

**修正后**：该定理**只对空集 $C$ 成立**——
即「非空胞腔上的界」**不能**由它给出。

**故其 doc-comment 已改写**，明确写出「**修正后，本定理只对空集成立**」，

**这与旧版（对 $g$ 无任何约束）形成对照。**

## 裁决 R-026：**A3 —— 「恰好拟合/过拟合边界」的形式化**（登记为裁决项）

**状态**：📋 **已登记为裁决项**（本实现**不自行选定**）

### 一、为什么本实现不自行选定

裁决 K 要求「误差 ≈ 噪声尺度」。**要把这句话变成定理，必须先确定**：

| 待定项 | 为什么须作者裁决 |
|---|---|
| **「误差」的度量** | 胞腔直径？Wasserstein 距离？二者在**非欧状态空间**上不可比 |
| **「噪声尺度」的定义** | 创新 sd？边缘 sd？（本轮实测二者差 **12 倍**：0.05 vs 0.6051） |
| **「≈」的容差** | 相差 2 倍算合格吗？$\sqrt2$ 倍？1 个数量级？ |
| **「不影响结论」的量化** | 「影响」须先定义下游结论的**敏感度** |

**这些是语言层选择**，本实现**不替作者决定**（同 R-013 的合规原则）。

### 二、本实现能提供的：**可用的形式骨架**（**不选定**）

本实现给出**参数化的谓词形状**，把选择权留给作者：

$$\mathrm{Qualified}(\mathrm{diam}, \sigma, \mathrm{tol})
  := \frac{\mathrm{diam}}{\sigma} \le \mathrm{tol}$$

**其中**：
- $\mathrm{diam}$：编码误差（本实现已有 `Encoder.Fiber`、`CellDiameter`）；
- $\sigma$：噪声尺度（**本轮 A1 已给出候选：创新 sd = 0.05**）；
- $\mathrm{tol}$：容差（**待作者定**；裁决 K 的「恰好」暗示 $\mathrm{tol}=1$，
  即「相等」，但**实测不会是精确相等**，故必须有容差）。

**⚠ 本实现不实现该谓词**——因为 $\mathrm{tol}$ 未定，
**实现它等于替作者选定容差**。

### 三、关键实测事实（供作者裁决时参考）

**本轮 A2 实测显示**：即使 $q=7$，$\mathrm{diam}/\sigma_{\text{创新}} = 10.0$。
**故若 $\mathrm{tol}=1$，则本方案离合格差 1 个数量级**（见 R-025 §四）。

**另一条关键事实**：$\sigma$ 的两个候选差 12 倍：
- 取**创新 sd** ⇒ 差 15.3 倍（不合格）；
- 取**边缘 sd** ⇒ 差 1.265 倍（**接近合格**）。

**⟹ 选哪个 $\sigma$ 直接决定合格与否。这是须作者裁决的实质问题。**

## 裁决 R-031：**多值属性 FCA 实测**（裁决 N 第 4 项）—— ⛔ **亦不可行**

**状态**：✅ 已清（**实测完成，结论已得**）
**依据**：作者裁决 N 第 4 项「测多值属性 FCA（唯一可能绕开指数爆炸的方向）」

### 一、为什么它被寄望绕开

| 方案 | 属性数 | 后果 |
|---|---|---|
| 单值（已测，R-029） | $k\times d$（**随分辨率线性增长**） | 闭集枚举 $=2^{kd}$ ⟹ 加密必爆 |
| **多值/刻度化** | $d$（**与分辨率无关**） | 闭集枚举 $=2^{d}$ ⟹ **不随分辨率增长** |

### 二、实测（**两规模 × 8 档分辨率**）

**⚠ 第一版失败（如实记录）**：朴素 scale/context 变换把「状态 × 刻度」当新对象，
对象数 $=T\cdot k$ ⟹ **把指数从属性侧搬到对象侧**，超时。**保留为负面结果。**

**第二版（正确做法）**：属性 $=d$ 个坐标，刻度只改阈值 ⟹ 属性数与对象数**均与 $k$ 无关**。

| T | k | #obj | **#attr** | **max#闭集** | maxdiam | **d/创新sd** |
|---|---|---|---|---|---|---|
| 200 | 3 | 200 | 3 | **8** | 1.1606 | 23.2 |
| 200 | 40 | 200 | 3 | **8** | 1.1606 | 23.2 |
| 200 | 60 | 200 | 3 | **8** | 1.1606 | 23.2 |
| 1000 | 3 | 1000 | 3 | **8** | 1.3233 | 26.5 |
| 1000 | 40 | 1000 | 3 | **8** | 1.2978 | 26.0 |

**⟹ 格确实【不爆炸】（恒为 8）——但误差也【完全不动】（恒为 23–27 倍）。**

### 三、⭐ **根因：两个上界被【同一个量】锁死**

$$\text{属性数}=d \Longrightarrow
\begin{cases}
\text{格规模}\le 2^{d} \\
\text{胞腔数}\le 2^{d}\ \Longrightarrow\ \text{胞腔直径}\gtrsim \mathrm{span}/2^{d}
\end{cases}$$

**⟹ 「格不爆炸」与「误差不降」是同一件事的两面，不是两个独立的好/坏消息。**

**诊断实测**（扫 $d$，固定 $T$）：

| $d$ | $\mathrm{span}/2^d$（理论下界） | 实测 maxdiam | 实测/理论 |
|---|---|---|---|
| 2 | 0.6204 | 1.3284 | 2.14 |
| 3 | 0.3149 | 1.1606 | 3.69 |
| 4 | 0.1497 | 1.1993 | 8.01 |
| 5 | 0.0679 | 1.0753 | 15.83 |
| 6 | 0.0366 | 1.1975 | 32.74 |

**误差确实按 $1/2^d$ 下降，但实测远大于理论下界**（比值 $2.14\to32.74$，
说明真实胞腔**远大于**均匀立方体）⟹ **要达噪声尺度，所需 $d$ 比理论值更大（更糟）。**

### 四、结论

**⛔ 多值属性 FCA【不能】绕开指数爆炸。**

它**只是把瓶颈从「$k\cdot d$」换成「$d$」**——
**而「格规模」与「误差」仍由同一个 $d$ 反向锁定，不可兼得。**

**⟹ 这加强了 R-029 的结论**：在本编码族（含多值）下，
**FCA 入口无法同时满足裁决 K 的两条要求。**

**⚠ 边界（不过头）**：
- 本结论覆盖「单值阈值谓词」**与**「多值/刻度化」**两类**编码；
- **未覆盖**：**pattern structures（真正的多值形式背景，非阈值化）**、
  **三元 FCA**、**粗糙集 FCA**——这些在档案中有源码（`RealFCATriadic`、`RealFCARoughSet`），
  但**本实现未逐一实测**（**登记为未测，非「不可做」**）。

### 二、⭐ 问题 1：能否用「梯度力 ÷ 历史惯性」替代外部阈值 σ？

**评估结论：部分能，但代价明确。本实现给出三条限制。**

**本实现的关键观察**：

| 原文概念 | 统计对应物 |
|---|---|
| **历史惯性** | **噪声尺度的估计量**（偏差序列去趋势后的波动） |
| **梯度力** | **系统性趋势**（偏差序列的确定性部分） |
| ⟹ **判据 = 信噪比** | $\lvert\text{梯度力}\rvert / \text{惯性}$ |

**⟹ 该判据只需历史序列，不需外部 σ ⟹ 确实能破 R-026 的循环。**

**⚠ 但三条限制（本实现实测得出）**：

| # | 限制 | 实测依据 |
|---|---|---|
| 1 | **判据变成「逐点」的** —— 每轮估一次，**不再是全局常数 σ** | 故 R-026「σ 取哪个」**被消解**，但换成「每轮判据可能不同」 |
| 2 | **需要历史序列** —— 循环**头几轮无历史**，判据不可用 | 须有初始轮次（本实现未解决） |
| 3 | **阈值 τ 仍是选择** | 实测：τ=1.0 判对 **12/16**；τ=2.0 判对 **10/16** |

**⟹ 故本实现**不声称**它完全消除循环依赖**——
它**去掉了外部 σ**，但**引入了 τ 与历史长度两个新参数**。

**⚠ 一处自我更正（如实记录）**：
本实现**第一版测试**预设「有趋势就该 continue」，得出 6/10 的判对率，
一度误判为「判据不佳」。**复核后发现是我的期望标签错了**——
真值应是「**累计趋势 > 2σ 才该 continue**」（否则信息不足，停是对的，正是裁决 K）。
**按正确真值重测后**，判据与真 SNR 高度一致（见 `results/closure_criterion2.json`）。
**本实现保留这次误判的记录**，因为它正是「期望标签错 ≠ 判据错」的实例。

### 三、⭐ 问题 2：是否补「非平凡性判据」？

**评估结论：值得补，但本实现只能给出骨架——因为原文的三个核心概念都未形式化。**

**原文判据**（`[哲学依据]` 4.2/4.3 逐字）：

| 类型 | 判据 |
|---|---|
| **平凡循环** | $\Sigma_{t+1}\cong\Sigma_t$ |
| **非平凡循环** | **不同构** ∧ 存在**无法由 $\Sigma_t$ 有限参数微调导出**的新关系 |

**⚠ 原文的三个未定义项**：「结构 $\Sigma$」「同构 $\cong$」「有限参数微调」。

**本实现的处置**（**不假装它们已定义**）：
把它们做成 `CycleStructure` 的**显式参数**（`S` / `SIso` / `Derivable`），
并**显式要求** `SIso` 是等价关系（不自称「同构」而暗中假定）。

**已形式化的**：
- `IsTrivialCycle` / `IsNontrivialCycle`；
- **`trivial_not_nontrivial`**：二者**互斥**（已证，仅用标准公理）。

**⭐ 本实现发现的**缝隙**（原文未讨论）**：
**「不同构但可由微调导出」的第三种情形既非平凡也非非平凡。**
**⟹ 故二者不是二分**——本实现在 doc-comment 中**如实标注该缝隙**。

**这对命运理论的意义**：命运理论**确实只有「误差」判据**，
**无「是否有新结构」判据**。补它有价值，**但须先形式化「结构」**——
而那是**独立工作量**（本实现**未做**，登记为后续）。
