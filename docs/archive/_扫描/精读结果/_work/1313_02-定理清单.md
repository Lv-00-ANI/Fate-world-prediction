## 一、编目规则

### 1.1 编号方式

本清单使用**层号 + 层内序号**的两段式编号，与主文档的「章号 + 序号」完全分离，二者不得混用。

| 形式 | 含义 | 例 |
|---|---|---|
| `T<层号>.<序号>` | **定理条目**（有真假的陈述，本清单的主体） | `T2.4` = 第 2 层（图与条件独立）第 4 条 |
| `A<n>` | **公理级假设编号** | `A19` = 因果图 $G$ 已知 |
| `O<n>.<m>` | **开放问题编号**（沿用主文档第 8 章 8.5 的分级编号） | `O8.1` |
| `[已知]` | 外部既有结果 | 后门准则 |
| `[已知·未核验]` | 外部既有结果，出处未核验 | DG 基原文献 |

**层号取值 $0$–$8$，含义固定**：

| 层 | 名称 | 数学内容 |
|---|---|---|
| **L0** | 基础 | 集合、测度、概率空间、路径测度、可测性 |
| **L1** | 代数与序 | 格论、Galois 连接、形式概念分析（FCA） |
| **L2** | 图与条件独立 | DAG、d-分离、马尔可夫性、因子分解 |
| **L3** | 因果结构 | SCM、`do` 算子、识别性（后门／前门／do-calculus） |
| **L4** | 反事实 | 反事实定义、三步计算、反事实误差界 |
| **L5** | 轨迹生成 | 动力系统、稳定性、随机过程、SDE、离散化 |
| **L6** | 规则层 | 规则的形式结构、$\alpha/\gamma/\circ/\upsilon$ 的代数性质 |
| **L7** | 预测与误差 | 预测问题、误差分层、条件误差界 |

**编号纪律**（承 `03-规范与裁决/05-公理与章序规范.md` §2.5.2 第 4 条）：

1. **编号一经分配，永不复用**。条目被删除时编号留空并标注「（已删除）」，后续条目**不上移补位**。
2. **同一编号不得承担两种类别**。一条编号在全文只能绑定一个类别标签与一个命题内容。
3. **类别发生实质变更时分配新编号**，并注明旧编号作废。
4. 本清单的层内序号**连续但不保证按依赖排序**；依赖顺序由「依赖」栏显式给出，读者应按依赖栏拓扑排序，不得按编号顺序阅读。

**编号与主文档的对照**：主文档第 8 章把 32 条公理级假设按类型三分（15 定义性约定 / 11 待证命题 / 6 不可证的经验假设）。本清单**只接管其中的「待证命题」部分**（即 A5、A6、A7、A8、A10、A11、A15、A21、A25、A30、A32 共 11 条），把它们展开为可证命题；**定义性约定**（15 条）不产生定理，**不可证的经验假设**（6 条）进入第三节单独登记。**依作者裁决 F，A33、A34 已正式加入为 A33/A34（原为候选），二者属「普适性前件」**，其作用域覆盖所涉定理的全部对象，见 §3.4。

### 1.2 三类归属的判定

判据直接取自 `00-总纲.md` 第二节，此处给出**可机械执行的判定程序**：

```
输入：一条陈述 S
1. 问：S 是否断言「真实世界的某对象满足某条件」？
   - 是 → 类别 = ③ 经验假设 → 不列入本清单第二节，改录第三节
   - 否 → 继续
2. 问：S 在给定其全部前件后，是否只依赖数学上已定义的对象？
   - 是 → 类别 = ① 可证（若本框架内已完成证明）或 ② 条件可证的前件为空的特例
   - 否 → 继续
3. 问：S 是否形如「若 H 成立，则 C 成立」，其中 H 的成立性需实验或领域知识确认？
   - 是 → 类别 = ② 条件可证
   - 否 → S 不是良构陈述，退回重写
```

**三类在本清单中的书写规范**：

| 类别 | 标签 | 书写要求 |
|---|---|---|
| **① 可证** | `[可证]` | 命题即结论，无前件。**若框架内已证完则标 `[可证·已证]`；本清单当前无此标记** |
| **② 条件可证** | `[条件可证]` | 命题必须写成 `H → C` 的显式形式；H 逐条列出；H 的来源（定义性约定 / 经验假设 / 待证前提）必须标注 |
| **③ 经验假设** | `[经验假设]` | **不进入第二节条目表**，只登记于第三节 |

**一条硬性纪律：条件定理的前件必须是「已命名的对象」**。禁止出现前件为「模型足够正确」「假设大致成立」一类未命名谓词的条目——这类前件无法在 Lean4 中写成类型，也无法在实验中判定。原文中「可接受的误差界」(`O8.2`) 就是这类未命名谓词的典型，本清单**不为它立任何定理**。

**关于 `[已知]` 条目的计数口径（重要）**：本清单中有 33 条标 `[已知]` 或 `[已知·未核验]`。**它们在「类别」栏中仍归入 ② 条件可证**，理由是：

> 一条外部既有结果 $R$ 在原语境下是无条件定理，但**在本框架中使用它时，必然携带一组接口前件**（「本框架的对象与 $R$ 的对象是同一类」）。因此，**本框架意义上的 $R$ 是一条条件定理**，其前件就是第五节的适配性命题 T9.x。

这一计数口径的实践后果是：**33 条 `[已知]` 条目并不构成本框架的「免费午餐」**。它们省下的是「证明 $R$ 本身」的工作，但**必须付出「证明 T9.x」的工作**。**这两项工作在量级上不同（前者通常是后者的一到两个数量级），但后者不可省。**

### 1.3 依赖表示法

**依赖栏**用三种记号，可混用：

| 记号 | 含义 | 例 |
|---|---|---|
| `T<层>.<序号>` | 依赖另一条定理 | `T3.4 ← T2.4` |
| `A<n>` | 依赖某条公理级假设的前件 | `T3.4 ← A19` |
| `D<n>.<m>` | 依赖某条定义（取自主文档章号.序号） | `T3.1 ← D3.1` |
| `—` | 无依赖（层内本原条目） | |

**三条依赖规则**：

1. **依赖必须指向本清单已编号的条目，或已命名的定义/假设**。禁止写「依赖第 3 章的一般结论」这类不具名指称（承 `03-规范与裁决/05-公理与章序规范.md` §2.4.2）。
2. **依赖不得成环**。若出现环，说明两条命题共享一个未显式化的共同前提，须把该前提提出为新的假设条目。
3. **跨层依赖只允许从低层指向高层**。若出现高层指向低层的依赖，该依赖实质是「高层结果用于低层的应用」，应改记为旁注而非依赖。

### 1.4 Mathlib 现状两栏

**两栏必须分开**（承 `00-总纲.md` 第三节）。表中直接给一栏合并写法 `原则上/现有覆盖`：

- **原则上可形式化**：几乎全部条目均为「是」。唯一需要讨论的是那些**前件本身不可形式化**的条目（它们已在 1.2 的判定程序中被过滤）。
- **Mathlib 现有覆盖**：取值 —— `有`（可直接调用）/ `部分`（有构件需补胶水）/ `无`（须自建）。

**一条对本路线有工程含义的结论**（承 `00-总纲.md` 第三节末）：

> Mathlib 缺因果推断**不是「正在补的缺口」，而是「不在其选题范围内」**。L2–L4、L6、L7 的全部条目**必须自建库**，不能等上游供给。这与「先填坑再动手」是不同的工程含义：自建库的接口设计必须一次性对齐，因为上游不会替你收敛。

## 四、条件定理的前件清单

> **本节的地位**：它是「**证明**」与「**实验**」的分界线。一条条件定理在被证明之后，其前件的成立性**只能由实验或领域知识确认**——这正是 `00-总纲.md` 第二节的判据：**实验的作用是确认条件定理的前件，而不是替代证明**。

### 4.1 前件的三种来源

条件定理的前件按来源分三类，**三类的确认方式完全不同**：

| 来源 | 含义 | 确认方式 | 本清单中的例 |
|---|---|---|---|
| **定义性约定**（D 类前件） | 我们决定采用的语言层选择 | **不需确认**。它是选择，不是事实。只需声明 | A17（干预入机制）、A28（四个空间有结构） |
| **经验假设**（E 类前件） | 关于真实世界的断言 | **只能由实验或领域知识确认**，框架内不可证 | E1–E7 |
| **待证前提**（T 类前件） | 框架内原则上可证、当前未证的命题 | **可由证明确认**（即它其实是另一条定理的前件链） | A5（类型保证组合合法）、A10（轨迹存在性） |

**一条操作纪律**：**任何条件定理的前件集合中，至少要有一项是 D 类或 E 类**。若一条条件定理的全部前件都是 T 类，则它实质上是一条无条件定理，只是尚未把前件证完——此时应把它写成两条定理（一条证明前件，一条使用前件），而不是一条带头重前件的条件定理。

## 七、最难的一条

### T3.11　do-calculus 的完备性

> **命题**：若 $P(Y\mid do(X=x))$ 在可识别模型类 $\mathfrak{M}$ 上可识别（定义 3.7），则存在一个仅用三条规则（T3.8–T3.10）构成的**有限推导序列**，把它改写为不含 $do$ 的表达式。

**选它的理由有四条，逐条独立：**

**理由一：它是全清单中唯一一条「不可绕过」的困难。**
其余高难度条目在主线上可绕开——T5.10（Hartman–Grobman）、T5.11（Lyapunov 指数）、T5.16（Itô 引理）**在本框架的主链（实例 → 规则 → 预测）上不是必需的**：主公式 (4.1)、(4.2) 不依赖它们。**但依作者裁决 C「不降级、不移出、不暂缓」，「主线上非必需」不再推出「不为它们分配工作」**——这三条已纳入自建随机分析库的范围（见 [`02-Mathlib缺口.md`](03-Mathlib缺口与自建库.md) §3.3，连续情形全量形式化）。**它们在路线中的地位是「非主链但仍必做」**，因此 T3.11 的「不可绕过」判据仍然成立，只是其独占性减弱：**T3.11 与 T5.10／T5.11／T5.16 同属「必做但极重」的一档**。**T3.11 的额外特殊性在于**：本框架第 3 章的中心判据是「识别性」（定义 3.7），而后门准则（T3.6）与前门准则（T3.7）**都是识别的充分条件而非必要条件**——主文档说明 3.3.1 明写「存在既不受后门也不受前门覆盖、但仍可识别的因果效应（由 do-calculus 的逐条改写给出）」。**要覆盖全部可识别的情形，只能靠完备性。** 没有 T3.11，L3 的「识别」判据就是不完整的。

**理由二：它的形式化前提本身需要先建立，而这些前提在 Mathlib 中一条都没有。**
要把 T3.11 写进 Lean，须先有：
- **D3.1–D3.4 的形式化**（SCM 四元组、结构方程、诱导图、`do` 算子）——Mathlib 无；
- **T2.1–T2.10 的形式化**（d-分离、马尔可夫性、因子分解、马尔可夫等价类）——Mathlib 无，**这是十级台阶**；
- **T3.14 的形式化**（识别性的类型化定义）——Mathlib 无，且**它的难点不在数学而在类型设计**：如何把「泛函 $g$ 不依赖结构方程集 $\mathcal{F}$」写成 Lean 里的类型约束，而不是一句自然语言；
- **T3.8–T3.10 的形式化**（三条规则的可靠性）——Mathlib 无。

**这四组前提每一项本身都是「高」难度**。T3.11 的难度不是「高难度条目之一」，而是**上面四组高难度条目的汇合**。

**理由三：它的证明结构不能照搬。**
外部证明的典型路线是「hedge（嵌套的 $do$ 表达式正规化）」。该证明依赖：
- 对**表达式结构**的归纳（须先形式化「$do$ 表达式」的语言）；
- 对**图**的归纳（须先形式化图操作与 d-分离的交互）；
- 一个**不变量**（每次规则应用不改变所表示的分布）。

把这三者适当形式化的成本极高，且现有证明的写法是为人类读者设计的、以大量「显然」「类似地」简化的——**形式化必须把这些全部展开**。

**理由四：它同时是「外部结果」与「适配性命题」的双重负担。**
T3.11 的证明由外部给出（本框架内未证）。但按第五节的结论，**外部结果不能直接搬用**——本框架必须补证 T9.2（SCM 四元组满足外部的正则性条件）、T9.3（四个删边图记号定义一致）、T9.4（识别性定义等价）。**T9.4 尤其关键**：本框架把「不依赖 $\mathcal{F}$」写成类型约束，而外部定义的「不依赖模型」是一个更大的类——**两者不等价时，T3.11 的完备性内容就与本框架所需的不同**。
