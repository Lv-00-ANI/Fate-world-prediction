**`pipeline_tendsto` 的签名（逐字）：**

```lean
theorem pipeline_tendsto (η θstar x θ₀ : ℝ) (hx : x ≠ 0) (hη : |1 - η| < 1) :
    Filter.Tendsto
      (fun n : ℕ => pipelineN linWorld (id : ℝ → ℝ) η

- `η θstar x θ₀ : ℝ` —— 全是**一维标量**

    errA A x' (wbW A φ η x' θ) < errA A x' θ
```

**载体是任意 `A : E →L[ℝ] F`——观测算子可以是任意有界线性映射，这才是真的泛化。**

## B.2 五个必须知道的口径陷阱

[System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding($false)))
