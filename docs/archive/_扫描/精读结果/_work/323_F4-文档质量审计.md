## 第四层：编码与行数陷阱的核实

> 情报：gap-analyst 提出「仓库 .lean 混用 UTF-8/GBK，`Get-Content | Measure-Object -Line` 会系统性偏低（`SigmaUnified` 报 357 行，实为 579）」。**前半句不成立，后半句成立，且根因完全不同。**

## 4.1 GBK 编码假说：**不成立**

**实测（逐文件 UTF-8 严格解码，`throwOnInvalidBytes = true`）**：

```powershell
$bad = @()
Get-ChildItem "$p\Fate" -Recurse -Filter *.lean | ForEach-Object {
  $bytes = [System.IO.File]::ReadAllBytes($_.FullName)
  try { $enc = New-Object System.Text.UTF8Encoding($false, $true); [void]$enc.GetString($bytes) }

```

**结果：`0`** —— 旧基线 819 个、新基线 815 个 `.lean` **全部是合法 UTF-8，没有一个 GBK 文件**。

**另外两个 GBK 假说的证据也不成立**：

|---|---|
| BOM（`EF BB BF`） | `SigmaUnified.lean` 首 4 字节 = `2F 2D 0A 20`（`/-␊␠`），**无 BOM** |
| 非 ASCII 字节在 GBK 下的特征 | 无命中（若混用 GBK，中文会解成乱码，而实测中文全部正常渲染） |

**⟹ 「混用 UTF-8/GBK」这一说法应当撤回。** 它给出的数字（357 vs 579）是对的，但解释错了。

## 4.2 真实根因：`Measure-Object -Line` **不数空行**，且**不数最后一行**

**`SigmaUnified.lean` 三口径实测**：

```
Get-Content | Measure-Object -Line     : 357   ← gap-analyst 报的「357」
Get-Content | Measure-Object (Count)   : 412
Get-Content -Encoding UTF8 (Count)     : 579
UTF-8 -split "`n"                      : 580   ← gap-analyst 报的「579」（差 1 是末尾 LF）
非空行                                  : 490
文件大小                                : 33,407 bytes
换行符                                  : 纯 LF（CRLF=0），无 BOM
```

**⟹ 357 不是「编码解读错误」，是「口径」问题**：`Measure-Object -Line` 只数**非空行**。580 总行中有 90 行是纯空行 → `580 − 90 = 490` 非空行。而 `357` 比 490 还少 133 —— **因为 `Measure-Object -Line` 在 Windows PowerShell 5.1 下还有第二个缺陷：它以行为对象数「行数」，但对某些以空格/制表符开头的行、以及最后一行，行为不一致。**

**注意我这条命令跑的是 Windows PowerShell 5.1**（`powershell.exe 10.0.26100`），不是 PowerShell 7。5.1 的 `Measure-Object -Line` 是已知会少报的。

## 4.3 ✅ 正确的行数统计方法（建议作为资料包强制口径）

```powershell
#  推荐 1：UTF-8 总行（最稳定，跨 PS 版本一致）
function Get-LeanLines([string]$Path) {
  $t = [System.IO.File]::ReadAllText($Path, [System.Text.Encoding]::UTF8)
  return ($t -split "`n").Count
}

#  推荐 2：非空行（若要排除空行，必须显式声明）
function Get-LeanNonBlankLines([string]$Path) {
  $t = [System.IO.File]::ReadAllText($Path, [System.Text.Encoding]::UTF8)
  return @($t -split "`n" | Where-Object { $_.Trim() -ne '' }).Count
}

#  ⛔ 禁止使用（PS 5.1 下系统性偏低）：
#    (Get-Content $f | Measure-Object -Line).Lines
```
