# 二、四个候选的详细展开

**先说清楚一件事**：下面四个候选的「在 Lean 里会是什么类型签名」，**不是本文发明的**——它们由三个已存在的 Lean 事实**限定**：

- `Frame.lean:709`：`abbrev Alpha (E : InstSpace) (C : CtxSpace) (X : StateSpace) (Y : OutSpace) := E.Carrier → Rule C X Y`
- `LawRule.lean:69-71`：`def LawRule (C) (X) (Y) := C.Carrier → X.Carrier → Set (MeasureTheory.Measure Y.Carrier)`
- `MainLoop.lean:90-96`：`abbrev Level := ℕ`；`def abstractUp (n : Level) (k : ℕ) : Level := n + k`；`def deconstructDown (n : Level) (k : ℕ) : Level := n - k`

⟹ **「R 从循环哪一步出」在类型上只能落成三种形状之一**：
1. **常量形**：`LoopState → LawRule`（每个循环状态配一条规则）——**这与循环动力学无关，是退化形**；
2. **转移形**：`LoopState → LoopyState` 之外再挂 `Rule`，即 `(State × LoopState) → LawRule` —— **这是唯一真正利用循环的形**；
3. **不动点形**：`{s // step s = s} → LawRule` —— 需要稳态存在，而 `MainLoop` 已证明稳态**在 `0 ≤ margin` 时 1 步就到**（见候选 D）。

⚠ **一个本文必须点明的关键不对称**：`MainLoop.lean` 的循环**不带状态**。它的 `LoopState` 是 `running | paused` 二值，`step` 只依赖 `(info, noise, margin, s)`，**不含任何规则、分类结构或因果结构**。所以「R = 循环产物」若要在 Lean 里落地，**必须先给循环换载体**——这是所有候选里唯一有「重构成本」的地方。这个成本**四个候选都要付**，只是付法不同。

### C.3 反对它的论据

**（a）最硬的一条（本文的独立判断，非引原文）**：**元规则与「预测」之间没有连接**。理论的目标链条是「规则集 → 预测」（净版第 7 章、`Frame.lean:782` `abbrev Pred X := Measure X`）。元规则是**二阶**对象，它不直接产出 `Pred`。要接上必须再加一层「元规则 → 规则 → 预测」，**多一层就多一个未定义的 $\gamma/\upsilon$ 语义问题**。

**（b）净版已明文禁止在这种二阶对象上预设任何关系**（`10-命运理论-净版.md:1947`）：

### D.2 支持它的论据

## §二.6 ⭐ 四个候选之间的关系：它们不是四选一

**这是本文最重要的一节。** 四个候选在文档里被并列成 ABCD，但**它们在数学上不是同一层的对象**：

| 候选 | 在循环里的位置 | 类型的形状 | 是否依赖「多轮」 |
|---|---|---|---|
| **A（R = U）** | 循环的**一个算子** | 常量/映射 | ❌ 不需要轮次 |
| **B（R = 循环产物）** | 循环**每轮的出口** | `轮次 → 规则集` | ✅ 需要 |
| **C（R = 元规则）** | 循环的**控制层** | `规则 → 规则` | ❌ 不需要 |
| **D（R = 稳态）** | 循环**收敛后的那一轮** | `不动点 → 规则` | ❌ 只需最后一步 |

**⟹ 真实的可选结构只有三条**：

1. **A**（R 是循环内部的一个算子本身）——**把问题消解掉**：规则不从循环出来，规则就是循环的一部分；
2. **B**（R 是循环每轮的出口）——**D 是 B 的一个特例**（B 只输出「最后那一轮」就是 D；B 输出「每一轮」且取 `LawRuleLattice` 的**格交**（= `∘` 取交）就是 D 的固定点）；
3. **C**（R 是循环的控制层）——**引入二阶对象，必须同时裁定 γ/υ 语义**。

**且 A 与 B 不冲突**：A 说「U 是规则集合」，B 说「每轮产一批规则」——**「每轮的产物就是那一轮的 U」** 就是文档里主控倾向的「A+B」。这个组合**既有原文定义支撑（A），又有循环结构支撑（B）**。

**⟹ 本文的判断：真正需要作者裁定的不是「A/B/C/D 选一个」，而是两个更小的判断：**

> **判断 ①（层级）**：规则是**循环内部的一个算子**（A），还是**循环的出口**（B/D）？
> **判断 ②（单轮 vs 多轮）**：若取出口，规则是**只取最后那一轮**（D），还是**每轮都产、并累积/取交**（B）？

**C 不在必选集里**——它是「A 或 B 的额外加强」，且代价是引入新的待裁决项。

## 4.2 §5.1–5.2：规则的形式定义与三条属性

**定义 5.1（规则）**（`:1747-1753`）：

> **规则** $R$ 是一条**带上下文的映射**：
> $$R:\ \mathcal{C}\times\mathcal{X}_{\text{local}}\to\mathcal{Y}$$
> 其中 $c\in\mathcal{C}$ 为上下文（条件）空间中的一点，$x\in\mathcal{X}_{\text{local}}\subset\mathcal{X}$ 为局部状态，$y\in\mathcal{Y}$ 为输出、预测或行动

**定义 5.2（条件分布形式，本章主用）**（`:1755-1761`）：

> **规则** $R$ 是一个**条件分布核**：
> $$R:\ P(y\mid x,c)$$
> 即，$R$ 关于 $(x,c)$ 给出的不是一个点值，而是 $\mathcal{Y}$ 上的一个分布

**本章的择一决定**（`:1763`）：

> **本章以定义 5.2 为主用形式**，理由是：分布形式可容纳概率规则与确定性规则两种情形，而映射形式只是核退化为点质量时的特例

**⚠ 与 Lean 的不一致（必须指出）**：净版说「以定义 5.2（条件分布核）为主用形式」，但 **Lean 的唯一实际载体是 `LawRule := C → X → Set (Measure Y)`**（集合值），而「条件分布核」在 Lean 里是 `Frame.lean:348` 的 `structure Rule`——**后者现在只是 `LawRule` 的子集**（`LawRuleRuleBridge` 主定理：`R ∈ im(Rule.toLaw) ⟺ IsPoint R`）。**⟹ 净版的「主用形式」在 Lean 里已被反转为「特例」。**

**定义 5.5（时效性）**（`:1808-1814`）——**这是「规则有版本」的唯一正式落点**：

> 规则 $R$ **具有时效性**，当且仅当它在时间上非平稳：
> $$P(y\mid x,c,t)\ \neq\ P(y\mid x,c,t'),\qquad t\neq t'$$
> **这是规则层中唯一一条具备完整数学表述、且可检验的命题。** 时变情形下，规则写作 $R_t$。

**证据 1（最强，理论文本级）**：净版 §5.4.1 的加粗统一表述是「**规则是实例集合在等价关系下的代表元（实例的商）…其数学原型是 Galois 连接的不动点结构**」。**「取商」是操作，「不动点」是反复操作的结果 ⟹ 这句话的语法本身就要求一个迭代过程。** 循环是唯一候选。⟹ 支持 B（多轮取商）+ D（直到不动）。

**证据 2（强，Lean 现状级）**：**「循环产物 → 规则」的函数形状在 Lean 里已经存在且已证关键性质**（§3.4）：

**⟹ 选 B 的落地成本是四个候选里**已经被付掉最多的一个**。** 这条路只缺「把输入从 `D` 换成 `Round`」这一层薄壳。

**证据 3（中，一致性级）**：净版定义 5.5（时效性 `R_t`）与定义 5.8（`R_{t+1} = υ(R_t, Data_t)`）**已经把规则层做成了时间序列**。B 的「每轮产一批规则」与这两个定义**逐字相容**；A 的「R 随 U 变化」没有承接这两个定义；C 与 D 都不涉及时间序列。
