### G. TD-32 —— ⭐ σ（非负标量）与 `ε`（距离）的直接相减不合法

**① 现状（Lean 原文）**
- `ScoreK.lean:52`（C3 §2.1 实测引）：`def bandLoss σ ε := max 0 (max (σ/2 - ε) (ε - 2σ))`；
- `ErrDefinitions.lean`：`def trackErr (d : X → X → ℝ) (trueTraj : ℕ → X) (n : ℕ) : Scenario A X → ℝ := fun s => d (s.traj n) (trueTraj n)` ⟹ **`err` = 距离 `d` 的值**；
