## 1. 引言

### 1.1 FCA 是什么

形式概念分析（Formal Concept Analysis, FCA）由 Rudolf Wille 于 1982 年提出 [Wille 1982]。
它的出发点是**一个二元关系**——形式背景（formal context）$\mathbb{K} = (O, A, I)$，
其中 $O$ 是对象集，$A$ 是属性集，$I \subseteq O \times A$ 是「对象 $o$ 具有属性 $a$」的满足关系。

FCA 的全部结构由两个**反变**算子生成：

$$\text{extent}(B) = \{o \in O \mid \forall a \in B,\; oIa\},
\qquad
\text{intent}(X) = \{a \in A \mid \forall o \in X,\; oIa\}.$$

二者的复合给出两个**闭包算子**，其不动点称为**形式概念**（formal concept）：一对 $(X, B)$ 满足 $X = \text{extent}(B)$ 且 $B = \text{intent}(X)$。
全体形式概念在「外延包含」序下构成一个**完备格**——**概念格**（concept lattice），
并且 FCA 的**基本定理**说：完备格恰是概念格（在同构意义下）。

FCA 的应用远超其数学核心：分类系统（taxonomy）、本体工程（ontology engineering）、
数据挖掘（association rules、frequent itemset）、知识发现、软件重构（class hierarchy recovery）。

### 1.2 为什么值得形式化

FCA 的三条主干——**Galois 连接**、**闭包算子**、**概念格**——在纸面上都很短，
但围绕它们有一整套**依赖细节的定理**：

* 反变伴随的「保极限」形态到底是什么（保并还是保交）？
* 概念格的 ⊓/⊔ 是**无条件**格运算，还是需要输入是概念？
* 概念格**一般不是分配格**——那么哪些格律能证、哪些是假命题？
* Duquenne–Guigues 基的「基」是一个**算法对象**还是一个**性质谓词**？

这些问题靠阅读文献容易出错，因为在纸面上「方向」往往被省略。**机器检查的价值在于它不允许方向含糊**。

## 2. 基本构造

### 2.1 形式背景与两个算子（定义）

**定义 2.1（extent / intent）** [`RealFCA.lean:62,65`]

```lean
def extent {O A : Type*} (R : O → A → Prop) (B : Set A) : Set O := {o | ∀ a, a ∈ B → R o a}
def intent {O A : Type*} (R : O → A → Prop) (O' : Set O) : Set A := {a | ∀ o, o ∈ O' → R o a}
```

与 Ganter–Wille [GW1999, Def. 1] 的 $B' = \{o \mid \forall a \in B: oIa\}$、$X' = \{a \mid \forall o \in X: oIa\}$ **逐字一致**。
**身份：与经典一致（定义，不声称内容）。**

### 2.2 反变单调

**定理 2.2（反变单调）** [`RealFCA.lean:71,77`]

$$B_1 \subseteq B_2 \Rightarrow \mathrm{extent}(B_2) \subseteq \mathrm{extent}(B_1), \qquad X_1 \subseteq X_2 \Rightarrow \mathrm{intent}(X_2) \subseteq \mathrm{intent}(X_1).$$

`theorem extent_antitone` / `theorem intent_antitone`。
经典陈述（$B_1 \subseteq B_2 \Rightarrow B_2' \subseteq B_1'$，[GW1999, Lemma 1]）。**身份：与经典一致。**

### 2.3 扩张律

**定理 2.3（扩张）** [`RealFCA.lean:86,91`]

$$X \subseteq \mathrm{extent}(\mathrm{intent}(X)), \qquad B \subseteq \mathrm{intent}(\mathrm{extent}(B)).$$

`theorem subset_extent_intent` / `theorem subset_intent_extent`。
经典（$X \subseteq X''$）。**身份：与经典一致。**

> **判据：非空洞。** 证明体是 `intro o ho a ha; exact ha o ho` —— **不是 `rfl`**，
> 但它**确实是定义展开**（展开 $\mathrm{extent}$ 后 $\forall\forall$ 交换）。
> 注意，按判据（`example : <同名陈述> := rfl`）**本条不能 `rfl` 通过**（因为 `extent∘intent` 是复合），
> 但它**比定义多说的内容为零**——它是**定义的必要推论**。项目自己在 `RealFCAAbstractionSoundness.lean:118-119`
> 把它的搬运版 `subset_fcaClosure` 标注为「**本条【不是】本文件的贡献——它就是既有定理**」。**这是正确的自我定位。**

### 2.4 Galois 连接（核心）

**定理 2.4（Galois 连接）** [`RealFCA.lean:99`]

$$X \subseteq \mathrm{extent}(B) \iff B \subseteq \mathrm{intent}(X).$$

`theorem galois_connection`。

要点二：级**判据实测**：`#print axioms Lattice.galois_connection` 输出
`'Lattice.galois_connection' does not depend on any axioms` —— **零公理**。
证明体是 `constructor` + 两次 `intro` + `exact`，即**纯粹的 $\forall\forall$ 交换**。

**身份：与经典一致**（[GW1999, Lemma 1]，即「Galois 连接」本身）。项目在
`RealFCADuality.lean:85-89` **诚实地把它标注为「改名转发，数学内容为零」**——
它在 `RealFCADuality` 里只是为了让后续定理有本文件内可引用的名字。
**这条自我标注是准确的**（本报告作者核验了 `fca_antitone_adjoint` 的证明体确为 `galois_connection R O' B`）。

### 2.5 闭包幂等

**定理 2.5（闭包幂等，对象端与属性端）** [`RealFCA.lean:112,128`]

$$\mathrm{extent}(\mathrm{intent}(\mathrm{extent}(\mathrm{intent}(X)))) = \mathrm{extent}(\mathrm{intent}(X)),$$
$$\mathrm{intent}(\mathrm{extent}(\mathrm{intent}(X))) = \mathrm{intent}(X).$$

`theorem closure_idempotent` / `theorem intent_closure_idempotent`。
另加 `theorem extent_intent_extent`（`:191`）：

$$\mathrm{extent}(\mathrm{intent}(\mathrm{extent}(B))) = \mathrm{extent}(B).$$

**身份：与经典一致。** 但**不是定义展开**——`closure_idempotent` 的证明体用了
`extent_antitone` 与 `subset_intent_extent` 的**两次组合**（见 `:119`、`:123`），
两条方向**证法不同**。⇒ **这是真正的复合引理**，axioms = `[propext, Quot.sound]`。

### 2.6 形式概念

**定义 2.6（形式概念）** [`RealFCA.lean:141`]

```lean
def IsFormalConcept {O A : Type*} (R : O → A → Prop) (O' : Set O) (B : Set A) : Prop :=
  O' = extent R B ∧ B = intent R O'
```

**探针实测（判空洞）**：`example : Lattice.IsFormalConcept R X B = (X = Lattice.extent R B ∧ B = Lattice.intent R X) := rfl`
**通过** ⟹ 这是**纯定义展开**，不声称内容。与 [GW1999, Def. 2] 一致。**身份：与经典一致（定义）。**

**定理 2.7（概念 ⟺ 闭包不动点）** [`RealFCA.lean:147`]

$$\mathrm{IsFormalConcept}(R, X, B) \iff \bigl(X = \mathrm{extent}(\mathrm{intent}(X)) \;\wedge\; B = \mathrm{intent}(X)\bigr).$$

`theorem formal_concept_iff_closure`。**身份：已知结果的重新形式化。**
经典的形式是「$X = X''$ 且 $B = X'$」，本式取「$X = \mathrm{extent}(\mathrm{intent}(X))$ 且 $B = \mathrm{intent}(X)$」，
即把 $B$ **消去**为 $X$ 的函数。**这个消去是本项目的形式**（后面的 ⊔ 定义依赖它），
但**数学内容与经典等价**。

**判据**：证明体是 `calc` 链 + `rw`，**不是 `rfl`**（因为要把 $B = \mathrm{intent}(X)$ 代进 $O' = \mathrm{extent}(B)$）。

**定理 2.8（提取幂等）** [`RealFCA.lean:166`] 概念再提取仍是同一概念：
`theorem concept_extraction_idempotent`。

> 注意 **判据：本条第一分量的证明体是 `rfl`**（源码 `:171` 逐字 `rfl`，且注释 `:170` 写明
> 「`extent(intent O') = extent(intent O')`（rfl）」。⇒ **该分量是空洞的**。
> 第二分量用 `intent_closure_idempotent`，**非空洞**。**整体强度：一半空洞。**
> **诚实标注**：这条定理的**信息量全部在第二分量**，第一分量只是定义恒等。本篇按实际计。

## 3. 概念格的代数结构

### 3.1 ⊓ 与 ⊔ 的定义

**定义 3.1** [`RealFCA.lean:203,248`]

```lean
def concept_meet R C₁ C₂ := (C₁.1 ∩ C₂.1, intent R (C₁.1 ∩ C₂.1))
def concept_join R C₁ C₂ := (extent R (C₁.2 ∩ C₂.2), intent R (extent R (C₁.2 ∩ C₂.2)))
```

**身份：与经典一致。** ⊓ 取**外延交**（内涵由闭包补全），⊔ 取**内涵交**（外延由闭包补全）——
这正是 [GW1999, Thm. 3] 的 $\wedge$ / $\vee$ 定义。**探针实测**两条定义均可 `rfl` 展开。

**定理 3.2（⊓ 是概念）** [`RealFCA.lean:209`] `theorem concept_meet_is_concept`：
**需要两个输入都是概念**（假设 $h_1, h_2$）。证明体用 `calc` 与 `extent_antitone`——**承重**。

**定理 3.3（⊔ 是概念）** [`RealFCA.lean:255`] `theorem concept_join_is_concept`：
要点**对任意输入成立**（无概念假设）。证明体第一分量用 `extent_intent_extent`，第二分量 `rfl`。

⇒ 要点**这个不对称是真实的结构事实**（`RealFCAConceptLatticeAlgebra.lean:78-79` 明写）：
⊔ 的第一分量定义上就是 `extent(...)`，闭包幂等保证它自动是概念；
⊓ 的第一分量是个 `∩`，**必须**用概念性才能把外延写成 `extent`。
**身份：与经典一致**（经典中 $\wedge$ 与 $\vee$ 的形式本就不对称），**但这条不对称被显式钉住，是优质的形式化**。
### 3.2 格律

**定理 3.4（交换律）** [`RealFCAConceptLatticeAlgebra.lean:97,107`] `meet_comm` / `join_comm`，对**任意**输入。

**定理 3.5（⊓ 结合）** [`:120`] `meet_assoc`，对**任意**输入。源码 `:123` 的证明体是 `unfold; rw [Set.inter_assoc]`——
注意 **这是定义展开 + `Set.inter_assoc`**。源码 `:74-76` 诚实标注：「`meet_assoc` 无条件成立，是因为 `concept_meet` 的第二分量**被定义为**第一分量的 `intent`；这是定义结构使然，但**仍需把 `Set.inter_assoc` 穿过 `intent`，故不是 `rfl`**」。
**判据实测**：`rw` 而非 `rfl` ⟹ **比定义多说一点点**（`congrArg intent` 级别）。**强度：低但真实。**

**定理 3.6（吸收律）** [`:134,159`] `meet_absorb_join` / `join_absorb_meet`，

> $\mathrm{lower}$ 说「$o$ 的**每个后继**落在 $B$ 内」——**对称性只能翻转 $E$ 的方向，
> 无法把这两种量化互换**。要使二者相等需**额外条件**（$E$ 是等价关系**且** $B$ 是 $E$-饱和集），`hsymm` 远不够。

**处置**：改陈述为**真的**等式 $\mathrm{extent}(\mathrm{fcaOfEquiv}(E), B) = \mathrm{intent}(\lambda a\,o.\, Eoa, B)$
（**两次量化形状相同，只是参数顺序翻转**），并且**删掉了 `hsymm`**——
因为更正后的等式是 `rfl` 级（两边定义上同为 $\{o \mid \forall a, a \in B \to Eoa\}$），**对称性不参与**。
源码 `:204-205` 逐字：「这正是『原陈述用错了地方』的标记：`hsymm` 能做的只是翻转 $E$ 的方向，**不能**把 `extent` 变成 `lower`。」

要点三：级**本篇判定：这是「量词顺序不可交换」家族中的一条，与 §3.4 的「反变不保交」、§4.2 的「左右伴随对调」同族。**
项目在 `:243-244` 自己把它们登记为同族三例：
① `extent_iInter`（反变保并、不保交）；② `fca_extent_eq_lower`（量词顺序不可换）；③ 本条（**左右伴随对调**）。

**第三条（左右伴随对调）** [`:245`] —— 项目也自我更正了：

**原稿**：$\mathrm{lower}(X) \subseteq Y \iff X \subseteq \mathrm{upper}(Y)$。**为假。**
反例（`:225-233` 逐字）：取 $O := \mathrm{Bool}$、$E \equiv \mathrm{True}$（全关系，**既对称又自反**，故满足原假设、**且补 `hrefl` 也无效**）、$X := \{\mathrm{true}\}$、$Y := \emptyset$：
左侧 $\mathrm{lower}(X) \subseteq \emptyset$ 读作 $\emptyset \subseteq \emptyset$ —— **真**；
右侧 $X \subseteq \mathrm{upper}(\emptyset)$ 读作 $\{\mathrm{true}\} \subseteq \emptyset$ —— **假**。⟹ **真 ↔ 假 为假**。

**正解**：$\mathrm{upper}(X) \subseteq Y \iff X \subseteq \mathrm{lower}(Y)$（即 $\mathrm{upper}$ 是**左**伴随、$\mathrm{lower}$ 是**右**伴随）。
注意，项目还做了**独立穷举复核**（`:234-236` 逐字）：在 $\mathrm{Bool}$ 上穷举全部 16 个 $(X,Y)$，
「违反恰有 **4** 处（…），**全部涉及退化集 $Y = \emptyset$ 或 $X = \mathrm{univ}$**——
**伴随律在退化集上最容易破**。」
注意，且明确 `hrefl` **补不回来**（`:237-238`：「$\Rightarrow$ 方向在 `hsymm + hrefl` 下仍为假（同一穷举含全关系，它有 `hrefl`），故本条**不是『补一个假设』能修的**，必须**改陈述**」）。

⇒ 要点二：级**身份判定：这是「已知结果的重新形式化」+「三条假命题的自我更正」的合体。**
经典粗糙集理论中 $(\overline{E}, \underline{E})$ 是协变 Galois 连接这一点是**标准的**（[Pawlak 1982]）；
**但「哪一个是左伴随」在纸面上极易写反，而本项目用内核穷举把 4 处违反全钉住了**。
**这是一个可复用的判据：「伴随律在退化集（$\emptyset$ / $\mathrm{univ}$）上最容易破」。**

**注意 边界**：第 5、6 条的对应采用**同类型**设定（$O = A$），源码 `:47-51` 逐字：
「这是粗糙集与 FCA 之间**最自然**的桥（属性 = 对象 = 论域元素），**不是**一般情形下的对应
（一般的 Rough–FCA 桥需要 $A = \mathrm{Set}\,O / E$ 的商结构）。」
⇒ **本篇按此边界陈述**：这里的「Rough–FCA 桥」是**同类型特例**，不是一般定理。

### 4.3 多值 / 模糊 FCA [`RealFCAManyValued.lean`]

**经典**：模糊 FCA（Belohlavek 等）把 $I$ 换成隶属度 $\mu : O \times A \to L$
（$L$ 为 residuated lattice），用 t-norm 与 residuum 定义模糊 extent/intent。
Belohlavek 证明了**模糊 Galois 连接**与**模糊概念格**的存在性。

**本代码做的**（`:35-43` 明写「**不**构造 Fuzzy 概念格的完整结构 … **不**做 Fuzzy Galois 连接的**伴随函子**层（residuated 版本），只做**阈值化**（crispification）这一最常用且**可证**的降级路径」）：

| 数学陈述 | Lean 名 | 强度 |

| $\mathrm{threshExtent}(\mu,\theta,B) = \{o \mid \forall a \in B, \theta \le \mu o a\}$ | `:68` | **定义** |
| $\theta_1 \le \theta_2 \Rightarrow \mathrm{threshExtent}(\theta_2) \subseteq \mathrm{threshExtent}(\theta_1)$ | `threshExtent_antitone_theta` `:86` | 要点**多值 FCA 独有**（经典中无阈值参数，**不可能**由 `RealFCA` 任何结论导出） |

要点二：级**身份判定：经典模糊 FCA 的【保守降级路径】的重新形式化。**

它的价值**在于「保守扩张」这一性质被证明**，而非在数学难度。项目自己在 `:155-160` 逐字承认：
「证明结构与 `RealFCA.galois_connection` **同型**（都是『$\forall\forall$ 交换』），故本条**不**是新的数学技巧；
其价值是确认阈值化是**保守扩张**（conservative extension）。」

**本篇判定：这个自我定位是准确的。** 注意 **但必须明确「未做」的部分**：
residuated lattice 层、t-norm / residuum、模糊概念格的**完备性**——**全部未做**。
⇒ **不能把本模块读作「模糊 FCA 已形式化」**；它只形式化了**模糊 FCA 到经典 FCA 的阈值回退**。

要点**两个真实的、多值独有的观察**（本篇认为是本模块最有价值的副产品）：
1. **阈值与集合大小这两个参数对语义的作用是正交的**（`:94-96`）：
   $\theta$ 升 ⟹ 缩，$\mu$ 升 ⟹ 胀，而「属性集增大」与「对象集增大」都是缩。
   这使 extent/intent 在阈值语义下的行为**不能**简单沿用经典的反变图景。
2. **$\mathrm{extent}$ 与 $\mathrm{intent}$ 随 $\mu$ 的单调方向相同**（`:141-144`）：
   因为二者都是「满足者集合」，只是满足者从对象换成属性。
   源码逐字：「这一点在经典 FCA 中**看不出**来（没有 $\mu$ 可供变化），故是本推广的**新增**观察。」
   ⇒ 要点**这是一条真实的、此前未在经典框架中显式陈述的观察。**

注意 **一个可核验的边界细节**：`threshExtent_high_theta` 的陈述里 `B.Nonempty` 是**必须的**
（$B = \emptyset$ 时 $\mathrm{threshExtent} = \mathrm{univ} \neq \emptyset$），
源码 `:200-209` 逐字登记「这是本文件**唯一**需要『反例属性』的定理」。**这个标注是准确的。**
### 4.4 三元 FCA（Lehmann–Wille） [`RealFCATriadic.lean`]

**经典**：Lehmann–Wille (1995) 把形式背景升为**三元**关系 $Y \subseteq K_1 \times K_2 \times K_3$
（对象 × 属性 × **条件/modus**），三元概念是三元组 $(A_1, A_2, A_3)$。
三元概念格是**非格**的偏序结构（**只有 $\sqcap$ 无 $\sqcup$**）。

**本代码做的**：

| 数学陈述 | Lean 名 | 与经典关系 / 强度 |
|:--|:--|:--|
| $\mathrm{extent2}(B, c) = \{o \mid \forall a \in B, Toac\}$ | `:66` | **定义** |
| $\mathrm{modus2}(X, B) = \{c \mid \forall o \in X, \forall a \in B, Toac\}$ | `:80` | 要点**三元独有**（经典无对应物） |
| $X \subseteq \mathrm{extent2}(B,c) \iff B \subseteq \mathrm{intent2}(X,c)$ | `tri_galois_oa` `:93` | **射影退化**：冻结 $c$ 后**完全**退回经典 Galois |
| $\mathrm{modus2}(X,B) = \{c \mid B \subseteq \mathrm{intent2}(X,c)\}$ | `tri_modus_iff_intent` `:111` | 要点**唯一把三种量化次序整理清楚的引理**；源码标「`Iff.rfl` 级**逐点展开**，数学内容有限」 |
| 三元概念 ⟺ 双向闭包不动点 | `tri_concept_iff_closure` `:145` | 要点**实测零公理** |
| $\mathrm{modus2}$ 对两个自变量**都反变** | `modus2_antitone_extent` `:182`, `modus2_antitone_intent` `:195` | 要点**反变双函子性**，经典无对应物 |
| $\mathrm{extent2}(B,c) = \mathrm{extent2}(B,c')$（当 $T$ 不依赖 $C$） | `tri_extent_projection_degenerates` `:213` | 要点**本文件核心**；**`hindep` 承重** |
| 退化时三元概念**恰为**二元概念 | `tri_concept_degenerates_to_binary` `:247` | 要点**「三元退化为二元」的最强陈述** |

要点二：级**身份判定：经典三元 FCA 的【射影退化】部分的重新形式化 —— 且项目显式削弱了定义，这一点必须讲清。**

注意**本模块对经典理论有一处【实质性的弱化】，项目自己如实登记了**（`:122-130` 逐字）：

> 注意，这里采用**弱化**的（但可证的）刻画：要求 $O'$、$B$ 在**存在**的 $c \in M$ 下互为闭包，且 $M$ 是 $O' \times B$ 的模。
> 这**弱于** Lehmann–Wille 原始的「对**所有** $c \in M$ 同时成立」版本（后者在一般情形下需额外条件）。
> 注意 **诚实标注**：本条陈述**被削弱**；削弱原因是要保持 `tri_concept_iff_closure`（下条）**无条件可证**。

⇒ 要点二：级**本篇判定：这是本专篇中最需要读者警惕的一处「与经典不一致」。**
`IsTriConcept` 的定义（`:131`）是

```lean
def IsTriConcept (T) (O' : Set O) (B : Set A) (M : Set C) : Prop :=
  (∃ c ∈ M, O' = extent2 T B c ∧ B = intent2 T O' c) ∧ M = modus2 T O' B
```

—— 用的是 **$\exists c \in M$**，而 Lehmann–Wille 的原定义要求**对每个 $c \in M$** 都成立。
**探针实测**：该 `def` 是纯定义展开（`rfl` 通过）⟹ 它是**定义层**的选择，不是定理的削弱。
**这个选择的后果**：`tri_concept_iff_closure` 与 `tri_concept_degenerates_to_binary` 因此**无条件可证**，
但**代价是它们刻画的对象比经典三元概念【宽】**。
注意 **读者不得把 `IsTriConcept` 读作 Lehmann–Wille 的三元概念**——它是后者的**超集**。

**另外两条「与经典一致」的重要结论**：
* **三元概念格不是格**：源码 `:35-38` 逐字「**不**构造完整的三元概念格（`triadic concept lattice` 是**非格**的偏序结构 —— 它只有 $\sqcap$ 无 $\sqcup$，且『基本定理』的完整形式涉及 $C$ 上的半格结构，超出本文件）」。
  ⇒ 要点**这条与 Lehmann–Wille 的经典陈述一致，且项目【主动不做】并说明了理由**。
* **条件并的第三条被删除**：源码 `:42-48` 逐字登记，原第 7 条
  「$\mathrm{extent2}(B, c_1 \cup c_2)$ 的关系」**被删除**，因为一般三元设定下
  「$\mathrm{extent2}(B, c_1 \cup c_2)$ 与 $\mathrm{extent2}(B, c_1)$、$\mathrm{extent2}(B, c_2)$ 之间
  **没有**干净的包含关系：$o \in \mathrm{extent2}(B, c_1 \cup c_2)$ 只保证 $Toac$ 对 $c \in \{c_1, c_2\}$ 成立，
  并不给出 $o \in \mathrm{extent2}(B, c_i)$。」
  ⇒ **这是又一次「宁可删掉也不陈述假命题」的处置。**

**`hindep` 的承重性**（`:49-51`）：`tri_extent_projection_degenerates` 的假设
「$T$ 不依赖 $C$」是**承重**的——去掉它结论为假（取 $C := \mathrm{Bool}$、$T o a c := c$：
$\mathrm{extent2}(T, \mathrm{univ}, \mathrm{true}) = \mathrm{univ}$ 而 $\mathrm{extent2}(T, \mathrm{univ}, \mathrm{false}) = \emptyset$）。
注意，源码 `:209-212` 逐字给出该反例。**标注准确。**

## 5. 独立用途（**本节是专篇的核心**）

> 本节回答一个纯 FCA 研究者/工程师会问的问题：
> **如果没有 LATTICE，这 3,000+ 行 FCA 代码能拿来做什么？**
> 对每个用途，本报告作者给出**对应的定理支撑**（不是泛泛而谈），并标注**成熟度**。

### 5.1 分类系统 / 本体工程

**用途**：从对象–属性表自动导出**分类层级**（taxonomy）。
概念格外延的包含序**就是**分类层级；每个概念 $(X, B)$ 的 $B$ 是该类的**定义性属性**。

**定理支撑**：
* **分类层级的序是偏序**：`IsSubconcept`（只看外延），`subconcept_trans`（`RealFCA.lean:182`）传递；
  **完全性由 `meet_isGLB`（`:202`）+ `IsClosedExtent.sInf`（`RealFCACompleteLattice.lean:239`）保证**。
* **「哪个分量是分类的不变量」**：`concept_intent_unique`（`RealFCADuality.lean:207`）——
  要点**外延相同 ⟹ 内涵相同**。这是分类系统能做到「外延唯一决定类」的**机器证明的依据**。
  注意 反之 `concept_extent_determined` + 源码 `:212-220` 的诚实标注：
  「FCA 概念的**外延**是概念的**完全**不变量，而**内涵**不是（内涵可含被闭包吸收的多余项）。
  这一『哪个分量是不变量』的区分正是概念格与属性集之间**非**双射的根源。」
  ⇒ 要点**工程含义**：**用外延做分类键是安全的，用内涵做分类键不安全。** 这是一条可直接落地的设计规则。
* **类的新增与合并的自由度**：`meet_absorb_join` / `join_absorb_meet`（`RealFCAConceptLatticeAlgebra.lean:134,159`）
  给出 $\sqcap/\sqcup$ 是真正的格运算。
* **注意 分配律不可用**：`RealFCAConceptLatticeAlgebra.lean:44-57` 逐字给出**内核级反例**：
  「在『任意 $R : O \to A \to \mathrm{Prop}$』的设定下那句话**是假命题**
  （可代 $O = \mathrm{Fin}\,2$、$A = \mathrm{Fin}\,2$、$R = (\cdot = \cdot)$ 检验：
  三个概念 $(\emptyset, \mathrm{univ})$、$(\{0\},\{0\})$、$(\{1\},\{1\})$ 破坏分配性）。」
  ⇒ 要点**工程含义**：**不要把概念格当布尔代数用**。分类合并/分发的「分配律直觉」在这里**不成立**。
  这条反例（三个元素、$2\times 2$ 的关系）**小而具体、可直接复用为回归测试**。

**成熟度**：要点(4 级)（A 层，零 LATTICE 依赖，格律齐备）。
**缺口**：**没有构造 $\mathrm{CompleteLattice}$ instance** ⟹ 上层不能直接用 Mathlib 的完备格 API，
要手写 $\bigwedge$（可用 `IsClosedExtent.sInf` 作为内容依据）。
### 5.2 知识发现 / 蕴含规则挖掘

**用途**：从数据中提取**蕴含规则** $P \Rightarrow Q$（「凡有 $P$ 中属性的对象必有 $Q$ 中属性」），
并求**基**（不冗余的规则集）。这是关联规则挖掘的 FCA 版本。

**定理支撑**：
* **规则语义与推演系统**：`ImplicationHolds`（`RealFCAImplicationBasis.lean:74`）、`impl_refl`/`impl_trans`（`:94,102`）、
  `impl_of_subset`（放大律，`:130`）、`impl_union_left`（左并律，`:140`）、`impl_inter_right`（右交律，`:167`）。
  ⇒ **这四条恰好是 Armstrong 型推导规则在 FCA 语义下的对应物**，且**每条都证过**。
* **等价类识别**：`impl_antisymm_iff_extent_eq`（`:114`）——
  要点**$P \to Q$ 且 $Q \to P$ ⟺ 外延相等** ⟹ **规则系统里「等价」的规则对数 = 外延族的大小**。
  这是一条**可直接用于规则去重**的判据。
* **规则闭包 = 内涵**：`implClosure`（`:193`）= `intent (extent P)`，
  且 `implClosure_least`（`:248`，**实测零公理**）证明它**是最小的蕴含封闭超集**。
  ⇒ 要点**工程含义**：**任何「沿规则累积」的实现，其正确性判据就是「= `intent∘extent`」**，
  不必再证最小性——已有定理。
* **基的性质**：`IsBasis`（`:276`）三子句（sound / complete / element-minimal）。
* **退化情形**：`basis_empty_of_no_implications`（`:323`）——无真蕴含时 $\emptyset$ 是基。

**成熟度**：要点三：级（A 层，语义层完备）。
**注意 缺口（必须明说）**：
* **没有 DG 基的【构造算法】**——注释 `:41-42` 明写「**不**枚举 Duquenne–Guigues 基、**不**做闭包系统的最小化、**不**做算法」。
  ⇒ **不能直接拿来跑数据**；它是一个「**正确性规范**」，不是一个工具。
* **没有有限性假设** ⟹ **唯一性 / 最小基数性不可用**（`:54-56`）。
* **没有伪内涵这个概念**——DG 基的算法核心（伪内涵枚举）**完全不在代码里**。

⇒ 要点**本篇的定位判断**：这一层是**「蕴含基的语义规范」**，
适合的角色是**验证器 / 规范**，而不是**挖掘器**。
工程上正确的用法是：**用别的工具（Python 的 `concepts` / `fcaR`）算出基，用这套定理证明「算出来的东西是基」**。

### 5.3 数据挖掘 / 模式发现

**用途**：发现频繁闭项集（frequent closed itemset）与概念——FCA 是这一路线的原始出处之一。

**定理支撑**：
* **闭集的内蕴/外蕴双刻画**：`fca_closure_fixpoint_iff_mem_range`（`RealFCAClosureOperatorLattice.lean:195`）——
  要点**「是闭集」$\iff$「是某个 `extent`」** ⟹ **可以直接把「闭集判定」实现为「一次包含检查」**
  （由 `fca_closure_subset_iff_fixpoint`（`:180`）把序比较化为不动点判定）。

### 8.3 本篇的核心结论（三句）

1. 要点**这 14 个模块（A 层 11 模块，零 LATTICE 耦合）构成一个【自足的、可独立成库的 FCA 形式化层】**，
   其根系 `RealFCA.lean` 只 `import Mathlib`，其签名对任意 `{O A : Type*}` 与任意 `R` 成立——
   **按项目自己 `RealFCA.lean:16-17` 的判据，它是「关于 FCA 的定理」，不是「关于 LATTICE 的定理」。**
2. 要点**它的独立用途是真实的且可被非 LATTICE 用户使用**：分类系统（§5.1）、蕴含规则语义规范（§5.2）、
   闭集/模式挖掘的终止与稳定性（§5.3）、粗糙集近似推理（§5.4）、多值数据阈值化（§5.5）、
   三元条件化分析（§5.6）、以及一条**意外但完整**的分词桥（§5.7）。
   注意 **但每一处都必须如实标注成熟度**：这是一个**「规范 / 验证器」级别的库**，
   **不是「算法 / 工具」级别的库**——**没有一处给出可执行算法**。
3. 要点二：级**本篇认为最有价值的两个形式化产出，都不是主流意义上的「定理」**：
   * **`covariant_pair_separated`（`RealFCADuality.lean:283`）**——
     把「FCA 的伴随是反变的、不能直接套 Mathlib 协变 `GaloisConnection`」做成了**可证的分离性结论**；
   * **`conceptToConstraint_side_condition_is_necessary`（`RealFCASyntaxBridge.lean:181`）**——
     把「全局语法桥不存在」做成了**不可能性证明**。
   ⇒ **形式化库对工程的独特贡献，恰恰是这一类「证明某事物【做不到】」的定理。**
