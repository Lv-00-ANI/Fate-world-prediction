## 1. 定义与约定

### 1.1 形式背景与两个算子

设 `O`、`A` 为类型（对象集、属性集），`R : O → A → Prop` 为**满足关系**
（经典 FCA 中的形式背景 `𝕂 = (O, A, R)`）。定义

```
extent R (B : Set A) : Set O := { o | ∀ a, a ∈ B → R o a }        (RealFCA.lean:62)
intent R (O' : Set O) : Set A := { a | ∀ o, o ∈ O' → R o a }       (RealFCA.lean:65)
```

要点**关键事实（本册全部结论的立足点）**：这两个定义的签名对**任意** `{O A : Type*}`
与**任意** `R` 成立，**不含任何 LATTICE 概念**。这正是 `RealFCA.lean:16-17` 的
「它不是『关于 LATTICE 的定理』，而是『关于 FCA 的定理』」在**类型层面**的含义。

### 1.2 形式概念与子概念序

```
IsFormalConcept R O' B := O' = extent R B ∧ B = intent R O'         (RealFCA.lean:141)
IsSubconcept R C₁ C₂    := C₁.1 ⊆ C₂.1                              (RealFCA.lean:177)
```

要点二：级**本册最重要的一条形式事实**（§3 全部结论的前提，已内核验证）：

> `#print Lattice.IsSubconcept` 的内核输出**逐字**为
> `fun {O} {A} R C₁ C₂ => C₁.1 ⊆ C₂.1`
> ⇒ **概念格的序只看第一分量（外延），完全不看第二分量（内涵）。**

注意，这条看似平凡，实则是**全部混淆的源头**：`Set O × Set A` 上**天然存在另一个序**
（`Prod.instLE`，逐分量），而 FCA 用的**不是**它。§3.3 会证明这个区分是**承重的**——
原稿在此处写过两条**假命题**（已由项目自己更正）。

### 1.3 概念格的两个运算

```
concept_meet R C₁ C₂ := ( C₁.1 ∩ C₂.1 , intent R (C₁.1 ∩ C₂.1) )       (RealFCA.lean:203)
concept_join R C₁ C₂ := ( extent R (C₁.2 ∩ C₂.2) ,                       (RealFCA.lean:248)
                          intent R (extent R (C₁.2 ∩ C₂.2)) )
```

要点**不对称是本质的，不是笔误**：
- `meet` 的第一分量**就是**外延的交；
- `join` 的第一分量**不是**外延的并，而是「内涵之交的外延」（= 并的闭包）。

### 1.4 闭包算子

```
structure IsClosureOp {α} [Preorder α] (c : α → α) : Prop where
  mono      : Monotone c
  extensive : ∀ x, x ≤ c x
  idem      : ∀ x, c (c x) = c x                                       (RealFCAClosureOperatorLattice.lean:69)
```

注意，源码 docstring 自陈：把三条性质**拆成具名字段**而非合取，理由是「让『本报告作者在用哪条性质』
在证明中**可见**」。本册在 §2 会依赖这一拆分——`sInf_closed` 的幂等证明
**只**用 `mono` 与 `extensive` 的配合。

## 2. 闭包算子格：FCA 的代数化核心

### 2.1 为什么这是「核心」

经典 FCA 有一条**表示定理**（Ganter–Wille 的 Basic Theorem）：
**每个完备格都同构于某个概念格**。它的证明两侧各需一个构造：

| 方向 | 构造 | 本项目对应 |
|:--|:--|:--|
| 完备格 → 概念格 | 取格上的「≤-闭集」为对象、主理想为属性 | 未做 |
| 概念格 → 完备格 | `extent∘intent` 是闭包算子，闭集族在任意交下封闭 | **已做，§2.2 / §3.4** |

要点：因此「闭包算子格」不是 FCA 的周边技术，而是**两个方向共用的枢纽**。
本册与 P19 的分工：P19 讲概念格的**存在与用法**，本册讲**它的代数骨架怎么立起来**。

### 2.2 主结果一：闭包算子族对逐点下确界封闭

> **定理 2.1**（`RealFCAClosureOperatorLattice.lean:104`，`sInf_closed`，**实质定理**）
> 设 `α` 为完备格，`ι` 为任意指标类型，`c : ι → α → α`。
> 若每个 `c i` 是闭包算子，则**逐点下确界** `fun x => ⨅ i, c i x` 也是闭包算子。
>
> **内核类型**（`#check @sInf_closed` 逐字）：
> `∀ {α} [CompleteLattice α] {ι : Sort*} {c : ι → α → α},
>  (∀ i, IsClosureOp (c i)) → IsClosureOp fun x => ⨅ i, c i x`
>
> **公理依赖**：`[propext, Quot.sound]`。

**证明技巧（三条互不相同）**——源码 docstring 逐字指出这一点，本册予以确认：

| 子目标 | 用到的性质 | 关键引理 |
|:--|:--|:--|
| **单调** | 每个 `c i` 的 `mono` | `iInf_le` + `le_iInf`：`⨅_j c j x ≤ c i x ≤ c i y` |
| **扩张** | 每个 `c i` 的 `extensive` | `le_iInf`：对**每个** `i` 证 `x ≤ c i x` |
| **幂等**（最难） | `mono` + `extensive` + `idem` 三者配合 | 见下 |

幂等性的两方向（`RealFCAClosureOperatorLattice.lean:109-119`）：

```
(⨅c) ((⨅c) x) ≤ (⨅c) x :
  for each i:  (⨅_j c j (⨅_k c k x)) ≤ c i (⨅_j c j x)      [iInf_le]
               ≤ c i (c i x)                                  [mono + iInf_le]
               = c i x                                        [idem]
(⨅c) x ≤ (⨅c) ((⨅c) x) :
  for each j:  (⨅_i c i x) ≤ c j ((⨅_i c i x))               [extensive]
```

要点**对立性检验（源码自陈，本册未独立复核其反例）**：源码 docstring 声称
「若把『闭包算子』改成『仅幂等』或『仅单调』，这一条**会假**」。
注意，本册**未**独立构造该反例；该声称**未经内核验证**，故仅作转述。

### 2.3 主结果二：逐点下确界**就是** `sInf`

定理 2.1 只说明「逐点 `iInf` 是闭包算子」——这**不等于**「它是族的 `sInf`」。
后者需要**上界刻画**。本册为此**独立构造并内核验证**了如下内容：

> **定理 2.2**（**本册新增的内核验证**，探针 `_ProbeTmpP19e`，`exit 0`）
> 在定理 2.1 的假设下，逐点 `iInf` 是**所有闭包算子上界的下界**：
> `∀ d, IsClosureOp d → (∀ i, c i ≤ d) → (fun x => ⨅ i, c i x) ≤ d`

同时验证了**上界集非空**：

> **定理 2.3**（**本册新增的内核验证**，同上探针）
> `const ⊤`（在 `CompleteLattice` 上）是闭包算子，且是**最大**的闭包算子：
> `IsClosureOp (fun _ : α => ⊤)` 且 `∀ c, c ≤ fun _ => ⊤`

**推论 2.4（闭包算子族构成完备格）**：由定理 2.1 + 2.2 + 2.3，
闭包算子族在逐点序下有**任意下确界**（= 逐点 `iInf`），且上界集非空，
故其 `sSup` 存在，等于「上界集的逐点 `iInf`」。

注意 **必要的诚实边界**：源码 `RealFCAClosureOperatorLattice.lean:38-42` 逐字声明

> 「**不**构造 `CompleteLattice (ClosureOp α)` 的 Lean instance：
> …本文件给出**全部内容性验证**（`sInf` 封闭 + 序刻画），
> instance 包装属于机械工作，留给后续波次。」

⇒ **推论 2.4 是本册从已有定理「合起来读」得到的结论，不是项目已证的一条定理。**
本册的三条内核验证补齐了推论 2.4 所需的**全部内容**，
但 注意 **没有**构造 `CompleteLattice` 的 Lean instance。
按本册 §0.1 的分类，定理 2.2 / 2.3 是**本册新增的验证**，
而推论 2.4 是**推论**（非项目已证的定理）。

### 2.4 主结果三：`sSup` 半边为什么不能逐点取

源码 `RealFCAClosureOperatorLattice.lean:47-51` 逐字登记了一条**负面事实**：

> 「`sSup` 半边**不做**：闭包算子族对逐点 `sSup` **一般不封闭**
> （两个闭包算子的逐点上确界通常既不扩张也不幂等）。
> 注意，这是一个**真实的负面事实**，故完备格的 `sSup` 必须由
> 『所有上界之 `sInf`』给出，而非逐点 `sSup`。」

注意 **本册未能独立验证这条负面事实，故必须如实标注**：
本册尝试在 `Set Bool`、`Fin n` 链等小模型上构造「两个闭包算子其逐点上确界不是闭包算子」
的反例，**未成功**。本册的探针迭代中记录了这一失败尝试的痕迹（最终版未包含该反例）。
⇒ **本册把该条按「源码自陈、未独立复核」转述，不作为本册的结论。**

要点：但**该条与 §2.3 并不冲突**，这一点需要讲清：
- 「逐点 `sSup` 一般不是闭包算子」⇒ 逐点 `sSup` **不能**充当格的 `sSup`；
- 「上界集的逐点 `sInf` 是闭包算子且是下确界」（定理 2.2）⇒ 它**能**充当格的 `sSup`。

⇒ **两个不同的对象，一个假一个真。** 源码的处置（用后者而非前者）在结构上是正确的。

### 2.6 序与不动点的对接

> **定理 2.6**（`RealFCAClosureOperatorLattice.lean:180`，**实质定理**）
> `fcaClosure R C ⊆ C ↔ fcaClosure R C = C`
> **证法**：`⟹` 方向需用**扩张性**补上 `C ⊆ fcaClosure R C`。注意 仅凭 `⊆` 无法得等式。

> **定理 2.7**（`RealFCAClosureOperatorLattice.lean:195`，**实质定理**）
> `fcaClosure R C = C ↔ ∃ B, C = extent R B`
> **证法**：`⟸` 用 `extent_intent_extent`；`⟹` 取 `B := intent R C`。

要点**定理 2.7 是「闭集」的内蕴刻画（不动点）与外蕴刻画（值域）的对接**——
这正是概念格外延集合的两种等价说法。用范畴语言说：`extent` 的**像**就是
`fcaClosure` 的**不动点集**；用格论语言说：它是 `fcaClosure` 诱导的**闭包系统**。

## 3. 概念格的完备格结构

### 3.1 `extent`/`intent` 的族化律：为什么「保并、不保交」

这是本册认为**最需要向 FCA 读者讲清**的一点，因为项目自己在此处**判错过方向**
（`RealFCACompleteLattice.lean:22-45` 与 `RealFCADuality.lean:100-115` 均有逐字登记）。

> **定理 3.1**（`RealFCACompleteLattice.lean:97`，`extent_iUnion`）
> `extent R (⋃ i, B i) = ⋂ i, extent R (B i)`
> 注意 **含空指标情形**（两边同为 `univ`），**不需要** `[Nonempty ι]`。

> **定理 3.2**（`RealFCACompleteLattice.lean:123`，`extent_iInter_subset`）
> `(⋃ i, extent R (B i)) ⊆ extent R (⋂ i, B i)`
> **只有这一侧**；**反方向为假**。

**为什么方向是这样（数学理由）**：`extent` 是**反变**的
（`RealFCA.lean:71` `extent_antitone`：`B₁ ⊆ B₂ ⟹ extent B₂ ⊆ extent B₁`）。
反变映射的族化律是 **`⋃ ↦ ⋂`**：

- `⋃ i, B i` 是**最小上界**，反变后成为**最大下界** `⋂ i, extent (B i)` ⇒ **等式成立**；
- `⋂ i, B i` 是**最大下界**，反变后只能给**不等式**（`⋃ i, extent (B i) ⊆ extent (⋂ i, B i)`）
  ⇒ **等式为假**。

**内核验证的反例**（`RealFCACompleteLattice.lean:32-37` 逐字，本册转述）：
取 `O := PUnit`、`A := ι := Bool`、`B i := {i}`、`R _ a := (a = false)`：

```
⋂ i, B i = {false} ∩ {true} = ∅  ⟹  LHS = extent ∅ = univ
RHS = extent {false} ∩ extent {true} = univ ∩ ∅ = ∅
univ ≠ ∅  ✗
```

注意**该反例的指标族是【非空】的**（`ι = Bool`）⇒ 这是**方向性错误**，
**不可**靠加 `[Nonempty ι]` 修复。源码 `:39-41` 逐字强调了这一点。

### 3.2 `sSup` / `sInf` 版本

> **定理 3.3**（`RealFCACompleteLattice.lean:148`，**实质定理**）
> `extent R (sSup 𝓑) = sInf (extent R '' 𝓑)`

> **定理 3.4**（`RealFCACompleteLattice.lean:184`，**实质定理**）
> `𝓑.Nonempty → sInf (extent R '' 𝓑) ⊆ extent R (sInf 𝓑)`
> 注意 `𝓑.Nonempty` 是**承重假设**：`𝓑 = ∅` 时命题**为假**
>（源码 `:67-68` 逐字：取 `R := fun _ _ => False`，`sInf ∅ = univ` 而 `extent univ = ∅`）。

> 注意 **等式版本为假**：`extent R (sInf 𝓑) = sInf (extent R '' 𝓑)` **不成立**
>（反例：`𝓑 = {{false}, {true}}`，**非空族**）。源码 `:69-70` 登记「已删除」。

要点**定理 3.3 的用途（源码自陈）**：「给出**格论形式**（保 `sSup`），
而非仅集合族形式，从而可直接喂给 `Order.GaloisConnection` 的 `l_sSup`/`u_sInf` 接口」。
注意，但 §4 会说明：FCA 的伴随是**反变**的，**喂不进** Mathlib 的协变接口。

### 3.3 要点二级：概念格是格：格律与两个**曾判错**的命题

> **定理 3.5**（`RealFCAConceptLatticeAlgebra.lean:97/107/120`，**实质定理**）
> `concept_meet` 交换、`concept_join` 交换、`concept_meet` 结合——**对任意输入**。

注意 **「对任意输入」是承重的**：因 `concept_meet` 的第二分量**被定义为**第一分量的 `intent`，
故输入**无需**是概念。源码 `:74-76` 逐字自陈「这不是 `rfl`」——需把
`Set.inter_assoc` **穿过** `intent`。

> **定理 3.6**（`RealFCAConceptLatticeAlgebra.lean:134/159`，**实质定理**）
> **吸收律**：`C₁` 是概念时，`C₁ ⊓ (C₁ ⊔ C₂) = C₁` 且 `C₁ ⊔ (C₁ ⊓ C₂) = C₁`。
> 注意 **假设不可省**：对非概念输入该等式**为假**。

要点二：级**两条重大更正的登记**（本册认为这是全篇最有价值的方法论素材）：

项目原稿曾把 `meet_isGLB` / `join_isLUB` 写成 Lean 的 `IsGLB` / `IsLUB` 谓词，
**两条都是假命题**，且**有两种独立的失败方式**（`RealFCAConceptLatticeAlgebra.lean:19-42, 181-201, 221-236`）：

| 失败方式 | 内容 |
|:--|:--|
| **① 序不匹配** | `IsGLB` 内部只用**环境 `LE`**（对 `Set O × Set A` 即 `Prod.instLE`，**逐分量**），而成员谓词 `IsSubconcept` **只看第一分量**。两个不同序混用 ⇒ 断言**无意义地强**。 |
| **② 更根本** | `IsGLB s a` **不是**「`a` 是 `s` 的最大元」，而是「`a` 是 `s` 的**下界集的最大下界**」。`s` 含第二分量任意极端者 ⇒ `s` 的最大下界**严格小于** `concept_meet`。 |

**内核反例**（`O := PUnit`、`A := PUnit`、`R := fun _ _ => False`、`C₁ = C₂ = (∅, ∅)`）：
`concept_meet = (∅, univ)`；而 `(∅, ∅) ∈ s`，`IsGLB` 要求 `concept_meet ≤ (∅, ∅)`，
即 `univ ⊆ ∅` —— **假**（`PUnit` 非空）不成立

**修法**（源码 `:202` / `:237`）：改为**显式的三元合取**，序一律统一为 `IsSubconcept`。
本册独立 `#check` 确认了修正后的内核类型：

> **定理 3.7**（`RealFCAConceptLatticeAlgebra.lean:202`，**实质定理，零公理**）
> `meet_isGLB`：`IsSubconcept R (C₁⊓C₂) C₁ ∧ IsSubconcept R (C₁⊓C₂) C₂ ∧
>  ∀ C, IsSubconcept R C C₁ → IsSubconcept R C C₂ → IsSubconcept R C (C₁⊓C₂)`
> **公理依赖：does not depend on any axioms.**

> **定理 3.8**（`RealFCAConceptLatticeAlgebra.lean:237`，**实质定理，零公理**）
> `join_isLUB`：在 `C₁`、`C₂` **都是概念**的假设下，
> `C₁ ≤ C₁⊔C₂ ∧ C₂ ≤ C₁⊔C₂ ∧ ∀ C, IsFormalConcept C → C₁ ≤ C → C₂ ≤ C → C₁⊔C₂ ≤ C`
> **公理依赖：does not depend on any axioms.**

要点二：级**定理 3.7 与 3.8 的【不对称】是真实的结构事实，不是省略**：
`meet_isGLB` **不需要**概念假设；`join_isLUB` **需要**（输入与上界都要是概念）。
源码 `:77-79` 逐字登记了这一点。**数学根源**：`⊓` 在**所有对**上闭（因第二分量定义式给出），
而 `⊔` 的闭性依赖 `extent∘intent∘extent = extent`（`RealFCA.lean:191`），
后者只在**属性侧的闭包**上成立。

**另一条假命题的更正**（`RealFCAConceptLatticeAlgebra.lean:277-285`）：

> 原稿把 `le_join_left`（`C₁ ≤ C₁ ⊔ C₂`）陈述为**无条件**成立——**该命题为假**。
> **内核反例**：`O = A = Fin 2`、`R = (· = ·)`、`C₁ = ({1}, {0})`：
> `concept_join` 第一分量 `= extent {0} = {0}`，而 `C₁.1 = {1} ⊄ {0}` 不成立
> **根因**：`C₁ ≤ C₁⊔C₂` 要求 `C₁.1 ⊆ extent C₁.2`，**这正是概念性条件**。

⇒ 修正后的 **定理 3.9**（`:286`）：加承重假设 `IsFormalConcept R C₁.1 C₁.2`。

### 3.4 要点：概念格的完备性：闭集族在任意交下封闭

这是「概念格是**完备**格」的**实质内容**（不是二元格律的族化）。

> **定理 3.10**（`RealFCACompleteLattice.lean:227`，`IsClosedExtent.iInter`，**实质定理**）
> 若每个 `i` 处 `Os i` 是 `extent` 的值域元素，则 `⋂ i, Os i` 也是。
> 注意 **不需要** `[Nonempty ι]`：`ι` 为空时 `⋂ i, Os i = univ = extent ∅`。
> **公理依赖**：`[propext, Classical.choice, Quot.sound]`。

> **定理 3.11**（`RealFCACompleteLattice.lean:239`，`IsClosedExtent.sInf`）
> `IsClosedExtent` 对 `sInf` 封闭（定理 3.10 的 `sInf` 包装）。

要点二：级**证明技巧（源码 `:218-226` 逐字登记，本册确认其正确性）**：

> 「注意 **证明走的是 `extent_iUnion`（真），而不是被证伪的『保交』式**：
> 取 `Os i = extent (B i)`，则 `⋂ i, Os i = ⋂ i, extent (B i) = extent (⋃ i, B i)`，

> 「注意 原稿曾用 `extent_iInter`（**假命题**）证明本定理；
> **命题本身为真**，故此处**保留定理、更换证明**。」

## 4. 对偶性：Galois 连接 ↔ 对偶格同构

### 4.1 要点：核心的负面结果：**不可**包装为协变 `GaloisConnection`

这是本册认为**最需要说清、也最容易被误解**的一条。

> **定理 4.1**（`RealFCADuality.lean:94`，`fca_antitone_adjoint`）
> `O' ⊆ extent R B ↔ B ⊆ intent R O'`
> **公理依赖：does not depend on any axioms.**

注意 **诚实标注（源码 `:85-89` 逐字自陈，本册确认）**：
> 「本定理**就是** `RealFCA.galois_connection` 的**改名转发**，
> **数学内容为零**。它在本文件中**不作为实质定理**计入。」

要点二：级**更重要的负面结果**（源码 `:48-53` 与 `:90-93` 逐字）：

> 「注意 **最重要的一条**：本文件**没有**把 `extent`/`intent` 包装成
> Mathlib `GaloisConnection`。**尝试过并失败**：因 `Set` 的 `≤` 是 `⊆`，
> 协变定义式 `l a ≤ b ↔ a ≤ u b` 要求 `intent O' ⊆ B ↔ O' ⊆ extent B`，
> 而 FCA 的**真**关系是 `B ⊆ intent O' ↔ O' ⊆ extent B`——**方向相反**。
> 故本文件只给**反变**形式的点式伴随 (`fca_antitone_adjoint`)，
> 并以 `covariant_pair_separated` 记录两者的分离。」

要点**本册的数学判读**：这是**正确的**。FCA 的伴随对
`(extent, intent)` 是**反变**的（contravariant / order-reversing Galois connection），
即 `extent : Set A → Set O` 与 `intent : Set O → Set A` 满足

```
O' ⊆ extent B  ⟺  B ⊆ intent O'
```

而 Mathlib 的 `GaloisConnection l u` 定义是 `l a ≤ b ↔ a ≤ u b`——
**协变伴随**（covariant / monotone Galois connection，
FCA 文献中也叫 residuated pair / adjunction）。

⇒ 要点二：级**这是两套不同的数学对象**：
- **反变伴随**：`extent`/`intent`（FCA 的），族化律是 `⋃ ↦ ⋂`（§3.1）；
- **协变伴随**：`upper`/`lower`（粗糙集的，§5.2），族化律是 `⋃ ↦ ⋃`、`⋂ ↦ ⋂`。

注意 **本册的补充判读**（源码未明说，本册据标准数学给出）：
反变伴随可以**规范地**转化为协变伴随——只要把 `Set A` 换成**对偶范畴** `Set Aᵒᵖ`
（即把序反过来）。此时 `extent : (Set A)ᵒᵖ → Set O` 是协变的，
`(extent, intent)` 成为 Mathlib 意义上的 `GaloisConnection`。
⇒ **源码说「不可包装」应精确理解为「不可在【未加对偶】的 `Set` 上包装」**，
而非「FCA 没有 Galois 连接」。注意 这是本册的**解读**，不是项目已证的事实。

### 4.2 分离性的显式陈述（本册关注的「唯一的负面定理」）

> **定理 4.2**（`RealFCADuality.lean:283`，`covariant_pair_separated`，**零公理**）
> `a ∈ intent R O' → a ∉ B → ¬ (intent R O' ⊆ B)`
> **公理依赖：does not depend on any axioms.**

注意 **证明强度**：本册 `#check` 确认其内核类型逐字为
`∀ {O A} (R) {B O'} {a}, a ∈ intent R O' → a ∉ B → ¬intent R O' ⊆ B`。

⇒ **数学内容**：这是**单调性** `a ∈ S → a ∉ B → ¬(S ⊆ B)` 的**直接实例**，
**不含新的数学技巧**。注意 源码 `:273-274` 自陈「这是本文件**唯一**实质新增的定理」，
注意 **本册对此持保留意见**：按 §0.1 判据，它在**内容上**是集合论平凡式；
其价值在于**登记一次失败尝试**（协变包装），而非提供数学。

**本册的诚实判断**：`covariant_pair_separated` 应归类为**记录性定理**（documentation theorem），
而非「实质新增的数学」。注意 **这是本册与源码 docstring 的分歧点，如实记录。**

### 4.3 对偶同构的内容级陈述

> **定理 4.3**（`RealFCADuality.lean:207`，`concept_intent_unique`）
> 共享**同一外延**的两个概念，其内涵相同：`IsFormalConcept R O' B₁ → IsFormalConcept R O' B₂ → B₁ = B₂`

> **定理 4.4**（`RealFCADuality.lean:221`，`concept_extent_determined`）
> 共享同一外延的两个概念，其 `extent` 值相同：`extent R B₁ = extent R B₂`

要点二：级**定理 4.4 的 docstring 给出了本册认为最重要的一条数学判读**（`:215-220` 逐字）：

> 「注意 诚实标注：本定理**没有**断言 `B₁ = B₂`（那是**假**的：两个不同属性集可有相同外延，
> 例如 `B` 与 `intent (extent B)`）。故本条的**真实内容**是：
> FCA 概念的**外延**是概念的**完全**不变量，而**内涵**不是
>（内涵可含被闭包吸收的多余项）。这一『哪个分量是不变量』的区分
> 正是概念格与属性集之间**非**双射的根源。」

⇒ **本册的确认**：这是**正确的**，且是 FCA 的核心结构事实。
用代数语言说：映射 `(O', B) ↦ O'` 是概念族上的**单射**（定理 4.3 是它的另一种表述），
而 `B ↦ extent B` **不是**单射。⇒ **概念格与属性集格之间只有 Galois 连接，没有同构。**

> **定理 4.5**（`RealFCADuality.lean:251/256`，**实质定理**）
> **两次反变相消为协变**：`extent ∘ intent` 与 `intent ∘ extent` 都**单调**。

要点**数学内容（源码 `:245-249` 逐字，本册确认）**：
> 「它是**两次**反变的**相消**，且**不能**由 `extent_antitone` 或 `intent_antitone`
> **任一条单独**得出（两条各是反变）。这条是 FCA 中『闭包算子单调』的**序论根源**。」

⇒ 这正是 §2 定理 2.5 中 `IsClosureOp.mono` 字段的来源。
**本册确认该因果链正确**：`fca_closure_isClosureOp` 的 `mono` 字段的证明体逐字为
`fun _ _ h => extent_antitone R (intent_antitone R h)`（`:167`），即定理 4.5 的展平。

## 5. 推广：代数结构保留了多少

本册对三类推广提**同一个问题**：**经典 FCA 的代数骨架（Galois 连接 / 闭包算子 /
完备格）在推广后保留了多少？**

### 5.1 多值 / 模糊 FCA：**阈值化是保守扩张**

**约定**：把 `Prop`-值的 `R` 换成 `ℝ`-值隶属度 `μ : O → A → ℝ`，引入阈值 `θ : ℝ`：

```
threshExtent μ θ B   := { o | ∀ a ∈ B, θ ≤ μ o a }                   (RealFCAManyValued.lean:68)
threshIntent μ θ O'  := { a | ∀ o ∈ O', θ ≤ μ o a }                  (RealFCAManyValued.lean:73)
```

> **定理 5.1**（`RealFCAManyValued.lean:161`，`thresh_galois`）
> `O' ⊆ threshExtent μ θ B ↔ B ⊆ threshIntent μ θ O'`
> **公理依赖**：`[propext, Classical.choice, Quot.sound]`。

要点二：级**这是本册认为多值部分最重要的结构结论**：**Galois 连接的【形式】完全保留**。
源码 `:155-157` 逐字：
> 「**关键保持性结果**——它说明经典 FCA 的 Galois 伴随在**阈值语义下完全保留**
>（形式与原式一致），故多值推广**不牺牲** FCA 的代数骨架。」

> **定理 5.2**（`RealFCAManyValued.lean:178`，`thresh_concept_iff`）
> `IsFormalConcept (fun o a => θ ≤ μ o a) O' B ↔
>  (O' = threshExtent μ θ (threshIntent μ θ O') ∧ B = threshIntent μ θ O')`

⇒ 要点**多值层没有新增概念类型**：阈值化后的「模糊概念」**精确地就是**经典形式概念
（关系取阈值化谓词）。源码 `:169-177` 逐字自陈这是**桥接引理**（非新数学），
但**本册认为其结构意义重大**：它说明**阈值化是从模糊 FCA 到经典 FCA 的保守扩张**，
故经典 FCA 的**全部**结论（包括 §2–§4 的所有代数结果）自动适用于阈值化设定。

**新增的单调律（经典 FCA 中不存在）**：

> **定理 5.3**（`RealFCAManyValued.lean:86`，**真·新增内容**）
> `θ₁ ≤ θ₂ → threshExtent μ θ₂ B ⊆ threshExtent μ θ₁ B`
> **含义**：**阈值升高 ⟹ 外延缩小**。注意 经典 FCA 无「阈值」参数，故此定理
> **不可能**由 `RealFCA` 任何结论导出。

> **定理 5.4**（`RealFCAManyValued.lean:133`，**真·新增内容**）
> `(∀ o a, μ₁ o a ≤ μ₂ o a) → threshExtent μ₁ θ B ⊆ threshExtent μ₂ θ B`
> **含义**：**隶属度升高 ⟹ 外延变大**。

要点二：级**源码 `:126-131` 的判读（本册确认）**：
> 「它与第 2 条（阈值单调）**方向相反**，共同刻画了 `(θ, μ)` 两个参数对
> 外延的作用：**θ 升 ⟹ 缩，μ 升 ⟹ 胀**。」

注意 **诚实边界（源码 `:44-52` 逐字，本册确认）**：
- `threshExtent_high_theta`（`θ > 1 ⟹ 外延 = ∅`）需**两个承重假设**：`μ ≤ 1` 与 `B.Nonempty`；
- 源码明确**不做** Fuzzy 概念格的完整结构（需 Łukasiewicz / residuated lattice 理论）。

| 定理 5.2（模糊概念 = 经典概念） | 同上 | 要点**重新形式化**（桥接） |
| 定理 5.3 / 5.4（θ、μ 的单调律） | 文献中作为**显然性质**通常不单列 | 要点**本册判为「本项目显式化的显然律」** |
| **不做** residuated / Łukasiewicz 结构 | Belohlavek 的**完整**模糊 FCA 用 residuated lattice | 注意 **诚实省略**（源码已登记） |

注意 **本册的重要保留**：项目的多值层是**阈值化**（crispification），
**不是** Belohlavek 意义上的模糊 FCA（后者用 residuated lattice 与
`⊗`/`→` 伴随，其概念格是**模糊格**）。⇒ **本册不把定理 5.1–5.4 称为「模糊 FCA 的形式化」**，
而称为「**多值背景的阈值化理论**」。这是必要的界定。

### 5.2 粗糙集：**协变伴随**，与 FCA 的**方向相反**

**约定**（Pawlak）：`E : O → O → Prop` 为关系，

```
upper E X := { o | ∃ x ∈ X, E o x }                                  (RealFCARoughSet.lean:69)
lower E X := { o | ∀ x, E o x → x ∈ X }                              (RealFCARoughSet.lean:79)
```

> **定理 5.5**（`RealFCARoughSet.lean:91`，**实质定理**）
> `(∀ x, E x x) → lower E X ⊆ X ∧ X ⊆ upper E X`
> 要点**精确的假设刻画**：**仅需自反性**，**不**要求对称或传递。
>（源码 `:88-89` 逐字：去掉 `hrefl` 后两个包含**都**可能失败。）

> **定理 5.6**（`RealFCARoughSet.lean:138` 与 `:245`，**零公理**）
> `(∀ x y, E x y → E y x) → upper E X ⊆ Y ↔ X ⊆ lower E Y`
> **公理依赖：does not depend on any axioms.**

要点二：级**这是本册认为粗糙集部分最重要的结构结论**：粗糙集的 `(upper, lower)` 是
**协变**伴随（`l := upper` 在左、`u := lower` 在右），而 FCA 的 `(extent, intent)`
是**反变**伴随。⇒ **两者是不同种类的 Galois 连接。**

**源码的两处重大更正（本册认为极有价值）**：

**更正一 —— `extent ≡ lower` 是假命题**（`RealFCARoughSet.lean:178-211` 逐字）：

> 原陈述 `extent (fcaOfEquiv E) B = lower E B`（假设仅 `hsymm`），**该等式不成立**。
> **内核反例**（探针 `_a2_rs_ce.lean`，`exit 0`）：取 `O := Bool`、
> `E x y := True`（**全关系，确实对称**）、`B := {true}`：
> - `lower E B = {o | ∀ x, E o x → x ∈ B} = ∅`（因 `false ∉ B`）；
> - `extent (fcaOfEquiv E) B = {o | ∀ a ∈ B, E o a} = univ` ⇒ **`univ ≠ ∅`**。
>
> **根因（数学）**：`extent` 说「`o` 与 `B` 的**每个**元素相关」，
> `lower` 说「`o` 的**每个后继**落在 `B` 内」——**对称性只能翻转 `E` 的方向，
> 无法把这两种量化互换。** 要使二者相等需**额外条件**
>（`E` 是等价关系**且** `B` 是 `E`-饱和集）。

⇒ 修正后的 **定理 5.7**（`:208`）：`extent (fcaOfEquiv E) B = intent (fun a o => E o a) B`
（**对转置关系取 `intent`**）。注意 证明为 `rfl` 级 ⇒ **内容上的恒等式**，
源码 `:203-205` 逐字承认「`hsymm` 已删除…这正是『原陈述用错了地方』的标记」。

**更正二 —— 左右伴随对调**（`RealFCARoughSet.lean:216-244` 逐字）：

> 原陈述 `lower E X ⊆ Y ↔ X ⊆ upper E Y`（`lower` 在左、`upper` 在右）**为假**。
> **内核反例**（探针 `_a2_adj2.lean`，`exit 0`）：取 `O := Bool`、`E x y := True`
>（**全关系，既对称又自反**）、`X := {true}`、`Y := ∅`：
> - 左侧 `lower E {true} ⊆ ∅`：全关系下 `lower E {true} = ∅` ⇒ **`∅ ⊆ ∅` 真**；
> - 右侧 `{true} ⊆ upper E ∅`：`upper E ∅ = ∅` ⇒ **`{true} ⊆ ∅` 假**；
> ⇒ **真 ↔ 假 为假**。
>
> 注意 **穷举复核**（coordinator 独立穷举 `Bool` 上全部 16 个 `(X,Y)`）：
> 违反恰有 **4** 处，**全部涉及退化集** `Y = ∅` 或 `X = univ`
> ——**伴随律在退化集上最容易破**。
> 注意 **`hrefl` 补不回来**：`⟹` 方向在 `hsymm + hrefl` 下仍为假（同一穷举含全关系）。

⇒ 正解即 **定理 5.6**（`upper` 是**左**伴随、`lower` 是**右**伴随），
使 `∃`（`upper`）与 `∀`（`lower`）正确配对。

> **定理 5.8**（`RealFCARoughSet.lean:271`，**实质定理**）
> `(∀ x, E x x) → (∀ x y z, E x y → E y z → E x z) → lower E (lower E X) = lower E X`
>
> **证明技巧（源码 `:262-268` 逐字）**：**两个方向用的假设不同**——
> `⊆` 方向只需**自反**；`⊇` 方向需要**传递**。
> 注意，去掉传递性时 `⊇` **为假**（取 `O := Fin 2`、`E 0 1 = True` 其余 `False`、`X := {0}`：
> `lower X = {0}`，但 `lower (lower X)` 含 1）。

> **定理 5.9**（`RealFCARoughSet.lean:167`）
> `intent (fcaOfEquiv E) {o} = {a | E o a}`
> **含义**：**FCA 的 `intent` 把单点扩展为其等价类** —— 粗糙集中生成等价类的操作。

**与经典文献对照**：

| 结论 | Pawlak / 文献 | 性质 |
|:--|:--|:--|
| 定理 5.5（夹逼律，仅需自反） | Pawlak：等价关系下 `lower X ⊆ X ⊆ upper X` | 要点**重新形式化**，但**假设强度被精确刻画**到自反（**这是本项目的增值**） |
| 定理 5.6（协变伴随） | 标准（`upper` ⊣ `lower`，Pawlak 近似算子的伴随对） | 要点**重新形式化** |
| 定理 5.8（`lower` 幂等） | 等价关系下 `lower` 是**内部算子**（interior），幂等是标准事实 | 要点**重新形式化**；**假设被拆解为自反 + 传递** |
| 要点「粗糙集算子与 FCA 算子在**序方向**上不同」（源码 `:51-54`） | 文献中通常不并置比较 | 要点**本册判为本项目的观察**（有价值但非定理） |

注意 **源码的诚实边界（`:46-50` 逐字，本册确认）**：
> 「第 5、6 条的『对应』采用**同类型**设定（`O = A`）…**不是**一般情形下的对应
>（一般的 Rough-FCA 桥需要 `A = Set O / E` 的商结构）。」

注意 **本册补充的关键判读**（源码 `:51-54` 逐字已给出，本册确认其正确）：
> 「『粗糙集是 FCA 的特例』这句话在**算子代数**层面**是错的**；
> 正确的说法是它们在**闭包系统**层面（第 6 条）对应。」

⇒ **本册特别强调这一点**：粗糙集与 FCA 的关系**不是**包含关系，
而是**两个不同种类的 Galois 连接**（协变 vs 反变）。
注意，而**更正一之后**，源码所宣称的「闭包系统层面的对应」**也已失去一条支撑**
（`extent ≡ lower` 已被证伪）。⇒ **本册认为「粗糙集 ↔ FCA」的对应在本项目中【目前不成立】**，
只剩下「二者都有 Galois 连接，但种类不同」这一负面性观察。
注意，这是本册**最需要提请 FCA 读者注意**的一条。

### 5.3 三元 FCA：射影退化与**被削弱的**基本定理

**约定**（Lehmann–Wille 1995）：关系升为 `T : O → A → C → Prop`（`C` = *modus* / 条件维）：

```
extent2 T B c   := { o | ∀ a ∈ B, T o a c }                          (RealFCATriadic.lean:66)
intent2 T O' c  := { a | ∀ o ∈ O', T o a c }                         (RealFCATriadic.lean:70)
modus2 T O' B   := { c | ∀ o ∈ O', ∀ a ∈ B, T o a c }                (RealFCATriadic.lean:80)
```

**（a）固定 `c` 时完全退回经典**

> **定理 5.10**（`RealFCATriadic.lean:93`，`tri_galois_oa`，**零公理**）
> `O' ⊆ extent2 T B c ↔ B ⊆ intent2 T O' c`
> **公理依赖：does not depend on any axioms.**

> **定理 5.11**（`RealFCATriadic.lean:111`，**实质定理**）
> `modus2 T O' B = { c | B ⊆ intent2 T O' c }`
> 要点**含义**：它把「**模**」这一**方向**（在 `C` 中取值）与「**内涵**」这一**集合**
>（在 `A` 中取值）联系起来。源码 `:104-108` 逐字：
> 「这条**不可**由第 3 条导出（第 3 条固定 `c`，本条**量化** `c`），
> 是三元结构『三维互相确定』的第一处体现。」

**（b）射影退化的精确条件**

> **定理 5.12**（`RealFCATriadic.lean:213`，**本文件核心结果**）
> `(∀ o a c c', T o a c ↔ T o a c') → extent2 T B c = extent2 T B c'`
>
> 注意 **承重假设不可省**：取 `C := Bool`、`T o a c := c` 即得
> `extent2 T univ true = univ` 而 `extent2 T univ false = ∅`，命题为假。
>
> ⇒ 要点**「三元退化为二元」的精确条件：恰好是 `T` 的第三维【平凡】。**

> **定理 5.13**（`RealFCATriadic.lean:247`，**最强退化陈述**）
> 在 `hindep` 成立且 `c ∈ M` 时，
> `IsTriConcept T O' B M ↔ (IsFormalConcept (fun o a => T o a c) O' B ∧ M = modus2 T O' B)`

**（c）模方向的反变双函子性**

> **定理 5.14**（`RealFCATriadic.lean:182/195`，**结构事实**）
> `modus2` 对**两个**自变量都**反变**：
> `O'₁ ⊆ O'₂ → modus2 T O'₂ B ⊆ modus2 T O'₁ B`；
> `B₁ ⊆ B₂ → modus2 T O' B₂ ⊆ modus2 T O' B₁`
> ⇒ 即 `modus2` 是**反变双函子** `Set O × Set A → Set C`。
> 注意 **经典 FCA 中没有对应物**（源码 `:190-192` 逐字）。

**（d）注意 三元概念的定义被【削弱】—— 本册最需要警示的一点**

源码 `RealFCATriadic.lean:122-133` 逐字：

> 「注意 这里采用**弱化**的（但可证的）刻画：要求 `O'`、`B` 在**存在**的 `c ∈ M`
> 下互为闭包，且 `M` 是 `O' × B` 的模。这**弱于** Lehmann–Wille 原始的
>『对**所有** `c ∈ M` 同时成立』版本（后者在一般情形下需额外条件）。
> 注意 **诚实标注**：本条陈述**被削弱**；削弱原因是要保持
> `tri_concept_iff_closure`（下条）**无条件可证**。」

⇒ 要点二：级**本册的判读**：这是**实质性**的偏离，不是记法差异。Lehmann–Wille 的
三元概念定义为：`(A₁, A₂, A₃)` 是真三元概念，当且仅当

```
∀ c ∈ A₃:  A₁ = extent2 T A₂ c  ∧  A₂ = intent2 T A₁ c     （对所有 c，不只存在一个）
A₃ = modus2 T A₁ A₂
```

注意，项目把「**对所有 `c ∈ M`**」弱化为「**存在 `c ∈ M`**」，
⇒ **项目所证的 `IsTriConcept` 不是 Lehmann–Wille 的三元概念。**
注意，因此 **定理 5.13 的「退化」结论是对【弱化定义】成立的**，不能直接读作
「Lehmann–Wille 三元概念在 `hindep` 下退化为二元概念」。
注意 **本册据此拒绝把 `RealFCATriadic` 称为「三元 FCA 的形式化」**，
而称为「**三元 FCA 的一个削弱变体 + 射影退化分析**」。

注意 **另一条被删除的条目**（源码 `:43-48` 逐字）：
> 「第 7 条**未**陈述…因为在一般三元设定下 `extent2 T B (c₁ ∪ c₂)` 与
> `extent2 T B c₁`、`extent2 T B c₂` 之间**没有**干净的包含关系…
> 故本文件**删除**该条，避免陈述假命题。」

**与经典文献对照**：

| 结论 | 文献 | 性质 |
|:--|:--|:--|
| 定理 5.10（固定 `c` 的 Galois 连接） | Lehmann–Wille 1995；Wille 1995 三元概念分析 | 要点**重新形式化**（桥接） |
| 定理 5.11（`modus2` 与内涵的对应） | 三元 FCA 中 `A₃ = {c ∣ A₂ ⊆ intent2(A₁, c)}` 型 | 要点**重新形式化** |
| 定理 5.12 / 5.13（射影退化） | 文献中通常陈述「三元 ⊇ 二元」但**罕有**精确的退化**条件** | 要点**本册判为本项目的有价值观察**（但基于削弱定义） |
| 定理 5.14（`modus2` 反变双函子） | 标准（全称量化的单调性） | 要点**重新形式化** |
| 注意 **三元概念定义被削弱** | Lehmann–Wille：对**所有** `c ∈ M` | 注意 **实质性偏离，源码已自陈** |
| 成立 「三元概念格是**非格**的偏序结构（只有 ⊓ 无 ⊔）」 | 文献（TCA 得 **trilattice**，非格） | 要点**与经典一致**（源码 `:36-38` 说明了该结构的非格性） |

要点二：级**本册的重要补充**：源码 `:36-38` 逐字称
「**不**构造完整的三元概念格（`triadic concept lattice` 是**非格**的偏序结构——
它只有 `⊓` 无 `⊔`，且『基本定理』的完整形式涉及 `C` 上的半格结构，超出本文件）」。
⇒ 要点**这是与经典文献最一致的一条**：TCA 的**基本定理**（Wille 1995）说的是
三元概念集构成 **trilattice**（三向偏序），**不是**格。
注意，而项目的三元模块**完全未触及** trilattice 结构。⇒ **§7 列为开放问题。**

### 8.2 本册识别出的开放问题

> **开放问题 1（本册提出）**：`RealFCAConceptLatticeAlgebra.lean:67-68` 称
> 「任意族的 `sSup` **需要分配性**，故不做」。

> **开放问题 3（本册提出）**：**trilattice 结构完全未做**。
