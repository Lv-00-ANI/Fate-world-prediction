## 1. 引言：为什么 FCA 值得形式化，以及这份形式化与经典文献的关系

形式概念分析（Formal Concept Analysis, Wille 1982；系统论述见 Ganter–Wille, *Formal Concept Analysis: Mathematical Foundations*, Springer 1999）
从一个**形式背景**（formal context）出发：

> 给定对象集 `O`、属性集 `A` 与二元关系 `R ⊆ O × A`，
> 定义 **外延**（extent）与 **内涵**（intent）：
> `extent(B) = { o | ∀ a ∈ B, R(o,a) }`，`intent(O') = { a | ∀ o ∈ O', R(o,a) }`。
> 这一对构成一个 **Galois 连接** `O' ⊆ extent(B) ⟺ B ⊆ intent(O')`，
> 其不动点 `(O',B)` 称为 **形式概念**（formal concept）；全体形式概念按
> 外延包含排序构成一个**完备格**，即**概念格**（concept lattice）。

FCA 的经典地位来自三点：它是**布尔数据上的完备聚类理论**；它给出**蕴含系统**与其**基**
（Duquenne–Guigues 基）的精确理论；它的**完备格表示定理**（每个完备格同构于某个概念格）
使它成为格论与数据科学之间的桥梁。应用面覆盖分类系统、本体工程、数据挖掘、知识发现、软件重构。

**为什么值得形式化。** FCA 的教科书结果**多数是初等的**（集合论 + 格论），但恰恰因为初等，
其**前提条件**（有限性、完备性、原子性）与**边界**（何处结论会失效）在非形式化的叙述里极易被滑过。
机器检查的价值有三种：
1. **守恒性检验**：把「显然」的步骤钉死（本篇 §2.1 用 `rfl` 判据**区分**了哪些「定理」其实是定义展开）；
2. **边界定位**：FCA 中若干自然陈述**为假**，机器给出内核级反例（§6.2 的 `no_constraint_has_extent_pair`）；
3. **可复用性**：一旦对**任意** `R` 证毕，则该结论在**每一**个应用实例上免费成立（§7 的分词器即此类）。

**与经典文献的关系。** 本篇在每一处都显式标注三类：
要点**与经典一致**（形式化了教科书结果）／要点**已知结果的重新形式化**（教科书有，形式化只是换载体）／
要点**新内容**（经典文献无此陈述，或此处的**边界/反例**是新的）。
注意，本项目的自评标准（`FCA-LAYERING.md:120-121`）是：
**3,162 行的 A 层已是有分量的 FCA 形式化规模**，对照 AFP 的 `FCA_Formal_Concept_Analysis` 条目；
且 `FCA-LAYERING.md:113-118` 记：**mathlib 有 Galois 连接与闭包算子，但没有专门的 FCA 库**——
注意 **该生态位判断引自项目自身调研 R6，coordinator 未独立复核**，本篇据此标注为**待核**。

要点：本篇的核心主张，逐条对应后文：
> **(i)** 蕴含基在项目里被证成的是**性质**（`IsBasis` 谓词的语义刻画），**不是算法**（§2）；
> **(ii)** 「要素层」是 FCA 之外**加的一层**，其与闭包的衔接是**定义性**的，项目对此如实标注（§3）；
> **(iii)** 实例化 `R x c := RealConstraintSat c x` 的价值不在「FCA 有用」，而在**它把一个具体满足关系钉成了形式背景**（§4）；
> **(iv)** 要点FCA 的 `intent` **就是**贪心最长匹配分词器的选择集——这是**独立于 LATTICE 的 FCA 应用**（§7）；
> **(v)** 抽象可靠性是**单向**的（concrete ⇐ abstract），不是 `γ∘α ⊇ id` 的双向等式（§8）。

### 2.2 蕴含的语义锚点

```lean
def ImplicationHolds (R : O → A → Prop) (P Q : Set A) : Prop := extent R P ⊆ extent R Q   -- :74
def Impl (R : O → A → Prop) : Set (Set A × Set A) := {p | ImplicationHolds R p.1 p.2}   -- :82
```

要点**与经典一致**：这正是 Ganter–Wille 中蕴含 `P → Q` 的标准语义
（「凡满足 `P` 中全部属性的对象也满足 `Q` 中全部属性」）。
要点**形式化上的选择**（`:71-72` 自述）：把蕴含**定义为**外延包含，
从而把全部后续定理化归为 `Set` 上的包含演算。这是一个**有意的载体选择**，不是新数学。

### 2.4 蕴含的等价类由**外延**决定

```lean
theorem impl_antisymm_iff_extent_eq (R) (P Q : Set A) :
    (ImplicationHolds R P Q ∧ ImplicationHolds R Q P) ↔ extent R P = extent R Q   -- :114
```

要点**这是有内容的**，且 `:110-112` 自述了它的**意义**：

> 它说明蕴含系统的**等价类数目 = 不同外延的数目**，
> 从而「基的规模」受外延族规模限制（一个对象集无关的上界）。

要点**与经典一致**：在 FCA 中，`P` 与 `Q` 逻辑等价 ⟺ `extent(P) = extent(Q)`，
即二者生成**同一个闭包**。这是 DG 基理论中「蕴含的等价类 = 闭包系统的元素」的标准事实的形式化。

**本篇核验**：`#print axioms` ⟹ `[propext, Classical.choice, Quot.sound]`（真实证明，非 `rfl`）。

### 2.5 放大律与闭合律

| 定理 | 陈述 | 强度判读 |
|:--|:--|:--|

| `impl_union_left` `:140` | `P₁ → Q` ⟹ `P₁ ∪ P₂ → Q` | 要点`:136-138` 自述「**真内容**」 |
| `impl_inter_right` `:167` | `P → Q₁` ⟹ `P → Q₁ ∩ Q₂` | 要点`:163-166` 自述「**纯逻辑**的合取规则」 |

注意 **但本篇必须指出一个从源码注释里读不出的、只能在内核层面看出的事实**：
**两条「律」的签名都只要求一个前提**——
`impl_union_left` 的前提是 `(h₁ : ImplicationHolds R P₁ Q)`（**只有 `h₁`，没有 `h₂`**，`:140-141`）；
`impl_inter_right` 同样只要求 `(h₁ : ImplicationHolds R P Q₁)`（`:167-168`）。

源码 docstring 说的是「`P₁ → Q` **与** `P₂ → Q` 蕴含 …」（`:134`），
**但签名里没有第二个前提**。理由在证明体内被注释为设计决策（`:156-157`、`:178-179`）：
因为 `P₁ ⊆ P₁ ∪ P₂`（`Q₁ ∩ Q₂ ⊆ Q₁`），由 `extent` **反变**即得结论，**第二个前提是多余的**。

⇒ 要点**判读**：这两条**不是**「左并/右交**合并**两条蕴含」（那需要 `h₂`），
而是**单前提的单调律**：`P → Q` ⟹ `P₁ ∪ P₂ → Q`（前提**放大**），
`P → Q₁` ⟹ `P → Q₁ ∩ Q₂`（结论**缩小**）。
注意，二者都**弱于**经典蕴含系统的「前提并 / 结论交」闭合规则——后者要求**两条**前提合并。
要点：这不是错误（命题**为真**且更一般），但**命名与 docstring 提示的是较强的读法**，
读者不应据此认为项目证了「并-交闭合」。这是**本篇独立发现的一条文档-签名落差**。

**本篇核验**：`#print axioms Lattice.impl_union_left` ⟹ `does not depend on any axioms`（完全不依赖任何公理）。

### 2.7 基的刻画：`IsBasis` 是**性质谓词**

```lean
def IsBasis (R : O → A → Prop) (𝓛 : Set (Set A × Set A)) : Prop :=
  (∀ p ∈ 𝓛, ImplicationHolds R p.1 p.2) ∧
  (∀ P Q : Set A, ImplicationHolds R P Q →
    ∃ p ∈ 𝓛, p.1 ⊆ P ∧ Q ⊆ p.2) ∧
  (∀ p ∈ 𝓛, ¬ (∀ P Q : Set A, ImplicationHolds R P Q →
    ∃ q ∈ 𝓛  {p}, q.1 ⊆ P ∧ Q ⊆ p.2))       -- :276-281
```

**三个子句**依次是：**语义可靠**（`𝓛` 的成员都成立）、**语义充分**（每条成立的蕴含都可由 `𝓛` 中某条推导）、
**逐元素不冗余**（去掉任何一条就不再充分）。

注意 **`:267-275` 的逐字诚实标注**（本项目最值得称道的一段）：

> 把「基」从**算法对象**（DG 基的构造过程）剥离为**性质谓词**——
> 注意 `minimal` 是**逐元素**极小性（`∀ p ∈ 𝓛, …`），**不是**基数最小性，**也不是**唯一性。
> DG 基的**唯一性**在一般（无限、任意 `R`）情形下**不成立**，故本文件不声称。

> 结论是「`∅` **是**一个基」，**不是**「唯一的基」——若存在重言蕴含（如 `P → P`），`{P → P}` 也可以是基。

## 3. 要素层：FCA 之外加的一层，及其与闭包的衔接

### 3.1 「要素」是什么

`lean/RealTemporalLayer.lean` 来自项目外部的思想构件「时态性层级体系」（`:11-12`），
**不是 FCA 的经典内容**。它引入：

```lean
inductive Gaze where | none | up | down                       -- :78-82
structure Temporal (O A : Type*) (R : O → A → Prop) where
  base : O      -- 基底：不随目光改变
  gaze : Gaze   -- 当前目光
                                                              -- :89-93
def IsElement (t : Temporal O A R) : Prop := t.gaze = Gaze.none           -- :129
def IsConcept (t : Temporal O A R) : Prop := t.gaze = Gaze.up ∨ t.gaze = Gaze.down  -- :132-133
```

要点**「要素」的精确含义**：**目光未投**——即「尚未被任何目光所捕获的给定物」（`:125`）。
它与「概念」**恰好互补且穷尽**（`element_concept_complement` `:139`、
`element_or_concept` `:150`、`not_element_and_concept` `:156`）。

要点二：级**第二个、更重要的「要素」判据**在第六节（`:247-323`），它与 FCA 直接挂钩：

```lean
def hasUpper (R : O → A → Prop) (o : O) : Prop := ∃ a : A, R o a        -- :253
def isElementUnderUpGaze (R) (o : O) : Prop := ¬ hasUpper R o            -- :260-261

theorem no_upper_iff_no_split (R) (o : O) :
    isElementUnderUpGaze R o ↔ ∀ B : Set A, B.Nonempty → o ∉ extent R B  -- :311-312
```

⇒ 要点**「要素」= 在论域内找不到任何上位归类**（`:249-250` 引体系原话：「存在论域内的上位，那就是概念。
没有上位，就是要素」）。

### 3.2 它如何与 FCA 的闭包衔接

注意 **项目对此的自我审查极为彻底**（`:38-43`、`:163-167`、`:420-436`）：

> 注意 **本文件的映射是【解读】，不是体系原文**（体系原文**未提 FCA**）。

### 3.4 要点一：条**有内容**的结果：两种目光的「要素」是同一个条件

`no_upper_iff_no_split`（`:311`）陈述 `isElementUnderUpGaze R o ↔ ∀ 非空 B, o ∉ extent R B`，

> **「无上位」在两种目光下说的是同一件事**（在非空构成的意义上），

与「真内容」的判断一致。

注意 **陈述里「非空」不可省**（`:299-301` 逐字）：
> `extent R ∅` 对**任意** `o` 都成立（`∀ a ∈ ∅, R o a` **空洞为真**）

但它的**证明技术是初等的**；其价值确实在**陈述的精确化**：
它把「两种目光」的差异主张**转化成一个可反驳的命题**，并**反驳了其中的一个读法**。

## 8. 抽象可靠性：一条**单向**的跨层转移定理

### 8.1 这条定理**不是**什么
