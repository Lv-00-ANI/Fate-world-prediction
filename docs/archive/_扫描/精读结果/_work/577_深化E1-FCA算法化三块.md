### 1.3 要点`IsBasis` / `Impl` / `implClosure` 的载体形态（本轮逐字读取）

```lean
-- RealFCAImplicationBasis.lean:86
def Impl (R : O → A → Prop) : Set (Set A × Set A) :=
  {p | ImplicationHolds R p.1 p.2}

-- RealFCAImplicationBasis.lean:193
def implClosure (R : O → A → Prop) (P : Set A) : Set A :=
  intent R (extent R P)

-- RealFCAImplicationBasis.lean:276-281
def IsBasis (R : O → A → Prop) (𝓛 : Set (Set A × Set A)) : Prop :=
  (∀ p ∈ 𝓛, ImplicationHolds R p.1 p.2) ∧
  (∀ P Q : Set A, ImplicationHolds R P Q →
    ∃ p ∈ 𝓛, p.1 ⊆ P ∧ Q ⊆ p.2) ∧
  (∀ p ∈ 𝓛, ¬ (∀ P Q : Set A, ImplicationHolds R P Q →
    ∃ q ∈ 𝓛 \ {p}, q.1 ⊆ P ∧ Q ⊆ q.2))
```

要点二级**三点判读**：
1. `Impl` 是 **`Set (Set A × Set A)`** —— 一个**物化的语义集合**，**不可枚举**（`Set` 不是可计算容器）；
2. `IsBasis : Prop` —— 要点**是性质谓词**，源码 `:267-269` 逐字自陈「把『基』从**算法对象**（DG 基的构造过程）剥离为**性质谓词**」；
3. 要点`IsBasis` 是 **`def … : Prop := A ∧ B ∧ C`（嵌套合取）而非 `structure`** —— 源码 `:289-292` 逐字记录「点号投影 `h.1` 会失败（`invalid projection, structure expected`）」。
   ⇒ 要点二级**这一条对本文极为关键**：**要对 `IsBasis` 做 `Decidable` 合成，必须先把它改成 `structure`**（见 §2.1.3 步骤 D-3）。

注意 **第三条子句（极小性）用 `𝓛 \ {p}` 而非 `Set.erase`**，源码 `:274` 的理由是「pinned mathlib 4.14 **没有** `Set.erase`」—— 注意 **这是一处 mathlib 主张**，本轮**未做符号级核验**，**登记为待核验**（§5.2 第 3 条）。

#### 2.1.3 具体步骤（含 `Decidable` 实例怎么合成）

要点二级**`Decidable` 合成链（本块的核心技术内容）** —— Lean 4 的 `Decidable` 是**类型类**，实例**逐级合成**，故必须先画清依赖方向：

```
[DecidableEq A]  ──┐
                   ├──▶ Decidable (a ∈ B)          （B : Finset A，Finset.mem 可判定）
[DecidableRel R] ──┴──▶ Decidable (R o a)          （逐点）
                          │
                          ▼
        Decidable (∀ a ∈ B, R o a)                 ⭐ 有限量化：Finset.forall_mem_decidable
                          │                          （⚠ 无限量化 ∀ a : A, … 【不可】判定 —— 这就是必须换 Finset 的根因）
                          ▼
        Decidable (o ∈ finsetExtent R B)           （univ.filter 的成员判定）
                          │
                          ▼
        Decidable (finsetExtent R B ⊆ B')          （Finset 的 ⊆ 是有限检查）
                          │
                          ▼
        Decidable (ImplicationHolds R P Q)         ⭐ 块 2/3 的地基（S-5）
                          │
        ┌─────────────────┴──────────────────┐
        ▼                                    ▼
 Decidable (IsClosedExtent)          Decidable (IsPseudoIntent)   ← 块 2
        │                                    │
        └────────────────┬───────────────────┘
                         ▼
              Decidable (IsBasis 𝓛)                            ← 块 3 的可判定性
```

要点二级**关键机制说明（为什么这一步【必须】换载体）**：
> `extent R B = {o | ∀ a : A, a ∈ B → R o a}` 中的量化是 **`∀ a : A`（对【全类型】量化）**。
> 当 `A` 是任意类型时，这个 `∀` **不是有限量化**，**没有 `Decidable` 实例** ——
> ⇒ 要点**这不是「mathlib 缺一个实例」，而是【数理上不可能】**（无限类型上的全称量化一般不可判定）。
> ⇒ 要点二级**这正是「`Set` 载体在原理上无法算法化」的根因** —— 与 §1.4 的 M-4 呼应。
