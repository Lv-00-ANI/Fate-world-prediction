## A.3 全部核心方程（唯一权威形式）

### A.3.1 离散形式（§3.1）

**唯一权威离散方程：**

$$x_{t+1} = f(x_t,\ u_t,\ \varepsilon_t;\ \theta,\ a_t), \qquad a_t \in \mathcal{A},\quad \theta \in \Theta,\quad u_t \in \mathcal{U},\quad \varepsilon_t \sim \mathcal{D}_\varepsilon$$

配初始条件：

$$x_0 \sim \mathcal{D}_0$$

轨迹由该式迭代生成：

$$\{x_t\}_{t\in\mathcal{T}} = \text{命运}_O, \qquad \mathcal{T} = \{0,1,\dots,T_{\max}\}$$

**出处与依据**：由原文方程 $x_{t+1}=f(x_t,u_t,\varepsilon_t;\theta,do(a_t))$（01:219、01:221；02:288、02:292）经 §3.3 类型修正得到。**修正为 $a_t$ 的根据是 02:402–407 与 02:540。**

**逐位类型表（阶段 0 直接采用）：**

| 参数位 | 符号 | 类型 / 域 | 合法性 |
|---|---|---|---|
| 第 1 位 | $x_t$ | 取值（$\mathcal{X}$ 中一点）/ 随机变量 | 合法 |
| 第 2 位 | $u_t$ | 取值（$\mathcal{U}$ 中一点）/ 随机变量 | 合法 |
| 第 3 位 | $\varepsilon_t$ | 取值（随机变量的一次实现） | 合法 |
| 分号后 1 | $\theta$ | 取值（$\Theta$ 中一点）——**命** | 合法 |
| 分号后 2 | $a_t$ | 取值（$\mathcal{A}$ 中一点）——**选择** | 合法（**原文的 $do(a_t)$ 在此位非法**） |
| 左端 | $x_{t+1}$ | 取值 / 随机变量 | — |
| 输出类型 | — | $f:\mathcal{X}\times\mathcal{U}\times\mathcal{E}_{\text{noise}}\times\Theta\times\mathcal{A}\to\mathcal{X}$ | — |

**四条使用约束（§3.1 说明）**：

1. **$f$ 是单步转移核，不是轨迹生成器**。左手是单步 $x_{t+1}$，右手含 $x_t$。原文另有「命运 $=f(\text{命},\text{运},\dots)$」（02:337），其 $f$ 是轨迹生成器，**不是同一个函数**（01:430–436）。**轨迹生成器不得用 $f$ 命名**；要命名写 $F_{\text{traj}}$，且 $F_{\text{traj}}(\theta,x_0,\{u_t\},\{\varepsilon_t\},\{a_t\})=\{x_t\}$。
2. **$x_0$ 不在 $f$ 的自变量中**（01:295、01:458）。「给定条件」是 $(\theta,x_0)$，但**只有 $\theta$ 是「命」**。
3. **反馈由 $x_t$ 自身递归隐式承载**，不需要额外的「反馈」自变量（01:436、01:550）。
4. **反馈回路的严格形式是条件化而非包含**：

$$P(e_j \mid e_i,\ \{x_\tau\}_{\tau\le t}) \neq P(e_j \mid e_i)$$

（02:196；01:523）

### A.3.2 连续形式（§3.2）

**唯一权威连续方程（SDE）：**

$$dX_t = \mu(X_t,\ \theta,\ a_t)\,dt + \sigma(X_t,\ \theta,\ a_t)\,dW_t, \qquad a_t \in \mathcal{A},\quad \theta \in \Theta$$

等价积分形式：

$$X_t = X_0 + \int_0^t \mu(X_s,\theta,a_s)\,ds + \int_0^t \sigma(X_s,\theta,a_s)\,dW_s$$

**出处**：由原文 SDE $dX_t=\mu(X_t,t;\theta)\,dt+\sigma(X_t,t;\theta)\,dW_t+do(a_t)$（02:290）经 §3.3 类型修正得到。

**四条使用约束**：

1. **离散与连续是同一系统的两种时间参数化**。离散形式 = 连续形式的 **Euler–Maruyama 时间离散化**。原文（02:359–361）未说明该关系，规范予以明确：

$$f(x_t,u_t,\varepsilon_t;\theta,a_t) := x_t + \mu(x_t,\theta,a_t)\Delta t + \sigma(x_t,\theta,a_t)\sqrt{\Delta t}\,\xi_t,\qquad \xi_t\sim N(0,I)$$

   （注：规范原样写 $N(0,I)$，按规则 LA3 正式文档应写作 $\mathcal{N}(0,\mathrm{Id}_d)$。）
2. **$a_t$ 进入 $\mu$ 与 $\sigma$ 两者**。若采用 $\sigma(X_t,\theta)$（扩散项不依赖干预），则 $\partial\sigma/\partial a_t\equiv0$ **是一条附加假设，必须显式声明**（02:413）。
3. **$\theta$ 不显含时间**。若 $\theta=\theta(t)$，自治/非自治分类立即受影响（02:353），此时必须显式写明 $\theta(t)$ 并声明其时间尺度。
4. **存在唯一性**需 Lipschitz 条件 + 线性增长（02:268）；这是**显式假设**，不是自动成立的前提（03:468 的 P10）。

### A.3.3 为什么 $f(x_t,u_t,\varepsilon_t;\theta,do(a_t))$ 是类型错误（§3.3）

该写法在 15、18、19 三轮至少出现五次（02:292、02:415），**作废**。作废理由是**类型错误**，不是记号不便、不是开放问题。

1. **$do$ 是算子、$a_t$ 是取值，属不同类型层。** $do(\cdot)$ 定义域是结构方程集 $\mathcal{F}$，值域是模型 $\mathcal{M}_{do(X=x)}$（02:54）。$a_t\in\mathcal{A}$ 是动作空间中的一点（01:242）。**算子不能作为函数自变量**；把算子放进取值位 = 把「运算本身」当「运算结果」使用。
2. **逐位检查**：前四位都是取值，第五位是算子；**同一参数表内的参数位必须容纳同一类型层的对象**，第五位与前四位不属同一论域。
3. **两种形态的同一错误**：把 $do(a_t)$ 当 $f$ 第五参数，与写出 $dX_t=\mu\,dt+\sigma\,dW_t+do(a_t)$，都在把算子当作作用结果使用。后者还多一重错误：$dt$、$dW_t$ 是**微分元**，$do(a_t)$ 是**模型变换算子**，「模型」与「微分元」之间没有已定义的嵌入、同构或线性结构（02:396），**故不可相加**。
4. **「禁止把 $do$ 写进方程」≠「禁止干预」**。干预经 $a_t$ 进入机制内部（§3.4）；$do$ 保留其在 SCM 结构方程集上的正当用法（§3.6）。一旦进入方程，干预应已体现在机制 $f$（或 $\mu,\sigma$）的参数中。

### A.3.6 $do$ 算子的唯一定义（§3.6）

**定义。** 设 $\mathcal{M}=\langle V,U,F,P(U)\rangle$ 为 SCM，$X\subseteq V$ 为被干预变量集，$x$ 为赋值。$do(X=x)$ 是**模型替换算子**，作用为：

1. **删除所有指向 $X$ 的入边**——从图中删去 $pa(X)$ 到 $X$ 的全部边；
2. **把 $X$ 的结构方程替换为常数方程** $X=x$；
3. **其余结构方程保持不变**。

形式化：

$$\mathcal{M}_{do(X=x)}=\langle V,\ U,\ F_{do},\ P(U)\rangle,\qquad F_{do}:\ X=x,\quad V_i=f_i(pa(V_i),U_i)\ \text{for}\ V_i\neq X$$

（02:54；S:1254 附近）

**两个等价表述必须同时成立、互为说明**：**模型替换**（第 2 条，方程层）与**删边**（第 1 条，图层）是同一次干预在两个层面上的投影——图上删边就是方程上替换为常数。

**单变量与变量集形式**：$do(X=x)$（对变量集赋值，02:313）与 $do(a_t)$（带时间下标的单动作，01:163）**是同一算子的两种写法**；$do(a_t)$ 是 $do(X=x)$ 在 $X=\{a\}$、$x=\{a_t\}$ 且动作被提升为变量时的特例。**正式方程不使用带时间下标的 $do(a_t)$**；$do$ 只出现于模型层表达式。

**英文原文禁令（强制）**：**禁止**使用「切断 $X$ 与其父节点的依赖」（或等价的「切断依赖」「截断依赖」）描述 $do$，**一律改为「删除所有指向 $X$ 的入边（模型替换）」**。四条理由：

1. 该措辞把**图操作**误述为**依赖切断**（统计关系陈述）——删边是原因，依赖消失是后果；把后果当定义，等于取消「为什么删边导致依赖消失」这一需 SCM 语义回答的问题。
2. 该措辞是**统计条件化**的语言，与「干预不等于观测」判词直接冲突（02:66；01:584）；原文同卷内两处直接冲突（02:318、02:303–304）。采用「切断依赖」= 在定义层面删掉该判词。
3. 该措辞抹掉了「模型替换」这一**可执行、可验证**的内容。「切断依赖」**不产生任何模型**，无法据以推出 $P(Y\mid do(X=x))$。
4. 本理论已有一处正确实现可对照：`Intervention.do` 做两步——删除指向该节点的入边、把该节点方程替换为常数函数（04:57：「`copy.deepcopy` → 删除指向 `node` 的入边 → 把该节点方程替换为常数函数」），**正是本定义 1、2 两条**，被判定语义正确（04:57、04:167）。**代码写对了，措辞没跟上。**

**由定义导出的三项限制（02:441–447）**：

1. **$do$ 不接受图作为输出**——它是图→干预分布的推演工具，不是数据→图的发现工具。用它「验证」因果边是循环论证；验证方向需**执行干预实验**。
2. **$do$ 的结论是「在该图下」的条件结论**——图错则结论无效，即使每步推导合法。**推导的合法性与结论的真假是两件事。**
3. **$do$ 不产生观测数据之外的信息**——把干预量**改写**为观测量，不创造新信息。

## C.1 已发现的两处文档间张力（阶段 0 须显式处理）

## C.2 最关键的 3 条结论

### 结论 1：类型化的根本分歧点是「算子 vs 取值」，不是记号

04规范 §3.3 的全部分量都归结为一条类型律：**`do` 的类型是算子（$\{\text{结构方程集}\}\to\{\text{结构方程集}\}$），$a_t$ 的类型是 $\mathcal{A}$ 中的取值；同一参数表内的参数位必须容纳同一类型层的对象。** 因此 $f(\dots;\theta,do(a_t))$ 与 $dX_t=\mu\,dt+\sigma\,dW_t+do(a_t)$ 是同一错误的两形态（外加第二重错误：算子与微分元不可相加）。阶段 0 的类型系统只要把 `do` 建模为 `Op[Model, Model]` 而非 `Value`，这条就自动被机械检查出来，不需要逐条人工审校。**同时须记住：禁止 `do` 入方程 ≠ 禁止干预。干预经 $a_t$ 进入机制参数位，$a_t$ 是必要输入，去掉它是模型退化，不是简化。**

### 结论 2：主链唯一为「实例 →(α)→ 规则 →(γ,π,υ)→ 规则集 → 预测」，因果层是旁路而非前置

这是 06裁决第 4、5、6、7、10 条的**联合结论**，四条互相锁定、必须同时执行：$\alpha:\mathcal{E}\to\mathcal{R}$ 的定义域是实例集（第 7/10 条）→ 规则层合法性不再依赖因果层 → 第 4 条三元循环消解、第 5 条「因果可选 vs 核心中间层」被裁为**可选的必需层**（分目标取值：机制解释/政策评估/干预设计=必需，反事实=必需，点预测=可绕过，规则层=不需要）→ 架构次序 = 「实例 → 规则 → 预测」，**架构图中禁止出现 SCM → 规则 的箭头**，`F:45` 的「先结构，后规则，再预测」作为第一原则废止。类型化后果：`α` 的输入类型必须严格为 `Set[Instance]`，**不得接受 `SCM`**；因果层必须是可挂载的 `Optional[Branch]`。

### 结论 3：真正会阻断阶段 0 的不是「矛盾」，而是**未定义符号**

06裁决的十条矛盾**已全部终裁完毕，无一条悬置**（表中明确移交的五类事项属他文档职责）。真正未闭合的是 04规范 自己标注为「原文从未定义」的符号与结构：$\pi_O$、$\mathcal{X}_{\text{local}}$ 的划界、$\mathcal{C}$ 的结构、编码算子 $x_t\mapsto(A_t,B_t)$ 及其误差界、格上动力学收敛理论、「命显/命隐」判据，以及 8 项定理的文献出处（该栏按规定**留空**）。加上 04规范 §2.6 揭示的结构性规律——**合规程度与规范条目的显式程度高度正相关，漏网不是作者不认真而是条目未覆盖**——阶段 0 的正确做法是：**把上表每一个未定义项建成 `Undefined`/`Pending` 占位类型并在类型检查中强制显式声明，而不是绕过它们或假装已定义。** 凡「用它算下去能得出结果」的路径，都是被未定义符号污染的路径。
