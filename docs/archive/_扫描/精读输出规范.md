# 精读单份文档的输出规范（所有子代理必须遵守）

> 每份文档产出一行 CSV + 必要时若干条「关键句」。
> **不要写读后感、不要写总结段、不要评价质量。只填字段。**

---

## 一、每份文档一行（主表）

文件：`_扫描/精读结果/read-<批次>.csv`，UTF-8 BOM。

| 列 | 必填 | 说明 |
|---|---|---|
| `序号` | ✅ | 从任务清单原样抄 |
| `路径` | ✅ | 从任务清单原样抄 |
| `类别` | ✅ | 六选一，见下表 |
| `主旨` | ✅ | **不超过 50 字**，说清这份文档在讲什么。不要写"本文讨论了…"，直接写内容 |
| `承载设计` | ✅ | **三选一：是 / 部分 / 否**。**是** = 文档主体就是设计（定义概念/方程/假设/算法/模块划分）；**部分** = 形态是过程产物或审计，但内含可抽取的规范、定义或硬规则；**否** = 纯记录、纯描述、纯检查，无可抽取设计 |
| `含推翻陈述` | ✅ | 是/否。**判定口径已统一为：本卡在 keys 表里登记了 ≥1 条关键句 ⟺ `是`**（即「含设计裁决」）。与 `关键句数` 必须完全同步：是→≥1，否→=0 |
| `关键句数` | ✅ | **本卡登记的条数**，不是全文所有推翻句的总数。必须与 keys 表里该序号的实际行数一致（没有填 0） |
| `正文完整` | ✅ | 完整/片段/截断。**片段** = 从更大文档剪出来的；**截断** = 导出时被切断 |
| `备注` | ❌ | 仅在发现异常时写（编码问题、名不副实、空文件等） |

### 类别（六选一，互斥）

| 类别 | 判据 |
|---|---|
| **设计源** | 承载理论/架构设计的正文：定义概念、方程、假设、算法、模块划分、规范性规则 |
| **版本副本** | 与另一份内容重复，或是同一文档的另一版本。**本任务已做哈希去重，若你发现"内容高度相似但不完全相同"的版本，仍判此类并在备注写明疑似对应哪份** |
| **过程产物** | 轮次报告、进度记录、任务派发、临时笔记、会话整理、执行日志 |
| **审计报告** | 对项目做检查/评审/核查/清点，结论是"哪里有问题" |
| **配置说明** | README、环境说明、索引、使用说明、纪律条目 |
| **转储导出** | 机器导出的数据/表格/文档转储，非手写 |

## 二、关键句表（仅当「含推翻陈述=是」时填）

文件：`_扫描/精读结果/keys-<批次>.csv`，UTF-8 BOM。

| 列 | 说明 |
|---|---|
| `序号` | 所属文档序号 |
| `行号` | **原文件里的真实行号**（从 1 开始，必须准确） |
| `原话` | **逐字引用，一个字都不许改**。可以截取一句，但不能改写、不能省略限定词 |
| `类型` | 三选一：`推翻`（说先前结论错了）/ `修正`（说应改为某表述）/ `作废`（说某概念/记号不再使用） |
| `涉及对象` | 被推翻/修正/作废的**具体对象**：概念名、符号、文件名、定理名 |

### 关键句的判定标准（很重要）

**要抽的**：
- 「因果不再是规则的上游，而是旁路」← 这是对设计的判定
- 「DG 基的权威定义已改为自指版 `DGBasisSelfRef`」← 这是对定义的修正
- 「『压缩』一词弃用」← 这是对术语的作废

**不要抽的**：
- 「32 轮中有 9 轮是明确的纠正」← 这是在**统计**纠正次数，不是在纠正
- 「本次提交修正了 3 个 bug」← 这是代码改动记录，不是设计裁决
- 「需要注意的是…」← 这是提醒，不是推翻

**一句话判据**：
> **这句话如果成立，会不会让某条设计不能再按原样使用？**
> 会 → 抽。不会 → 不抽。

## 三、读原文的具体要求

1. **必须读原文**。路径 = `C:\Users\xingg\Desktop\命运计划\命运-素材-原始文件-不可更改\` + 任务清单里的 `路径`。
2. **必须读完整份**。不许只读开头就下判断（本次任务的核心要求）。
3. **超过 50KB 的文件**：先读完，但如果中途发现是同一模式的重复（如大量轮次表格），可以在备注写「第 N 行后为同一模板重复」并跳读剩余部分，**但必须读够足以判断类别和主旨的量**。
4. **遇到乱码文件名**：按任务清单给的路径直接读，文件名乱码不影响内容（内容通常是正常 UTF-8）。
5. **遇到 UTF-16 文件**：Python 用 `encoding='utf-16'` 读。检测方法：读前几个字节有 `\xff\xfe` 或 `\xfe\xff`。
6. **遇到二进制/空文件**：类别填「转储导出」，备注写「非文本」。

## 四、行号必须准确

`行号` 是被后续引用的唯一凭据。**取行号的方法**：

```python
with open(path, 'r', encoding='utf-8', errors='ignore') as f:
    lines = f.readlines()
for i, line in enumerate(lines, start=1):   # start=1，这就是真实行号
    if 关键句 in line:
        print(i, line.strip())
```

**不许估算行号**，不许用"大概在第 200 行左右"。
