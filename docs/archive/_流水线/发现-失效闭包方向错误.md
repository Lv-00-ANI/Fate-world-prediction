# 重要发现：`invalidate ⊆ closureAll` 的**陈述方向是错的**

> **日期**：2026-11-02
> **发现者**：协调者（复核 T14 时）
> **影响**：T8 / T10 / T14 **三个专项**追逐的主定理，陈述本身不成立——不是证不出来。

---

## 一、方向对比

| 概念 | 语义 | 方向 |
|---|---|---|
| `invalidate g k bk` | 改 `k` 会**失效**的声明 = **依赖 `k`** 的声明 | **反向可达**（谁依赖我） |
| `closureAll g n [k]` | 从 `k` 出发**能推出**的声明 | **正向可达**（我依赖谁） |

**两者方向相反。**

失效传播是「我改了，谁受牵连」——沿着 `deps` 边**逆着走**。
而传递闭包是「我从什么推出」——沿着 `deps` 边**顺着走**。

**所以「失效集合 ⊆ 正向闭包」不可能普遍成立。**

---

## 二、零公理反例（`FateV2/Core/InvalidateDirectionCounterexample.lean`）

```lean
/-- 一条声明：`key = 1`，依赖 `deps = [0]`。 -/
def dtest : Decl Nat :=
  { key := 1, kind := .defn, bodyKind := .body, deps := [0], visibility := .open_ }

def gtest : DeclGraph Nat := [dtest]

def val1 : List Nat := closureAll gtest 1 [0]   -- = [0, 0]
def val2 : List Nat := closureAll gtest 2 [0]   -- = [0, 0]
def vald : List Nat := depsOfAll gtest 1        -- = [0]

theorem key_one_not_in_val : (1 : Nat) ∉ val2   -- ✅ 零公理证出
```

**计算实测**：

```
depsOfAll gtest 0  = []          -- 从 0 出发推不出任何东西（没有 key = 0 的声明）
closureAll gtest 1 [0] = [0, 0]  -- 闭包里只有 0
closureAll gtest 2 [0] = [0, 0]  -- 两层之后仍然只有 0
depsOfAll gtest 1 = [0]          -- 但 1 依赖 0
```

所以：`dtest ∈ invalidate gtest 0 .body`（因为 `0 ∈ dtest.deps` 且 kind 传播），
**但 `dtest.key = 1 ∉ closureAll gtest 2 [0]`。**

**主定理的反例成立。**

## 三、正确的陈述应该是什么

「失效集合 ⊆ **反向闭包**」：

```lean
/-- 反向闭包：从 `k` 沿 `deps` 边**逆着**走能到达的声明（谁依赖我）。 -/
def revClosure (g : DeclGraph K) (n : Nat) (roots : List K) : List K := ...

theorem invalidate_subset_revClosure :
    ∀ d ∈ invalidate g k bk, d.key ∈ revClosure g n [k]
```

或者更直接：**「失效集合 = 反向可达中会传播的那些」**——这正是 `InvalidateMixed.invalidateMixed_body_eq_expanding_dependents` 已经在做的事（按 kind 分桶的 `dependents`）。

**⟹ 其实 T7 的 `invalidateMixed_*` 系列已经把这件事说清了**：
失效集合就是「按 kind 过滤的下游」，不需要再套一层正向闭包。

## 五、教训

> **接手一条「证不出」的主定理时，先花 5 分钟验证陈述是否为真。**

三个专项（T8 → T10 → T14）累计投入了大量工作追一条假命题。
每一轮都诚实地报告「未证出」并给出精确定位，但**没人质疑过目标本身**。

这与本项目已记录的「假降级」是同一族问题，但方向相反：
- 假降级：能做说成不能做
- **本次：不能做（陈述为假）却没有识别出来，一直追**

**规程**：派单时要求子代理**先验证陈述的可满足性**（给一个小例子的 `#eval` 或反例搜索），再开始证明。
