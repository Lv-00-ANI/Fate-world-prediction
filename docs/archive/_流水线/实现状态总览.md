### `I1-WF-VIOL` 为什么部分是误报

以 `rawMap_total` 为例：

```lean
theorem rawMap_total (L : DiscLaw α) (f : α → Z) :
    (rawMap L f).total = L.total := rfl
```

**它是 `rfl`** ⟹ 对**任意** `DiscLaw`（包括 `vals`/`wt` 不等长的）都成立。
「表不等长时结论可能为假」对它不适用——因为 `total` 的定义就是 `sumN wt`，与 `vals` 无关。

**G14 的判据是「签名里没有 `WellFormed` 前件」**，这对 `rfl` 型定理过严。
